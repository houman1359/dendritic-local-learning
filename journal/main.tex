\begin{abstract}
Learning in neural networks requires assigning task error to individual weights. Real neurons distribute these weights across dendritic branches: when must learning distinguish locations within a neuron? We describe learning signals as combinations of spatial delivery patterns, or a route dictionary, and derive how local synaptic sensitivity combines with downstream error. In image classifiers, one signal per neuron captures most of the learning benefit. Branch-selective updates help when branches receive conflicting inputs; higher-order interactions can additionally favor signals that change with the input. In conductance-neuron populations, inhibitory gating improves resistance to distractors but fails on a nonlinear interaction task. Adding the parent branch's response slope rescues learning with Adam. Removing the target interaction largely removes the deficit, even with the same nonlinear branches. Separate experiments show that serial compartments help correct nuisance gains when information is distributed across branches. Reconstructed arbors provide sparse representations of modeled sensitivity changes, but recorded visual responses show no detected preferential alignment with shared dendritic ancestry. These results distinguish the spatial information a task needs from the delivery patterns and gains dendrites can supply. They do not establish that biological teaching signals use those patterns.
\end{abstract}

\section*{Introduction}

Learning requires assigning task error to individual weights. Backpropagation (BP) computes this assignment by applying the chain rule through a network \citep{rumelhart1986learning}; related sensitivity calculations apply to recurrent and steady-state systems \citep{almeida1987asynchronous,pineda1987recurrent}. For a point neuron, the gradient separates into a weight's local effect on output and that output's downstream effect on loss. Biologically, these factors correspond to a synaptic eligibility and a learning signal. Hebbian plasticity associates local pre- and postsynaptic variables \citep{hebb1949organization}, whereas three-factor rules combine eligibility with an outcome-dependent signal \citep{fremaux2016threefactor}. The learning signal need not be computed locally.

Learning theories differ in how they obtain that signal and how efficiently it guides updates \citep{werfel2005learning}. Feedback alignment uses separate error pathways \citep{lillicrap2016feedback,nokland2016dfa}; equilibrium, predictive and prospective methods infer target states or errors through dynamics \citep{scellier2017equilibrium,whittington2017predictive,song2024prospective}; eligibility propagation combines temporal traces with neuron-specific signals \citep{bellec2020eprop}. Preserving neuronal identity can convey more information than sharing one scalar across neurons \citep{whittington2019theories,lillicrap2020backprop}. Evidence for distinct instructive signals across neuronal populations motivates asking which additional distinctions matter within one arbor \citep{francioni2026vectorized}.

Real neurons distribute synapses across dendrites, where cable filtering, nonlinear integration and inhibition shape somatic output \citep{rall1962dendrites,koch1999biophysics,poirazi2003pyramidal,london2005dendritic,spruston2008pyramidal,branco2010single,larkum2013cellular}. Knowing which neuron contributed to an error need not identify which branch should change. Conversely, distinct branch computations need not require distinct learning signals. We ask when one signal per neuron suffices and when learning benefits from finer spatial information.

A learning signal has both a value and a set of recipients. We describe the available spatial delivery patterns as a \emph{route dictionary}. Each pattern specifies how strongly a signal reaches each compartment; a coefficient, which may change with the input example, sets that pattern's amplitude. A single uniform pattern broadcasts through the arbor, whereas several patterns can distinguish subtrees. We use \emph{ancestry} to describe the shared branching paths from the soma: descendants of a branch form one subtree. Unlike a basis, a dictionary can contain redundant patterns. Conductance changes can modify delivery gains: inhibition lowers local resistance and attenuates other inputs even when its own current is small \citep{koch1983nonlinear,holt1997shunting,chance2002gain,gidon2012inhibition,lovettbarron2012regulation}.

Dendritic models already connect compartmental computation and plasticity to memory, feature binding and forward capacity \citep{poirazi2001capacity,legenstein2011branch,jones2021successive,beniaguev2021single}. Learning theories propose somatic prediction, segregated teaching, interneuron-mediated errors, bursts and prospective dynamics \citep{urbanczik2014dendritic,schiess2016somatodendritic,guerguiev2017segregated,sacramento2018dendritic,payeur2021burst,ellenberger2026gle,richards2019dendritic}; cable-learning models optimize reconstructed neurons through synaptic sensitivities \citep{bicknell2021synaptic}. Our question concerns the spatial information these mechanisms must preserve.

Building on our conductance-tree preprint \citep{safaai2026localcredit}, we test a progression from neuronal identity to branch selection and input-dependent transport. The central distinction is between selecting a recipient branch and supplying the sensitivity its update requires. We then separate these learning requirements from the contributions of serial forward computation, anatomical delivery patterns and conductance-dependent gain. Throughout, representability is checked before attributing a learning deficit to credit assignment.

\section*{Results}

Four model classes separate the roles of dendritic structure. Feedback-only hierarchies determine recipients without serial forward computation (Figs.~\ref{fig:branchconflict}--\ref{fig:subtreefactorial}); scalar computational trees allow exact representability tests (Fig.~\ref{fig:prospective}); directed conductance trees model integration toward the soma (Figs.~\ref{fig:framework}, \ref{fig:conductancecredit}--\ref{fig:physicaldepth}); and reciprocal cables include bidirectional current flow along reconstructed arbors (Figs.~\ref{fig:topology}--\ref{fig:focal}). Recorded responses separately test functional alignment with branching structure (Fig.~\ref{fig:boundary}). DendriNet implements the image, population and physical-depth studies; the single-neuron conductance study uses standalone NumPy code. Reciprocal cables, algebraic trees and statistical analyses use separate implementations. Each figure identifies its model or data source (Supplementary Notation guide).

\subsection*{Exact gradients separate local sensitivity from downstream credit}

For a point neuron $u$ with output $y_u=f_u(\sum_iw_ix_i+b_u)$ and task loss $\mathcal L$, the chain rule gives $\partial\mathcal L/\partial w_i=x_if'_u\delta_u$. Here $x_i,w_i$ are input activity and weight, $b_u$ is bias, $f_u$ is the activation function, and $\delta_u=\partial\mathcal L/\partial y_u$ is the neuronal error. The derivative $f'_u$ is evaluated at the current input sum. Eligibility $x_if'_u$ measures the weight's local effect; credit $\delta_u$ measures its downstream consequence (Fig.~\ref{fig:framework}A). Eligibility here is an instantaneous derivative, without a temporal trace. Gradient descent changes a weight by $-\eta$ times its gradient, with learning rate $\eta>0$.

A directed compartment tree replaces the point neuron, with soma \(n=0\) and compartment voltages \(V_n\), suppressing the neuron index $u$ where unambiguous. A contact with maximal conductance \(g_i\geq0\), activity \(x_i\geq0\), and reversal potential \(E_i^{\mathrm{rev}}\) contributes current \(g_ix_i(E_i^{\mathrm{rev}}-V_n)\). A child \(c\) supplies output \(a_c=f_c(V_c)\) to its parent through coupling conductance \(g_{c\to n}^{\rm den}\). Let \(\mathcal S_n^X\) be the contacts of class \(X\in\{\mathrm E,\mathrm I\}\) on compartment $n$, and \(G_n^X=\sum_{i\in\mathcal S_n^X}g_ix_i\) their aggregate open conductance. Leak conductance and reversal potential are \(g_n^{\rm L}\) and \(E_{\rm L}\). Summing over children of $n$, the directed model imposes zero net current:
\[
0=g_n^{\rm L}(E_{\rm L}-V_n)
 +G_n^{\rm E}(E_{\rm E}-V_n)+G_n^{\rm I}(E_{\rm I}-V_n)
 +\sum_c g_{c\to n}^{\rm den}(a_c-V_n).
\]
Collecting the terms in \(V_n\) gives the steady state
\begin{equation}
\begin{aligned}
V_n&=R_n^{\rm tot}\left(g_n^{\rm L}E_{\rm L}+G_n^{\rm E}E_{\rm E}
 +G_n^{\rm I}E_{\rm I}+\sum_cg_{c\to n}^{\rm den}a_c\right),\\
(R_n^{\rm tot})^{-1}&=g_n^{\rm L}+G_n^{\rm E}+G_n^{\rm I}
 +\sum_cg_{c\to n}^{\rm den}.
\end{aligned}
\label{eq:directedvoltage}
\end{equation}
Here \(R_n^{\rm tot}\) is the reciprocal of the compartment's total conductance, with incoming child outputs held fixed. It is a local resistance in the directed model, not the driving-point resistance of a reciprocal cable, where neighboring voltages also respond to an injected current. Excitation and inhibition differ through their reversal potentials, not through a negative inhibitory conductance. The artificial trees use dimensionless \(E_{\rm E}=1\) and \(E_{\rm I}=E_{\rm L}=0\). Inhibition therefore contributes to the denominator but not the numerator: increasing \(G_n^{\rm I}\) lowers local resistance and attenuates excitation and child input. This is shunting inhibition. The division concerns steady-state voltage, not a general divisive effect on firing rate \citep{holt1997shunting}. These directed steady states are evaluated from terminals to soma; reciprocal reconstructed cables are treated separately below.

Holding the incoming child outputs fixed, differentiating Eq.~\ref{eq:directedvoltage} gives \(\partial V_n/\partial g_i=x_iR_n^{\rm tot}(E_i^{\rm rev}-V_n)\). Applying the chain rule then yields
\begin{equation}
\frac{\partial\mathcal L}{\partial g_i}
=\underbrace{x_iR_n^{\mathrm{tot}}(E_i^{\mathrm{rev}}-V_n)}_{\mathrm{local\ eligibility}}
\underbrace{\delta^V_{n,u}}_{\partial\mathcal L/\partial V_n}.
\label{eq:factorization}
\end{equation}
Excitatory and inhibitory contacts share this factorization (Fig.~\ref{fig:framework}A): eligibility measures conductance-to-voltage sensitivity, and credit measures voltage-to-loss sensitivity. For a coupling conductance, the corresponding local factor is $R_n^{\rm tot}(a_c-V_n)$. When $g=\exp\theta$ is optimized in log coordinates, the chain rule gives $\partial\mathcal L/\partial\theta=g\,\partial\mathcal L/\partial g$ (Supplementary Section~S1).

An additive control retains the graph while summing signed inputs without conductance division or reversal-potential driving forces. Its eligibility is differentiated from that additive computation (Methods).

Voltage error denotes a loss derivative. Each compartment has one directed path to the soma, giving
\begin{equation}
\delta^V_{n,u}=\delta^V_{0,u}\widetilde\alpha_n,
\qquad
\widetilde\alpha_n=
\prod_{(i\to k)\in\operatorname{path}(n\to0)}
f_i'(V_i)R_k^{\mathrm{tot}}g_{i\to k}^{\mathrm{den}}.
\label{eq:pathgain}
\end{equation}
Here \(f'_i(V_i)\) is the child compartment's output derivative, \(g_{i\to k}^{\mathrm{den}}\) is its coupling conductance to parent \(k\), and \(\delta^V_{0,u}=f'_0(V_0)\delta_u\) is the somatic voltage error. The path multiplier \(\widetilde\alpha_n\) converts one somatic error into a \emph{learning-signal field}: one error value at each compartment. The conductance-only component of this product is attenuated by additional conductance on a path's ancestors; branch nonlinearities and forward voltages can change as well (Supplementary Section~S1 and Fig.~S1).

Reciprocal cables instead require a joint adjoint calculation of how local currents affect task loss (Methods). These mathematical sensitivities do not establish a biological error-transmission mechanism.

Local credit assignment (LocalCA) retains eligibility and supplies an approximate compartment signal, denoted by a hat (Fig.~\ref{fig:framework}B shows a strict scalar, one signal per neuron and the exact path, each on a generic tree):
\begin{align}
\widehat\nabla_{g_i}\mathcal L
=x_iR_n^{\mathrm{tot}}(E_i^{\mathrm{rev}}-V_n)\widehat\delta^V_{n,u},
\label{eq:dendriticlocalrule}
\\
\widehat{\bm\delta}^{V}_u=A_u\bm c_u.
\label{eq:routedfield}
\end{align}
Columns of \(A_u\in\mathbb R^{N_u\times K}\) are fixed delivery profiles over \(N_u\) nonsomatic compartments; the coefficient vector \(\bm c_u\) sets their amplitudes for each example. To distinguish the supplied coefficients from local modulation, we write \(\bm c_u=\Gamma_u\bm c_u^{\rm source}\). The diagonal matrix \(\Gamma_u\) scales each profile (Fig.~\ref{fig:framework}A). Fixed nonzero gains preserve the set of fields the dictionary can represent, although they can affect optimization and the influence of unreliable signals (Supplementary Figs.~S4--S5). Broadcast, subtree and compartment profiles give progressively finer control over where credit is delivered (Fig.~\ref{fig:framework}C). This describes signal delivery; it does not specify the mechanism that computes the coefficients or the forward cable dynamics.


At \(K=1\), the all-ones column \(A_u=\bm1\) broadcasts one coefficient through the arbor; at \(K=N_u\), the identity matrix \(A_u=I\) can reproduce the full nonsomatic field. Nested subtrees provide intermediate dictionaries. Profile count, rank (the number of independent profiles) and coefficient information are distinct resources. Exact path transport combines one somatic scalar with state-dependent local derivatives; it does not require an independent external error for every compartment. We call a coefficient rule \emph{oracle} when it uses an exact field unavailable to the restricted learner. Such a rule tests what the dictionary could express, not how a biological circuit would calculate its coefficients.

We quantify representational capacity by \emph{capture}: the fraction of a learning-signal field's squared amplitude reproduced by its least-squares projection onto the dictionary. We call this squared amplitude ``field energy''; it is not an energetic cost of biological signaling:
\[
\mathcal C(A;\bm\delta)=\frac{\|P_A\bm\delta\|^2}{\|\bm\delta\|^2},\qquad P_A=AA^\dagger.
\]
Here $A^\dagger$ is the Moore--Penrose pseudoinverse. Averaging these ratios weights fields equally; $\tr(P_AC)/\tr(C)$, with uncentered second moment $C=\E[\bm\delta\bm\delta^{\mathsf T}]$, weights them by energy. Both use oracle least-squares coefficients and measure reconstruction, not task performance.

The learning signal depends on whether we differentiate compartment voltage or output. In the nonlinear image models, the delivered signal is a loss derivative with respect to compartment output, and eligibility includes the derivative of output with respect to voltage. When compartment outputs are identity functions, output and voltage errors coincide. We report voltage-error capture separately and compare the conventions in Supplementary Table~S2. Exact-transport, activation-function and additive-integration controls are reported in Supplementary Fig.~S2. These distinctions let us compare spatial delivery without silently changing the local derivative.

Better reconstruction of a learning signal does not necessarily produce a better parameter update. Local eligibilities transform that signal before it changes a weight. If $E_\theta(x)$ maps compartment signals to parameter gradients, the exact and delivered gradients are $\bm g=E_\theta\bm\delta$ and $\widehat{\bm g}=E_\theta P_A\bm\delta$; the latter need not be an orthogonal projection of $\bm g$. The one-step smoothness guarantee therefore concerns the delivered update's mean and covariance, which field capture alone does not determine (Methods; Supplementary Fig.~S3G). Field capture alone therefore does not predict which tree will learn best; additional structure-selection tests are reported in Supplementary Section~S12.

\subsection*{One signal per neuron captures most of the image-task learning benefit}

Image classification provides a reference using directed artificial conductance trees (DendriNet), without reconstructed morphology or spiking dynamics \citep{safaai2026gainload}. The MNIST networks used one layer of 128 $[3,3]$ trees, each with three proximal and nine terminal compartments, followed by a trainable readout. Branching vectors list daughter counts from soma to tips. Shunting and raw-additive controls shared the graph, contacts, nonlinearities and protocol, with architecture-specific initialization; the additive model removed the conductance denominator and reversal-potential driving forces.

Six rules separated neuronal identity from within-arbor resolution (Fig.~\ref{fig:framework}B--D). A strict scalar shared one signal across neurons; per-neuron feedback broadcast each neuron's readout-derived error through its arbor. Projected $K=1$ and $K=3$ rules instead averaged exact activation errors across the arbor or within each proximal subtree. Per-neuron and projected $K=1$ feedback thus shared a spatial profile but obtained their coefficients differently. Exact paths retained every compartment error; a decoder-only reference froze the dendritic core. Development-selected and common-rate comparisons used ten fresh paired seeds per architecture over 180 epochs (Methods; Supplementary Fig.~S7).

Preserving neuronal identity produced the main accuracy gain. Per-neuron feedback reached approximately 97\% accuracy in both architectures, exceeding the strict scalar by 9.23 percentage points in shunting trees and 7.46 in additive trees (Fig.~\ref{fig:framework}D,E). Decoder-only learning was substantially less effective. Three projected profiles improved little over one: selected-rate paired intervals spanned zero, with similarly small common-rate differences. Exact paths added almost nothing in shunting trees and a small gain in additive trees, also attainable with one projected profile. Preserving each neuron's error mattered much more than resolving its delivery within the arbor.

This pattern extended to different feedback sources and image tasks. With a fixed random feedback matrix, direct feedback alignment (DFA) again benefited strongly from neuronal identity and little from exact within-arbor transport \citep{nokland2016dfa} (fifteen paired seeds; Fig.~\ref{fig:framework}E,F). Fashion-MNIST gave a similar result in ten seeds, although its less restrictive scalar fallback retained neuronal signals for some parameters. On flattened CIFAR-10, exact paths slightly reduced accuracy relative to per-neuron feedback while matching BP within a prespecified one-percentage-point equivalence margin (twenty seeds). Differences in feedback source, scalar construction and tree preclude pooling their effect sizes. Full estimates, intervals and equivalence tests are in Supplementary Section~S2 and Figs.~S6--S9.

Richer dictionaries nevertheless reconstructed the trained learning-signal fields more accurately (Fig.~\ref{fig:framework}G). Moving from one profile to three increased capture in both architectures, particularly in the additive trees; the identity dictionary reproduced the field by construction. Thus the extra spatial information was present, but preserving more of it brought little additional classification benefit. We next tested tasks in which the identity of the recipient branch was explicitly relevant.

\subsection*{Branch-selective information prevents updates from inactive distractors}

Branch selection matters when local activity comes from irrelevant inputs. A logistic classifier had $B\in\{2,4,8\}$ parallel branch weight vectors, without internal forward compartments or conductance nonlinearities (Fig.~\ref{fig:branchconflict}A). Context selected the branch determining the output, but every branch formed an ungated eligibility. Inputs were pooled Fashion-MNIST images from two classes, giving 50\% chance accuracy. At conflict dose $\chi=0$, all branches received the selected image; increasing $\chi$ replaced nonselected images independently with opposite-class examples.

For binary cross-entropy loss, example $i$ has selected branch $b_i^\star$, input $\bm x_{i,b}$ and target $y_i\in\{0,1\}$:
\begin{equation}
z_i=\bm w_{b_i^\star}^{\mathsf T}\bm x_{i,b_i^\star},\qquad
\delta_i=\sigma(z_i)-y_i,
\label{eq:branchconflictforward}
\end{equation}
where $\sigma$ is the logistic function. Unselected branches have zero exact derivative despite nonzero eligibility. For $N$ examples, branch-specific and neuron-shared updates use
\begin{equation}
\bm d_b^{\rm selected}=N^{-1}\sum_i\delta_i\mathbf1[b_i^\star=b]\bm x_{i,b},\qquad
\bm d_b^{\rm shared}=N^{-1}\sum_i\delta_i B^{-1}\bm x_{i,b}.
\label{eq:branchconflictupdates}
\end{equation}
Weights change by $-\eta\bm d_b$. The factor $1/B$ matches summed delivery coefficients, not update norms. A feedback selector and an eligibility gate are algebraically equivalent. In dictionary notation, $A=I_B$, $\Gamma_{bb}=\mathbf1[b_i^\star=b]$ and $\bm c^{\rm source}=\delta_i\bm1_B$: one error and a context cue control $B$ branch profiles, rather than a fixed $K=1$ profile. Context $c$ is distinct from coefficient vector $\bm c_u$. Deranging the route preserves rank and sparsity while changing recipients (Fig.~\ref{fig:branchconflict}B).

The shared update's signed alignment with the exact update, $\langle\bm d^{\rm shared},\bm d^{\rm selected}\rangle/\|\bm d^{\rm selected}\|^2$, predicts initial descent when positive and ascent when negative. Centered symmetric evidence gives $s(\chi)=1-2\chi(B-1)/B$, crossing zero at $\chi_c=B/[2(B-1)]$. Measured initial alignment closely followed this prediction, with small systematic deviations (Fig.~\ref{fig:branchconflict}C). Trained chance crossings were displaced because alignment changed during learning, but shared credit failed sooner with more branches: eight crossed before four, and four before two, in every seed. Some two-branch fits never crossed chance (Fig.~\ref{fig:branchconflict}D; Supplementary Fig.~S10).

A separate synthetic interference task showed the consequence for previously learned contexts. Shared credit substantially degraded performance on an earlier context, whereas subtree selection preserved it in all ten seeds (Fig.~\ref{fig:branchconflict}E). Selection protects the inactive parameter blocks by construction; this test does not establish protection against forgetting when contexts share a learned representation.

At full conflict, correct selection exceeded shared credit by roughly 35--58 accuracy points, with a larger benefit at stronger conflict in every seed. Sending the same signal to the wrong branch was harmful even without conflict and led to below-chance performance under strong conflict (Fig.~\ref{fig:branchconflict}F--H). BP and the gated point control matched branch-specific selection exactly. Although changing branch count also changes capacity, these within-architecture comparisons isolate a clear requirement: the learner must identify which branch should receive the error. It does not need a separate externally computed error for every branch.

\subsection*{Ancestry provides a modest advantage at an intermediate feedback budget}

Nested subtree profiles offer intermediate resolution between broadcast and branch-specific delivery. Eight independent eight-dimensional terminal weight blocks occupied a balanced binary feedback tree; only the context-selected block determined the logit. Internal nodes defined feedback supports without serial forward computation (Fig.~\ref{fig:subtreefactorial}A). Distractors opposed the selected class increasingly with hierarchical distance, deliberately favoring the matched task-to-route assignment.

Profiles grouped all terminals, halves, sibling pairs or individual terminals at $K\in\{1,2,4,8\}$. Each profile had unit length. The selected stream supported its class, while more distant streams supplied stronger opposing evidence. Pooling over the whole tree or a half therefore mixed incompatible signals; sibling pairs were the first grouping with net positive evidence (Fig.~\ref{fig:subtreefactorial}B; Methods). This resolution follows from task design, not unsupervised discovery of an optimal anatomy.

Rank-matched controls changed assignment, support geometry or sparsity through cyclic derangement, depth-interleaving, random-sparse routes and dense random fields. Figure~\ref{fig:subtreefactorial}B preserves the signs of the delivered coefficients $\Phi_{cb}$, normalized by each row's maximum absolute value. Permuting task streams across leaves leaves forward resources fixed. Matched partitions had coincident field capture, so capture alone cannot explain performance (Supplementary Fig.~S11A).

Correct routing improved as profiles became more selective, while coarse pooling and wrong-branch delivery could drive performance below chance (Fig.~\ref{fig:subtreefactorial}C). Rewiring the tree while preserving branch degree and depth impaired intermediate-resolution delivery, but had no effect when credit was fully shared or fully resolved (Fig.~\ref{fig:subtreefactorial}D). The advantage specific to ancestry was modest: at $K=4$, it exceeded the per-seed best matched control by 1.27 percentage points (95\% paired interval, 0.59--1.95; Holm-adjusted $P=0.0101$). It lost at lower budgets and tied at full resolution. The much larger contrast with wrong-branch delivery mainly reflects assignment, whereas the smaller advantage over other well-matched profiles measures the contribution of ancestry itself (Fig.~\ref{fig:subtreefactorial}E).

A separate twenty-seed cohort tested coefficient estimation. A cue encoder learned supplied route-activation labels, rather than discovering routing from task outcomes. With noisy cues, its soft coefficients improved on a frozen profile but remained far below oracle delivery. Exploratory hard selection narrowed the gap by preventing weak signals from reaching incompatible routes (Fig.~\ref{fig:subtreefactorial}F). With noise-free cues, hard selection matched the oracle at every calibration size; soft delivery needed more examples. Delaying the decoded route across independent contexts removed its benefit (Supplementary Section~S3). Useful delivery therefore requires both an appropriate pattern and activation on the correct example.

\subsection*{Cross-branch interactions change the spatial credit that learning uses}

Branch selection identifies recipients, but it may not capture how their contributions change with the input. To isolate this issue, we compared tasks with the same average input sensitivity but different interaction order. Seven scalar computational units allowed us to establish that the targets were exactly representable before testing learning. Each unit computed $u=a+bu_L+cu_R+du_Lu_R$, combining its two child outputs and their product. Eight independent inputs were equally likely to be $-1$ or $+1$. Pairwise targets summed four disjoint products, $f_M=\frac12\sum_{(i,j)\in M}s_{ij}x_ix_j$; quartic targets combined complementary quartets, $f_A=\frac12(s_A\prod_{i\in A}x_i+s_{\bar A}\prod_{i\notin A}x_i)$. Signs were independently sampled from $\{-1,+1\}$; here $A$ is an input set, not a delivery matrix. Paired tasks shared a compatible tree, input assignment, initial weights and examples (Fig.~\ref{fig:prospective}A).

Both targets have input-sensitivity second moment $\E[\nabla_xf\nabla_xf^{\mathsf T}]=I_8/4$. However, orthogonality of binary-input products gives $\E\|\nabla_xf\|^2=d\operatorname{Var}(f)$ for homogeneous degree $d$. Matching this spectrum therefore requires clean variances one and one-half for pairwise and quartic targets; equal absolute label noise gives twice the quartic relative noise floor. Both tasks use squared-error loss. Spectrum matching controls first-derivative sensitivity, not interaction order or relative noise.

Compatibility means that some parameter setting represents the target exactly. For these scalar trees, it depends on how interactions cross each subtree boundary: one scalar output must summarize all information that the rest of the tree needs from that subtree. We derived a necessary and sufficient rank condition for this requirement, together with a lower bound on error when it fails. The condition explains why some logical targets require particular input groupings or depths, independently of the learning rule (Methods; Supplementary Section~S4 and Figs.~S14--S15). Both targets in the matched comparison satisfy it.

All rules used exact local eligibilities and the same output error. Exact paths were compared with unit broadcast and a calibrated six-site profile, frozen from mean path derivatives on 256 unlabeled initialization examples (Fig.~\ref{fig:prospective}B). Three development seeds selected rates with equal budgets; twenty fresh paired seeds evaluated them. A separate nested target used prefix interactions on its own compatible depth-four tree, without the matched spectrum (Supplementary Fig.~S12F).

The calibrated profile learned pairwise targets well but left substantial quartic error (Fig.~\ref{fig:prospective}C,D). Normalized mean squared error (NMSE) divides prediction MSE by clean target variance. At 1,024 updates, the quartic-minus-pairwise increase in the calibrated-minus-exact gap was 0.838 (95\% paired interval, 0.719--0.931), positive in all twenty seeds; the common-rate comparison was similar. Most exact quartic fits were near the noise floor, and the remaining fits reached it with further training. A slow exact pairwise fit affected its mean, limiting interpretation of the early mean-error ordering. Nested outcomes are in Supplementary Figs.~S16--S17.

The deficit persisted when we removed the noise imbalance between tasks. Twenty additional paired seeds compared the original absolute noise, no label noise and matched relative noise, using the previously selected and common Adam rates. We define the interaction-dependent credit deficit as $D_{\rm int}=[\mathrm{NMSE}_{\rm cal}-\mathrm{NMSE}_{\rm exact}]_{\rm quartic}-[\mathrm{NMSE}_{\rm cal}-\mathrm{NMSE}_{\rm exact}]_{\rm pairwise}$. After 16,384 updates, it remained near one normalized-error unit and positive in every seed under all three noise conditions (Fig.~\ref{fig:prospective}E). Unequal relative noise therefore does not explain the fixed-profile deficit in this comparison. Rates were not retuned for each noise condition, and these finite-budget results do not establish convergence (Supplementary Section~S4).

Longer training of the original seeds gave the same qualitative separation. Extending all trajectories to 16,384 updates without retuning removed the early exact pairwise lag but preserved the interaction deficit at both final and validation-selected states (Fig.~\ref{fig:prospective}F). The deficit was positive in every seed at each tested budget. These continuations reuse the original cohort, and the dynamics remain constrained: calibrated fits contacted coefficient bounds, whereas exact fits did not. Common-rate and optimizer controls are reported in Supplementary Table~S8.

The learned credit fields reveal a distinction missed by the matched input spectrum. Let $\bm q(x)$ contain root-output derivatives with respect to the six nonsomatic outputs. In exact-trained pairwise models, almost all field energy lay along one fixed spatial direction: only its amplitude needed to change between examples. For quartic and nested targets, one direction captured less than half, and approximately five reached 95\% capture (Fig.~\ref{fig:prospective}G). Longer training and alternative weightings preserved this separation. Uniform broadcast captured little in every task, because even a one-dimensional field can have a nonuniform, signed direction (Supplementary Section~S4).

These results support input-dependent credit in the tested interaction tasks without establishing that all six exact signals are necessary for learning. Reconstructing an exact-trained field and learning the target are different requirements. One- and two-profile oracle learners, input permutations, Boolean tasks, positive-conductance teachers and optimizer controls delimit this distinction; some tasks remain learnable with fixed or broadcast credit (Supplementary Figs.~S13--S18). Finite-sample estimation and direct learning tests are in Supplementary Fig.~S37. Interaction structure motivates credit comparisons, rather than a universal resolution law.

\subsection*{Local inhibitory selection preserves opposing branch tuning}

We next asked which spatial distinctions inhibition can supply, beginning with branch selection in a conductance neuron. A standalone NumPy implementation of Eq.~\ref{eq:directedvoltage} used seven-compartment teachers and students with four terminals, two proximal compartments and a soma, guaranteeing representability. This implementation is separate from DendriNet. Compartment outputs were identity functions, $a_n=V_n$; conductance division still made input integration nonlinear. Both subtrees received the same two independent features $z_1,z_2\sim\mathcal U[-2,2]$, encoded as $\exp(\pm z_j)$ at their terminals. A binary context cue inhibited one proximal compartment, selecting the other subtree for stronger transmission to the soma. Teacher tuning increased with features in both subtrees for aligned targets, but increased in one and decreased in the other for opposed targets (Fig.~\ref{fig:conductancecredit}A). All 24 excitatory, inhibitory and coupling conductances learned from paired initial states and examples. A simpler monotonic teacher was already learnable with broadcast despite a varying path field (Supplementary Fig.~S19).

Context changes distal transport while leaving proximal transport factors context invariant; the somatic error can still vary with context. The hard distal gate delivered $\widehat\delta^V_i=\delta^V_0\mathbf1[a_p^{\rm I}=0]$ to terminal $i$ of parent $p$, where parent inhibitory activity $a_p^{\rm I}$ was zero or ten. A continuous alternative used gain $(1+g_p^{\rm I}a_p^{\rm I})^{-1}$, with maximal inhibitory conductance $g_p^{\rm I}$ and unit leak. Proximal and somatic signals remained ungated. For each terminal input conductance $g=\exp\theta$, the local update was proportional to $-\widehat\delta_i^V\,\partial V_i/\partial\theta$; log-coordinate eligibility includes the factor $g$ in Eq.~\ref{eq:factorization}. The gate selects which terminals receive somatic error without evaluating path products. It is approximate: inhibition attenuates exact distal credit but does not generally reduce it to zero. Two fixed distal profiles with oracle amplitudes and unit proximal credit supplied a capacity control (Fig.~\ref{fig:conductancecredit}B).

The opposed target exposed a large difference between learning rules. Across twenty paired seeds, exact credit, the hard distal gate and the oracle all reached low validation-selected error, whereas broadcast retained substantial error (Fig.~\ref{fig:conductancecredit}C,D). On aligned targets, broadcast was much more effective. The increase in its deficit relative to the gate was positive in every seed and persisted with longer training (Supplementary Fig.~S22A). Curves report fixed-checkpoint error; endpoint comparisons use validation-selected states within the stated budget.

Both gating location and assignment mattered. Reversing distal selection failed. Gating proximal updates also failed because it closed precisely when proximal inhibitory eligibility was nonzero, preventing those conductances from learning. Correct distal gating changed all 24 parameters and succeeded across tested rates; continuous gating performed similarly (Fig.~\ref{fig:conductancecredit}E). The earlier calibrated-broadcast model also showed stronger cancellation of context-specific gradients than exact credit (Supplementary Fig.~S22B). Most opposed broadcast fits contacted bounds, unlike exact and gated fits; wider-bound controls are in Supplementary Fig.~S20.

Checkpoint tuning curves make the learned computation visible: exact credit and distal gating closely recover the teacher's increasing and decreasing branch contributions, whereas broadcast weakens both (Fig.~\ref{fig:conductancecredit}F,G).

Independent-input follow-ups extended the comparison to graded teacher, sensory-selection and sensory-mixture targets. Relative input resistance improved over broadcast in all twenty seeds of each task, whereas the earlier proportional gate failed on graded mixtures. Residual errors and bound contacts limit this extension (Supplementary Section~S5 and Supplementary Table~S13).

\subsection*{Parent response sensitivity rescues learning of a nonlinear interaction}

To test selection beyond the single-neuron teacher, we used the PyTorch DendriNet implementation to train sixteen $[4,2]$ neurons on four sensory streams. Each neuron had eight terminals, four proximal compartments and a soma. Two terminals carrying features $j=1,2$ fed the proximal compartment assigned to stream $b$; an affine readout combined somatic voltages, $\widehat y=\sum_u w_u^{\rm out}V_u+b^{\rm out}$ (Fig.~\ref{fig:conductancepopulation}A). Here $w_u^{\rm out}$ and $b^{\rm out}$ are trainable readout weights and bias. A one-hot cue selected one stream: $c_b=1$ for that stream and zero otherwise. Inhibitory activity $a_b^{\rm I}=4(1-c_b)$ suppressed the other proximal compartments. Features $z_{bj}$ were independently uniform on $[-2,2]$ and encoded as $\exp(\pm z_{bj})$. The separable target added two feature responses; the interaction target also required their product:
\[
y_{\rm sep}=\sum_{b=0}^3c_b(-1)^b\frac{\tanh z_{b1}+\tanh z_{b2}}2,
\qquad
y_{\rm int}=y_{\rm sep}+\frac14\sum_{b=0}^3c_b(-1)^b\tanh z_{b1}\tanh z_{b2}.
\]
The initial selection experiment used $y_{\rm sep}$ and identity parent outputs. All its rules shared the same forward model and retained direct cue inputs. Distractor stress amplified only the unselected streams: severity $s$ multiplies their latent features before exponential encoding ($s=1$ is ordinary testing). The selected features, cue and target stay fixed.

As in the single-neuron model, a conductance update combines local eligibility with a delivered learning signal. Each neuron $u$ receives its own somatic voltage error $\delta_u^V=\partial\mathcal L/\partial V_u$. For per-example loss $\mathcal L=(\widehat y-y)^2/(2\sigma_y^2)$, this is $w_u^{\rm out}(\widehat y-y)/\sigma_y^2$, where $\sigma_y^2$ is training-target variance; training averages gradients over each minibatch. Broadcast shares that error among compartments within the neuron. The resistance gate instead delivers $\delta_u^Vh_{up}$ to terminals of parent $p$, where $h_{up}$ is the parent's input resistance relative to its value without inhibition. This attenuation lies between zero and one and uses the actual conductance denominator, unlike the simpler continuous gate in Fig.~\ref{fig:conductancecredit}E. Proximal and somatic signals remain ungated. Wrong-branch gating cyclically permutes the four gains; the uniform root-mean-square (RMS) control preserves their norm but discards assignment. It does not equalize eligibility-weighted update norms.

Resistance gating helped most under strong distractors. Ordinary-test mean NMSE improved only about 1.7-fold, while stressed performance remained close to exact credit (Fig.~\ref{fig:conductancepopulation}B). The approximately 87-fold broadcast-to-gate error ratio used development-selected rates of 0.03 and 0.1, respectively. At common rate 0.1, the advantage was smaller but still 6.6-fold, with lower error in all twenty paired seeds (Supplementary Fig.~S22C). The robustness effect therefore persists under rate matching, but its magnitude depends strongly on rate selection.

Uniform attenuation and wrong-branch gains failed to reproduce this benefit. Replacing forward shunting with tonic inhibition or matched current injection also increased stress error under exact BP (Fig.~\ref{fig:conductancepopulation}B; Supplementary Fig.~S22C). Forward selection and selective learning thus contributed separately. At common archived checkpoints, correct gating strengthened terminal-gradient alignment with the matching context and reduced alignment with other contexts (Supplementary Fig.~S22D). Cross-context alignment was near zero on average, with either sign across seeds. These directional diagnostics do not establish harmful cross-context updates (Supplementary Table~S18).

The chain rule separates the information required at a terminal from its local eligibility. For an input log-conductance $\theta$ on terminal $i$ of neuron $u$, with $g=\exp\theta$, the exact gradient is $(\partial V_i/\partial\theta)\delta^V_{ui}$. Eligibility includes $\partial g/\partial\theta=g$; the delivered factor measures the terminal voltage's effect on loss. With identity terminal outputs and shunting inhibition, this factor is
\begin{equation}
\delta^V_{ui}=\delta^V_u\,\kappa_{ui}\,h_{up}\,f'_p(V_p),\qquad
h_{up}=\frac{D_{up}^0}{D_{up}^0+g_{up}^{\rm I}a_b^{\rm I}},\qquad
\kappa_{ui}=\frac{g_{p\to u}^{\rm den}g_{i\to p}^{\rm den}}{D_uD_{up}^0}.
\label{eq:populationtransport}
\end{equation}
Here terminal $i$ feeds parent $p$ assigned to stream $b$, and $p$ feeds soma $u$. The $g^{\rm den}$ terms are coupling conductances; $g_{up}^{\rm I}$ is maximal parent inhibitory conductance and $a_b^{\rm I}$ its cue-dependent activity. Leak is one, so $D_{up}^0=1+\sum_i g_{i\to p}^{\rm den}$ is the parent's conductance without inhibition and $D_u=1+\sum_p g_{p\to u}^{\rm den}$ the somatic denominator; each sum includes only that compartment's children. The three factors have distinct roles: $h_{up}$ supplies inhibitory attenuation; $f'_p(V_p)=\mathrm d f_p/\mathrm d V_p$ measures the slope of parent output $a_p=f_p(V_p)$; and $\kappa_{ui}$ contains the remaining coupling scales. At fixed weights, $\kappa_{ui}$ is constant across examples, although it changes during learning. Neuron indices on voltages and couplings are suppressed for readability. The rule key in Fig.~\ref{fig:conductancepopulation}A shows which factors each terminal signal retains.

For identity parents, $f'_p=1$, so resistance supplies all example dependence in this path multiplier. For $\tanh$ parents, the slope is $1-\tanh^2(V_p)$ and depends on the current inputs. Multiplying the gate by this slope restores the terminal gradient's exact example dependence, up to the positive terminal-specific scale $\kappa_{ui}$, including after minibatch averaging at fixed weights. We verified this identity to numerical precision at archived and initial states (Supplementary Section~S5). It concerns terminal input gradients, not all parameter blocks or optimizer trajectories. Incoming couplings and parent inhibitory conductances use parent-output eligibility, which already includes $f'_p$ once; their supplied signal remains ungated (Supplementary Table~S20).

Resistance gating failed when we added a within-stream interaction to the target and made parent outputs nonlinear. This comparison used $y_{\rm int}$ and replaced identity parent outputs with $\tanh$. The gate gave slightly higher mean ordinary-test error than broadcast, with the descriptive paired interval excluding zero; exact BP reached low error. Conductance bounds were contacted during training in 18/20 gate, 19/20 broadcast and 2/20 exact fits, although not necessarily at their selected states. A smaller graded-mixture pilot also failed and had a separate representational limitation (Supplementary Table~S14). Because the parent nonlinearity and target changed together, this comparison alone could not identify the source of failure.

We tested the missing slope while fixing the nonlinear task and forward model. Augmentation delivered $\delta_u^Vh_{up}f'_p(V_p)$; its control shuffled $f'_p$ across examples within each parent and context, preserving assignment and the distribution of slopes while breaking their input correspondence. In twenty new paired seeds with separately selected rates, augmentation reduced mean Adam NMSE from 0.0504 to $6.02\times10^{-5}$, approaching but not equaling exact BP. Shuffling retained a large error. Both predefined contrasts favored augmentation in every seed (Holm-adjusted $P=3.81\times10^{-6}$ each; Fig.~\ref{fig:conductancepopulation}C; Supplementary Table~S15).

The learned response surfaces show what the rescue changes. After removing the two single-feature contributions, the remaining interaction is weak under resistance gating and closely matches the target under augmentation (Fig.~\ref{fig:conductancepopulation}D). These surfaces average all twenty rescue seeds, with contexts aligned by target sign. The full responses and exact-credit reference are shown in Supplementary Fig.~S22E--H.

The rescue persisted at a common rate and with wider conductance bounds. Neither resistance nor augmentation contacted the bounds at its newly selected rate, so saturation cannot explain their difference. A complementary control retained the nonlinear parents but removed the target interaction. Resistance gating then reached low error close to augmentation at the same rate (Supplementary Fig.~S23B and Section~S5). The need for example-dependent parent sensitivity therefore depended on the target computation, not simply on whether the branches were nonlinear.

The target interaction also explains why a cue-only gate can miss useful information. A terminal's eligibility depends on its own feature. With independent symmetric features, averaging over the other feature cancels the target-interaction contribution to its expected update. The parent slope depends on both features and can prevent this cancellation. This argument concerns one component of the expected terminal update, rather than the full gradient or a guarantee of convergence (Supplementary Section~S5).

We next asked whether learning required a precise parent signal. In a separate twenty-seed cohort, two- or four-level sensitivity estimates and estimates from noisy parent voltages retained low error at a common rate (Fig.~\ref{fig:conductancepopulation}E). Shuffled and context-mean controls left large errors. The additional information therefore need not be an exact numerical derivative in this task; it must retain useful dependence on the current inputs. The full noise sweep and controls are in Supplementary Fig.~S23A and Section~S7.

A further twenty-seed cohort tested whether the inhibitory map could itself be learned. A small controller mapped the supplied cue to relative disinhibition, with direct terminal cue inputs removed in every routing condition. Both resistance and augmented rules learned to select the matching stream, but only augmentation reached low interaction-task error (Fig.~\ref{fig:conductancepopulation}F; Supplementary Fig.~S23C,D). Thus learning where to route the signal did not replace the need for parent sensitivity. Unlike the encoder in Fig.~\ref{fig:subtreefactorial}F, which learned supplied route-activation labels, this controller learned from task-derived somatic errors and parent-local eligibilities. Uniform routing removes cue information from the forward computation and serves as a forward-selection control. These tests retain Adam, fixed sensory grouping and supplied somatic errors; they do not test discovery of the contexts themselves.

Optimization remains a separate limitation. Under SGD, augmentation brought little improvement, but exact credit also remained inaccurate across an expanded rate and training-budget grid. That comparison therefore cannot identify a derivative-specific failure (Supplementary Table~S15 and Section~S5). Full-factor delivery matches BP algebraically; the successful approximate rule still assumes that terminals can access input-dependent information from the parent. The experiments test the usefulness of that information, not a biological mechanism for transmitting it.

\subsection*{Serial dendritic computation helps when nuisance information is distributed}

The selection and rescue comparisons held dendritic architecture fixed. Varying serial depth instead asks whether successive compartments help remove multiplicative nuisance gains. Physical depth $D_{\rm p}$ counts forward stages; feedback resolution counts backward distinctions.

DendriNet networks had 64 somata and eight nonsomatic compartments per soma. D1 $[8]$, D2 $[2,3]$ and D3 $[2,1,2]$ distributed them over one to three stages; a four-tier task added D4 $[1,1,2,2]$. The two-tier D2 tree used $[4,1]$. These designs retained 66,178 trainable parameters and 14,336 active synapses. A resource-identical grouped-point control connected all modules directly to the soma; raw-additive trees removed divisive normalization. Approximately parameter-matched point networks supplied a separate reference (Fig.~\ref{fig:physicaldepth}A).

Excitation carried class information multiplied by nuisance gains: $x_{\rm E}=\max\{b_{\rm E}+y\Delta+\epsilon_{\rm E},10^{-4}\}\prod_\ell\exp(\sigma_\ell z_\ell-\tfrac12\sigma_\ell^2)$, with independent standard Gaussian $z_\ell$, $\Delta=0.80$ and $\sigma_\ell=0.25$. Here $b_{\rm E}$ is baseline excitation, $\epsilon_{\rm E}$ is additive input noise and $y\in\{0,1\}$ is the class. Inhibitory sensors used $s_\ell(\alpha)=\alpha z_\ell+\sqrt{1-\alpha^2}\xi_\ell$, with independent standard Gaussian $\xi_\ell$: zero fidelity preserved sensor distributions but removed trial-specific information; one reported the factor exactly. With inhibitory reversal zero, sensors could support successive divisions \citep{carandini2012normalization}. Nested gains acted on fine, coarse and global groups; flat gains had equal-resolution supports; local-ratio tasks placed all required information within each module (Fig.~\ref{fig:physicaldepth}B). The families differ in spatial support, not whether multiplication commutes. Supplementary Section~S8 specifies generators and the development-selected operating point.

Serial integration helped when the information needed to remove nuisance gains was spread across modules. With informative sensors and exact BP, the serial tree exceeded the grouped-point control by about 30 accuracy points for nested gains and 22 for flat gains. The advantage disappeared when sensors lost their trial-specific information, and was exactly zero when each module already had all information needed for a local ratio (Fig.~\ref{fig:physicaldepth}C). On the nested task, accuracy rose from about 61\% with one stage to 92\% with three, while grouped and reversed controls remained near the shallow result. An approximately matched point network reached 99\%, and adding a fourth serial stage did not improve the four-tier task (Fig.~\ref{fig:physicaldepth}D; Supplementary Figs.~S24--S26). Serial stages helped under specific information constraints, rather than providing a general architectural advantage.

The benefit of serial computation did not determine which credit rule ultimately performed best. We reran six configurations with a 600-epoch budget in ten paired seeds, retaining their original optimizer settings and validation-based stopping rule. The advantage of three stages over one persisted and increased. Most shallow fits stopped early, while every three-stage fit reached the longer budget with validation loss still decreasing (Fig.~\ref{fig:physicaldepth}E,F). Thus neither the original nor the extended endpoint should be interpreted as convergence for the deeper models.

Within the three-stage LocalCA models, exact paths initially gave higher accuracy than a shared somatic signal, but the ordering reversed with longer training in all ten seeds. Exact-path LocalCA nevertheless retained lower cross-entropy (Fig.~\ref{fig:physicaldepth}G,H). The accuracy reversal therefore did not mean that its predictions were worse under every loss measure.

Optimizer matching was consequential. BP and LocalCA used different base rates and parameter groups, with clipping, decay and masks otherwise matched. At 180 epochs, changing the broadcast optimizer recipe changed accuracy by 13.47 percentage points; implementing broadcast through autograd or LocalCA under the same recipe gave nearly identical results (difference $-0.06$ points; 95\% paired interval, $-0.23$ to 0.09; Supplementary Fig.~S26C). Exact credit retained a small accuracy advantage over broadcast under the BP recipe at the extended endpoint. These controls separate a forward-computation benefit from claims about the best credit rule, which depend on optimizer settings, training duration and outcome measure.

\subsection*{Reconstructed arbors provide spatial routes beyond a shared broadcast}

The learning tasks motivate asking which delivery patterns real arbors supply. MICrONS combines mouse visual-cortex anatomy, calcium-imaging responses and mapped synaptic partners \citep{microns2025}. Observed geometry defines soma-rooted ancestry; conductances, voltages and gradient fields are modeled.

Each inhibitory-bearing segment supplied a candidate route over its input-bearing descendants (Fig.~\ref{fig:topology}A,B). Focal shunts generated signed fields $t_i=d_{\rm sh}^{-1}\log[(|\gamma_i'|+\epsilon)/(|\gamma_i|+\epsilon)]$, where $\gamma_i,\gamma_i'$ are open excitatory-conductance sensitivities before and after intervention and $d_{\rm sh}=0.001$ is dose relative to local leak-plus-synaptic conductance. For route matrix $A_K$, diagonal excitatory-area weights $W$ and weighted least-squares projector $P_{A_K,W}$,
\begin{equation}
\mathcal C(A_K;\bm t)=\frac{\|P_{A_K,W}\bm t\|_W^2}{\|\bm t\|_W^2},\qquad
\|\bm v\|_W^2=\bm v^{\mathsf T}W\bm v.
\label{eq:reconstructioncapture}
\end{equation}
Ensemble capture sums energies over perturbations. A common-constrained singular-value-decomposition dictionary supplies a rank-budget ceiling. Random anatomical routes, depth bins, density-preserving shuffles and degree--depth surrogate trees control spatial organization (Fig.~\ref{fig:topology}C).

These passive fields favor ancestry under somatic loss by construction. The test measures compression of the tree's own responses, not observed teaching. Broadcast alone captured 31.4\% in the initial eight cells, near the 32.6\% rank-one ceiling. Every dictionary therefore included broadcast plus $K-1$ spatial profiles, fixed before testing 47 disjoint cells from the same mouse and a second-mouse cohort. For each cell, spatial share is $C-C_0$ and residual capture is $C_{\rm res}=(C-C_0)/(1-C_0)$, where $C_0$ is broadcast capture. We calculate these within each cell before averaging across cells.

Adding spatial profiles captured substantial structure beyond broadcast. With eight profiles in the 47-cell cohort, ancestry captured about 62\% of field energy, compared with 20\% for broadcast alone (Fig.~\ref{fig:topology}D,E). However, surrogate trees preserving degree and depth captured much of the same structure. Ancestry exceeded each cell's surrogate mean in 38 cells, yet in eleven cells at least half the surrogate trees matched or exceeded the real arbor (Fig.~\ref{fig:topology}F). Its mean surplus over surrogates was only 0.041 of total field energy (95\% cell-bootstrap interval, 0.020--0.062). Larger advantages over depth bins and shuffled routes establish the value of spatial structure, while the modest surrogate contrast limits what can be attributed to the specific reconstructed anatomy (Fig.~\ref{fig:topology}G).

Ancestry achieved this capture with fewer than one fifth of the nonzero entries required by a dense dictionary. Shuffled routes retained the same sparsity but captured less, so sparsity alone did not explain the result. Nonzero-entry fraction is a computational delivery-cost proxy, not a measure of anatomy or metabolic expenditure. Equal numbers of columns also need not provide equal rank.

The ancestry--surrogate--depth ordering held in the initial cohort and eight eligible Pinky cells from a second mouse (Fig.~\ref{fig:topology}H). Pinky's smaller arbors approach the residual-capture ceiling; lower-budget outcomes and exclusions remain separate. Labeling, geometry and compression controls are in Supplementary Figs.~S27--S30. After matching locations jointly in three-dimensional space and along the arbor, none of the tested inhibitory-targeting measures showed a reliable difference, and the initial anatomy-specific coarse-energy excess did not replicate in the 47-cell cohort. These constraints limit the anatomical specificity of the modeled advantage.

\subsection*{Focal shunts rescale spatial sensitivity according to branching structure}

A focal shunt links anatomical routes to conductance-dependent gains. In reconstructed reciprocal cables, we compared inhibition with an injection matching its baseline focal current, plus a separately solved somatic current restoring baseline somatic voltage (Fig.~\ref{fig:focal}A).

Let $G$ be the symmetric passive conductance matrix, $\bm b$ the current-source vector and $\bm e_k$ the unit vector at site $k$. Baseline voltages satisfy $G\bm V=\bm b$. Adding conductance $\kappa_k$ at site $k$ changes $G$ to $G+\kappa_k\bm e_k\bm e_k^{\mathsf T}$ and the source to $\bm b+\kappa_kE_{\rm I}\bm e_k$; matched injection supplies $\kappa_k(E_{\rm I}-V_k)$ without changing $G$. The adjoint $\bm q=G^{-\mathsf T}\nabla_{\bm V}\mathcal L$ measures loss sensitivity to injected current, distinct from local voltage credit or the scalar-tree path vector. For fixed somatic loss derivative,
\begin{equation}
\bm q'=\bm q-\frac{\kappa_kq_k}{1+\kappa_k(G^{-1})_{kk}}G^{-1}\bm e_k.
\label{eq:sherman}
\end{equation}
Here $G^{-1}\bm e_k$ is the voltage response to unit current at $k$, and $(G^{-1})_{kk}$ is driving-point resistance. All descendants share attenuation $[1+\kappa_k(G^{-1})_{kk}]^{-1}$; sister blocks along the soma path and the soma-side remainder each share another factor. Baseline-transfer-weighted indicators of these disjoint ancestry blocks form a dictionary on which the shunt acts through diagonal gains $\Gamma_u$ (Fig.~\ref{fig:focal}B). This identity need not hold in an arbitrary overlapping route dictionary.

The sensitivity to open excitatory conductance is $\gamma_i=q_id_i$, with driving force $d_i=E_{\rm E}-V_i$, which can vary within a block. Sensitivity to maximal conductance additionally includes presynaptic activity $x_i$. In the small-dose fields of Fig.~\ref{fig:topology}, driving-force and adjoint terms strongly opposed one another, yet 97.1--99.9\% of full-field energy remained within the focal ancestry partitions (Supplementary Section~S10).

We measured absolute log gradient change $m_i=|\log[(|\gamma_i'|+\epsilon_\gamma)/(|\gamma_i|+\epsilon_\gamma)]|$, and localization $\Lambda_k=\operatorname{median}_{D(k)}m_i-\operatorname{median}_{C(k)}m_i$ between descendants $D(k)$ and depth-matched off-route sites $C(k)$. In the permissive normalized model, shunt localization increased with dose, while injection changed descendant gradients roughly threefold less (Fig.~\ref{fig:focal}C,D). Injection's unrelated-site changes were zero under the soma-restoring construction, not in general.

To separate transport from local voltage effects, we replaced the adjoint while holding the post-shunt driving force fixed: $\Delta\Lambda_k=\Lambda_k(\bm q'\odot\bm d')-\Lambda_k(\bm q\odot\bm d')$, with both localizations measured relative to the same baseline. Including the changed adjoint increased localization in all eight cells, whereas changing the driving force alone accounted for a smaller part of the full effect (Fig.~\ref{fig:focal}E). The shunt therefore changes how local perturbations influence the soma, as well as changing their local driving force.

The strong localization in the normalized model did not persist across physical cable parameters. At $R_a=150\,\Omega\,\mathrm{cm}$ and $R_m=15{,}000\,\Omega\,\mathrm{cm}^2$, shunt-minus-injection localization was close to zero and had opposite signs in the initial and disjoint cohorts. Shunts attenuated gradients both below the inhibited site and elsewhere; lower membrane resistance increased descendant attenuation, whereas matched injection enhanced gradients (Fig.~\ref{fig:focal}F,G). Adding background conductance restored preferential descendant effects at high membrane resistance, consistently across the initial eight cells (Fig.~\ref{fig:focal}H). Spatial selectivity therefore depends on the cable's conductance state, rather than following from branch geometry alone \citep{chance2002gain,destexhe2003highconductance}.

Fixed-absolute, relative-local and input-normalized dose controls remain in Supplementary Fig.~S31A. Weak voltage-dependent currents gave similar responses around the tested steady states, but their baseline Jacobian was fixed across doses; this does not establish robustness to strongly active dendrites or channel kinetics (Supplementary Fig.~S32D,E). The ancestry identity supplies a modeled transport mechanism \citep{gidon2012inhibition}, not evidence that these routes carry endogenous errors.

\subsection*{Measured responses show no detected ancestry alignment}

Measured responses test whether functional relationships follow the ancestry structure suggested by modeled capacity and transport. Here a target is a postsynaptic neuron, and its partners are presynaptic neurons mapped onto that arbor. Seven MICrONS targets had complete arbors and imaged partners: 69 partners in the selected-scan dataset and thirteen eligible scans in the scan-complete analysis. These recordings sampled stimulus responses rather than a learning assay; no teaching signal was experimentally imposed or measured (Fig.~\ref{fig:boundary}A).

Functional similarity was the correlation between partners' mean fluorescence responses across repeated stimulus conditions. Shared ancestry was the fraction of their soma-to-contact paths held in common. We then asked whether the two were associated after removing effects of Euclidean separation and differences in soma-to-contact path length, using partial rank correlation. Partners with more shared ancestry did not have reliably more similar responses (Fig.~\ref{fig:boundary}B). The mean estimate was slightly negative, and its target-bootstrap interval included zero. Reanalyzing all eligible scans from the same seven targets, or using raw shared path, tree distance or membership in the same major branch, gave the same qualitative conclusion (Fig.~\ref{fig:boundary}C; Supplementary Fig.~S33). This provides no evidence of preferential ancestry alignment among the sampled partners; it tests a different scale from population-level like-to-like wiring \citep{ding2025wiring}.

We assessed which effects this small cohort could detect using response simulations that preserved partners, shared inputs, repeated stimuli and seven-target inference. Noise followed measured repeat reliabilities, with negative estimates assigned zero reliable variance. Under the specified Gaussian ancestry-signal model, 80\% detection required a mean observed partial rank correlation near 0.25; the measured estimate and its interval fell below that point (Fig.~\ref{fig:boundary}D). Perfect reliability gave a similar observed-correlation threshold but required much less underlying ancestry-aligned tuning variance. Recording noise thus made underlying alignment harder to detect. These model-conditional thresholds leave weaker effects, different signal geometries and unobserved partners unresolved (Methods; Supplementary Section~S11).

A separate passive-tree model predicted each target's responses from its recorded partners. The selected ancestry routes reached only about half the mapped inputs; in six of thirteen scans, every route reached just one input (Fig.~\ref{fig:boundary}E,F). With so little grouping, the comparison mainly tests a nearly fixed transfer pattern rather than rich example-dependent credit. The ancestry-restricted rule showed no reliable predictive advantage over ridge regression and performed similarly to random anatomical routes (Supplementary Figs.~S33--S34). There was also no measured positive control demonstrating ancestry-aligned teaching. This model diagnostic and the direct response-similarity test constrain different parts of the anatomical proposal.

\section*{Discussion}

Learning benefits from spatial selection when a common signal mixes incompatible weight changes. Dendritic morphology supplies candidate delivery patterns, teaching mechanisms supply their coefficients, and conductance regulates their gains. Image classification benefited mainly from preserving neuronal identity; branch selection became useful with conflicting inputs. A dendrite's computational complexity alone therefore does not determine the spatial resolution of credit it needs.

The routing tasks distinguish having useful delivery patterns from activating them correctly. Hierarchical distractors favor ancestry at intermediate resolution when routes group inputs relevant to the same context. Cue decoding and weak delivery to incompatible routes impose additional limits (Fig.~\ref{fig:subtreefactorial}F). More calibration data reduced soft leakage; hard selection removed it while retaining a noisy-cue deficit. Exact paths and projected coefficients are idealized controls with information unavailable to restricted learners. Representing a useful signal does not explain how its coefficients are computed.

Average input sensitivity also fails to predict credit requirements. Pairwise and quartic targets share a spectrum and a compatible tree, yet pairwise learning mainly changes the amplitude of one spatial credit pattern, while higher-order learning changes the pattern itself. Uniform broadcast can miss even the first case when the useful direction is nonuniform and signed. An initialization-based selector performed worse than a fixed maximum-budget tree in every seed average (Supplementary Fig.~S35). The trained-state observations therefore do not validate initialization-based selection. Separately, the scalar-tree representability criterion connects input grouping to hierarchical tensor representations and supports structure estimation from noisy examples \citep{hackbusch2009tensor,grasedyck2010hierarchical,cohen2016tensor}. Representational limits must be distinguished from learning-rule failure.

Conductance trees provide a mechanism for locally available selection. In the seven-compartment neuron, a distal inhibitory gate supports opposing branch tuning without oracle path coefficients, provided proximal updates remain ungated. Cortical circuits select task-relevant sensory evidence, and earlier dendritic-disinhibition models connect pathway selection to plasticity \citep{mante2013context,yang2016gating}. Calcium- and reward-dependent plasticity, together with inhibitory plasticity, can also support nonlinear feature binding in a detailed striatal neuron \citep{khodadadi2025binding}. Our population experiment asks a narrower question by changing credit delivery at fixed forward computation: which spatial factors must a supplied learning signal retain? Correctly assigned resistance gates improve distractor robustness, with benefits depending strongly on stress and learning rate; uniform or wrong-branch attenuation does not reproduce them. Replacing forward shunting remains costly even with exact credit. Forward input selection and spatially selective learning therefore contribute separately in this task.

The nonlinear rescue identifies when parent sensitivity matters. Resistance gating reaches low error on the separable target despite nonlinear parents; the added interaction exposes a large deficit. Supplying the parent slope matched to the current example rescues learning with Adam, whereas shuffling slopes within the same branch and context does not. Branch selection and response sensitivity therefore provide different information. The smaller SGD benefit is difficult to interpret because exact SGD also remained inaccurate. Learning-rate schedules, conductance parameterization and update scaling may all influence convergence.

The additional population tests relax two assumptions of the original rescue. Coarse or noisy parent-state estimates retain useful input dependence, and a small shared controller learns the cue-to-inhibition map without route labels. These results do not identify a biological carrier for parent-to-terminal feedback or establish a distributed inhibitory circuit. The models still receive explicit context and neuron-specific somatic errors, retain fixed sensory grouping and use Adam. Temporal and recurrent learning remain open extensions. Separately, serial compartments help remove distributed nuisance gains, but the LocalCA accuracy ranking reverses with longer training while exact paths retain lower cross-entropy. Forward computation, credit information and optimization require separate assessment.

Reconstructed arbors provide a complementary test of what spatial patterns are available. Their ancestry routes represent modeled passive sensitivity changes more efficiently than a common broadcast, but degree- and depth-matched surrogate trees explain much of that capacity. Moreover, the modeled fields favor ancestry because they arise from passive transport to the soma. Evidence beyond this construction would require measured learning-related fields or models with different error sources or active dynamics. Focal shunting supplies a concrete link: in the passive model it rescales sensitivity by ancestry-defined blocks. Changes in driving force partly oppose those transport effects, and the cable's conductance state determines how selectively they affect descendants. This concerns how inhibition changes sensitivity to a supplied loss, a different role from computing errors or regulating forward integration \citep{rossbroich2023disinhibitory,galloni2026cellular,greedy2026celltype,safaai2026gainload}.

The small recorded cohort provided no evidence of preferential ancestry alignment; its offline learning diagnostic chiefly tests an almost fixed transfer profile. A direct experiment would compare plasticity below a focal inhibitory site with electrotonically matched off-route sites while matching somatic voltage, first-order current and outcome signal. Changing conductance state would test the predicted separation between shared and ancestry-selective effects \citep{francioni2026vectorized,cichon2015branch,bloss2016structured}. The anatomical calculations motivate this test but do not establish that the modeled routes carry endogenous teaching signals.

The framework complements somatic prediction, segregated teaching, interneuron-mediated errors and burst plasticity \citep{urbanczik2014dendritic,guerguiev2017segregated,sacramento2018dendritic,payeur2021burst}, alongside cable-learning and engineered gating models \citep{bicknell2021synaptic,chavlis2025dendrites,sezener2021gated,iyer2022activedendrites,lv2025dendritic}. Spikes, temporal eligibility, recurrence and channel kinetics may change both the available profiles and the way their coefficients are estimated \citep{bittner2017btsp,magee2020plasticity}. The organizing question is which task-relevant distinctions the arbor and learning mechanism can jointly preserve.

\subsection*{Model classes and biological evidence}

Directed conductance trees, feedback-only hierarchies, scalar computational trees and reciprocal reconstructed cables serve the distinct purposes introduced in Results. MICrONS responses are measured; their learning fields are modeled or imposed. None of these analyses records endogenous dendritic error delivery.



\subsection*{Conductance models and delivery coordinates}

In a directed tree, $[b_1,\ldots,b_D]$ lists branching factors from soma to tips, giving $\sum_{d=1}^D\prod_{r=1}^db_r$ nonsomatic compartments. Equation~\ref{eq:directedvoltage} specifies the forward steady state. Artificial conductance trees use dimensionless leak one and reversals $E_{\rm L}=E_{\rm I}=0$, $E_{\rm E}=1$. Monotone parameter transforms enforce nonnegative conductances. Branch-output nonlinearities, termed reactivations in the implementation, are identity functions when disabled.

For a reciprocal cable residual $\bm F(\bm V,\bm g,\bm x)=0$, the nonsingular voltage Jacobian $J_V$ gives the adjoint
\begin{equation}
J_V^{\mathsf T}\bm q=\nabla_{\bm V}\mathcal L,
\qquad \partial\mathcal L/\partial g_i=-\bm q^{\mathsf T}\partial\bm F/\partial g_i.
\label{eq:generaladjoint}
\end{equation}
For passive current balance, $\bm F=G\bm V-\bm b$ fixes the residual sign, and the synaptic gradient is $x_i(E_i^{\rm rev}-V_n)q_n$. This calculation supplies the reference \citep{almeida1987asynchronous,pineda1987recurrent,schiess2016somatodendritic,bicknell2021synaptic}. For output $a_n=f_n(V_n)$, activation error $\delta^a_n=\partial\mathcal L/\partial a_n$ gives voltage error $\delta^V_n=f_n'(V_n)\delta^a_n$. Image LocalCA replaces $\delta^a_n$ while retaining $f_n'$ and exact local gate derivatives in eligibility. Fixed activation-space profiles can therefore vary in voltage space; exact supplied fields recover exact selected gradients.

The raw-additive control retains the graph but sums signed inputs without the conductance denominator or reversal-potential driving force. Normalized-additive controls additionally standardize voltage across stage coordinates within each example; Supplementary Section~S2 defines those variants. Additional preconditioners are defined in Supplementary Section~S1.

Nonzero diagonal gains in $A\Gamma$ preserve span while changing conditioning (Supplementary Fig.~S5).

\subsection*{Image feedback ladders and checkpoint diagnostics}

The decoder supplies neuronal activation errors. Strict scalar feedback shares their mean, substituting the largest-magnitude signed coordinate when the mean's magnitude is at most $10^{-6}$. Per-neuron feedback preserves neuronal identity. The historical scalar fallback retained that identity at the soma-width stage (640 of 2,413,312 core parameters); the separate strict-scalar control removes this exception.

MNIST networks use 128 $[3,3]$ trees with 40 excitatory and 20 inhibitory contacts per nonsomatic compartment. Rules share initialization and data streams within architecture. Pixels are flattened and divided by 255. Seed-specific splits contain 48,000 training and 12,000 validation images, with the official 10,000-image test set held out. Adam trains for 180 epochs with batches of 256, standard moment coefficients, no decay and validation-minimum checkpoint selection. Original synapse/decoder, coupling and gate rates are 0.0015, 0.0007 and 0.0005. Three development seeds select multipliers 0.3, 1 or 3 using validation alone; ten fresh seeds compare selected and original common rates (190 unique fits).

Projected $K=1,3$ rules average exact activation errors over the specified supports; decoder-only controls freeze the core. Capture uses 2,048 held-out images at initial and exact-trained states, with activation and voltage coordinates kept separate. Exact transport is checked against automatic differentiation.

\subsection*{Contextual conflict and ancestry routing}

The branch-conflict study crosses twenty paired seeds, three branch counts and eight opposite-class replacement probabilities. Equations~\ref{eq:branchconflictforward}--\ref{eq:branchconflictupdates} define the classifier and updates. BP and gated-point controls are equivalent; derangement changes recipients. Initialization utility is $\langle\bm d^{\rm shared},\bm d^{\rm selected}\rangle/\|\bm d^{\rm selected}\|^2$, distinct from nonnegative one-step utility below. Trained chance crossings use interpolation and each seed's first sampled crossing, retaining non-crossings. The separate ten-seed interference task trains both contexts for sixty epochs, then context 1 for twelve, measuring context-0 accuracy loss on 1,024 held-out examples.

The ancestry factorial has eight eight-dimensional blocks with balanced contexts and labels. Inputs combine unit teacher directions, Gaussian noise of SD 1.1 and context-relative coefficients $1,-0.15,-0.45,-0.75$. Unit-norm ancestry rows obey $\Phi^{(K)}_{cb}=\sqrt{K/8}\,\mathbf1[g_K(\pi(c))=g_K(b)]$, where $\pi$ permutes leaves and $g_K$ identifies contiguous groups. Updates are $\Delta\bm w_b=-(8\eta/N)\sum_i\delta_i\Phi^{(K)}_{c_ib}\bm x_{i,\pi^{-1}(b)}$. Each seed supplies 2,048 training, 2,048 test and 1,024 switch examples; full-batch descent uses rate 0.3, eighty training and twenty switch epochs.

The best matched control is each seed's maximum among four non-PCA controls. Integer correct counts preserve signed-rank ties; Holm adjustment covers four budgets. Generator, encoder, cue-delay and checkpoint-replay details are in Supplementary Section~S3; historical alternative tests remain labeled separately.



\subsection*{Update utility and prospective selection}

Let the exact gradient be $\bm\mu$ and the delivered update estimator have mean $\bm m$ and covariance $\Sigma_{\rm route}$ at the current weights. Here smoothness $L$ bounds how fast the loss gradient changes, $[z]_+=\max(z,0)$, and covariance is over the stated update randomness. For an $L$-smooth loss and a nonnegative step $\eta$, expected loss after the update is bounded above by $\mathcal L-\eta\bm\mu^{\mathsf T}\bm m+(L\eta^2/2)(\|\bm m\|^2+\operatorname{tr}\Sigma_{\rm route})$. Optimizing this expression gives utility $U=[\bm\mu^{\mathsf T}\bm m]_+^2/[2L(\|\bm m\|^2+\operatorname{tr}\Sigma_{\rm route})]$, with zero for a zero denominator. Utility certifies one-step progress under the stated moments; it is not a long-horizon ordering.

Synthetic quadratic screens use sixteen Haar coordinates and a designed signal/noise crossover, without a forward neuron (Supplementary Fig.~S3). Retrospective factorial utility uses actual full-batch updates and a global logistic-curvature bound; maximum bandwidth matches its selection success. Supplementary Figs.~S35--S36 report the failed prospective selector and its finite-horizon extension, including evolving noise and observed-context-count controls. Supplementary Table~S12 indexes the complete outcomes, frozen choices and computational costs.

\subsection*{Interaction compatibility, fixed profiles and learned spectra}

For subtree leaf set $S$, the Fourier coefficient matrix $C_S$ indexes inside and outside input products. Removing its constant inside row gives $C_S^\circ$. A scalar multi-affine tree is compatible exactly when every centered cut has rank at most one. With proper cuts $\mathcal S(T)$,
\begin{equation}
\operatorname{MSE}(f,\widehat f_T)\geq B(T;f):=\max_{S\in\mathcal S(T)}\sum_{j\geq2}\sigma_j(C_S^\circ)^2.
\label{eq:morphologyselection}
\end{equation}
Overlapping cut tails cannot be summed. Supplementary Section~S4 gives the constructive proof, minimum-depth algorithm, candidate census and noisy-query estimator. These assumptions do not automatically extend to conductance ancestors.

Three development seeds select rates; twenty fresh blocks pair tasks, trees, initialization, inputs, noise and minibatches. Exact, unit, calibrated and sign-only profiles share eligibilities. Calibration averages path derivatives on 256 unlabeled examples. SGD/Adam comparisons use selected and common rates, with coefficients bounded to $[-2,2]$. The balanced extension continues verified original checkpoints to 16,384 updates. Original noise variance is 0.0225; NMSE divides by clean variance, one for pairwise/nested and one-half for quartic.

The new noise sensitivity analysis uses twenty additional paired seeds, the inherited Adam rates, unchanged clipping/bounds and three noise conditions. Training lasts 16,384 updates; the primary contrast uses exact clean-domain NMSE over all 256 inputs. Supplementary Section~S4 provides the complete outcomes and independent endpoint checks.

For example-by-site path matrix $Q$, rank-one capture is $\sigma_1(Q)^2/\sum_j\sigma_j(Q)^2$. It permits oracle example-dependent amplitudes. Loss-weighted, eligibility-weighted and site-normalized diagnostics, relabeling controls and replay of 600 earlier fits are retained separately.



\subsection*{Conductance trees with context-dependent feature tuning}

Teacher and student share a seven-compartment directed circuit with identity outputs and 24 plastic E/I/coupling conductances. Paired rules share inputs and initial states. Aligned/opposed targets change the teacher's feature tuning while preserving representability.

\subsection*{Sensory selection and inhibitory credit in DendriNet}

Sixteen $[4,2]$ neurons receive four independent two-feature streams, encoded as $\exp(\pm z)$, and excitatory cue channels. Cue-selected targets and proximal inhibition are defined in Results. Tonic inhibition has activity three; the current control fixes its matching voltage at initialization. Forward controls preserve context access and all 1,297 active trainable parameters. Training minimizes half MSE divided by training-target variance; evaluation NMSE uses the variance of the evaluated split.

Relative-resistance, wrong-branch and uniform-RMS rules differ only in terminal delivery. Terminal log-conductances differentiate identity output $V_i$ and receive $\delta_u^V$ times $1$, $h$ or $hf'_p$, omitting $\kappa_{ui}$. Terminal-to-parent couplings and proximal inhibitory conductances differentiate $a_p=f_p(V_p)$: their eligibility includes $f'_p$ once, while supplied $\delta_u^V$ omits $g_{p\to u}^{\rm den}/D_u$. Parent-to-soma couplings and readout use exact local derivatives. All log-conductance eligibilities include $\partial g/\partial\theta=g$; incoming child outputs and supplied signals are detached. Supplementary Table~S20 lists the blocks. Tonic/current controls retain the cue-derived shunting gate as a counterfactual backward signal, not their actual resistance ratio. Three development seeds select Adam rates 0.01, 0.03 or 0.1; twenty fresh seeds yield 400 training trajectories for 4,096 updates. Validation alone chooses checkpoints. The two primary severity-three broadcast/RMS contrasts against resistance use Holm-adjusted paired sign-flip tests (Supplementary Table~S14).

The nonlinear rescue fixes the $\tanh$ parents and interaction target. It adds $hf'$, within-parent/context example shuffling and an algebraically exact full-factor diagnostic. Three development seeds tune Adam and SGD separately; twenty new seeds evaluate original and wider bounds (320 trajectories), followed by sixty additional common-rate trajectories on the same seed blocks. Two original-bound Adam contrasts, resistance-minus-augmented and shuffled-minus-augmented ordinary error, define the Holm family. Bound occupancy and interaction-gradient diagnostics never select settings. A further 100 same-seed trajectories keep nonlinear parents but remove target interactions at common Adam rate 0.03.

The archived context matrix compares delivered and exact gradients at identical selected states for all 400 original checkpoints, separately for terminal, proximal, somatic and readout parameters. Cosines compare context-averaged raw log-conductance gradients (ordinary readout coordinates), using one pooled diagnostic target variance. Four matching-context or twelve cross-context entries are averaged within each seed before inference. This is a descriptive first-order diagnostic, not an Adam-step or continual-learning test. Supplementary Section~S5 retains all protocols and outcomes.



The approximate-sensitivity study replaced only the terminal parent-slope factor with quantized or noisy estimates, leaving forward voltages unchanged. A separate shared $4\times4$ controller mapped the supplied context cue to normalized disinhibition, with direct terminal cue inputs removed. Its update summed parent-local eligibilities weighted by supplied somatic errors, without desired-route labels or exact downstream coupling factors. Each study used separate development seeds and twenty paired evaluation seeds (Supplementary Section~S7).

\subsection*{Focal shunting and the electrotonic boundary}

Up to sixteen sites per cell span depth quartiles, each with at least three excitatory descendants and comparison sites. Excitatory/inhibitory area-scaled conductances use factors 0.35 and reversals one/$-0.2$. Doses are 0.25, 0.5, one and two times local leak-plus-synaptic conductance. Finite differences check adjoint gradients.

Sweeps span $R_a=100,150,250\,\Omega\,\mathrm{cm}$, $R_m=300$--$30,000\,\Omega\,\mathrm{cm}^2$, several dose normalizations and background conductance; the disjoint cohort has 235 sites in 45 cells. \subsection*{Measured-response prediction and geometric diagnostics}

The seven-target cohort includes thirteen eligible scans. Offline learning holds out stimulus identities. Training-only percentile transforms produce nonnegative presynaptic proxies, and each partner enters at its dominant mapped contact segment. A linear somatic readout predicts the standardized target response. Only input-conductance credit differs across rules; readout and bias gradients remain exact.

Four-route dictionaries are selected without target responses and receive the projected baseline transfer profile multiplied by the scalar readout error. Supplementary Section~S11 defines delivery and reconstruction. Fig.~\ref{fig:boundary}E shows supports reconstructed from saved segment identifiers for the median-input-count scan, with identifier-based tie breaking; Supplementary Fig.~S33B summarizes all scans.
