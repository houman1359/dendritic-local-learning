\begin{abstract}
Learning changes the weights of a neural network to improve an objective.
Credit assignment asks which weights should change and by how much.
Backpropagation computes exact gradients, but uses backward information not
locally available to each weight. For a point-neuron network,
the gradient of each incoming weight factorizes into a weight-specific
eligibility and a neuron-specific learning signal. We extend this result to
conductance-based dendritic trees, where synaptic weights are conductances
distributed across compartments. Each gradient combines local eligibility with
a compartment-specific error transported through the arbor, separating neuron
identity, dendritic address and conductance-dependent route gain. We represent
restricted feedback as a credit operator mapping gradients to local updates; a
stochastic bound predicts when it preserves aligned signal while rejecting
noise. On image tasks, neuron-specific feedback explains most of the
improvement from scalar feedback to exact path transport; path resolution adds
little. In a controlled branch-conflict task, branch-specific feedback helps
when branches require opposing updates. In mechanism-matched tasks, serial
depth helps only when its nonlinear operations match task structure.
Reconstructed arbors provide sparse candidate routes, but a one-mouse MICrONS
visual-response cohort reveals no preferential alignment with them.
Dendritic structure therefore supports local credit assignment under matched
conditions rather than replacing backpropagation.
\end{abstract}

\section*{Introduction}

Learning in a neural network adjusts its parameters to improve an objective.
Most parameters are weights that set the strengths of connections between
units. Because the objective is evaluated at the output, an internal weight
acts through downstream computations before its consequence is known.
\emph{Credit assignment} determines how changing each weight would affect the
objective and therefore how it should be updated.

For a differentiable network, backpropagation applies the chain rule backward
to compute the exact gradient of every weight \citep{rumelhart1986learning}. In
recurrent or steady-state networks, the same calculation can be written as an
adjoint system \citep{almeida1987asynchronous,pineda1987recurrent}. These
calculations define the required information, not a biological mechanism.
Local activity does not determine this gradient, which also depends on
downstream weights, nonlinearities and the objective.
A biological rule must combine locally available information with a limited
signal carrying this downstream consequence
\citep{whittington2019theories,lillicrap2020backprop}.

The point-neuron abstraction exposes this separation. A point unit combines
weighted inputs into one state and produces one output. Each incoming-weight
gradient factorizes into a connection-specific \emph{eligibility}, determined
by the input and local state, and a task-dependent \emph{learning signal}
assigned to the unit. Biologically, such a weight represents synaptic efficacy.
Hebbian plasticity describes the local association between pre- and
postsynaptic variables \citep{hebb1949organization}; three-factor rules add an
outcome-dependent signal \citep{fremaux2016threefactor}. We call this
task-dependent factor a \emph{learning signal}. Backpropagation supplies its
exact value, whereas a candidate biological mechanism supplies an available
approximation. A rule is \emph{local} here when a weight uses its own
eligibility and an available learning signal; that signal may still depend on
the network-wide objective.

Biologically motivated theories differ in how they construct and communicate
learning signals. Feedback alignment uses a separate feedback pathway
\citep{lillicrap2016feedback,nokland2016dfa}; equilibrium, predictive and
prospective methods infer errors or target states from network dynamics
\citep{scellier2017equilibrium,whittington2017predictive,
song2024prospective}; and eligibility propagation combines synaptic traces with
neuron-specific signals \citep{bellec2020eprop}. Despite these mechanistic
differences, feedback can assign independent task-dependent factors only to
units that it addresses separately. A scalar broadcast cannot specify
independent task-dependent factors for different units, whereas one signal per
unit can \citep{werfel2005learning,lillicrap2016feedback}. A shared scalar does
not equalize weights: each retains its own eligibility, while only the
task-dependent factor is shared. \emph{Feedback bandwidth} is the number of
independently communicated signals at a given routing level, across neurons or
across locations within one neuron.

A point-neuron model collapses a cell to one state and one learning signal. A
biological neuron instead receives thousands of synaptic inputs across a
branching dendritic arbor. Cable filtering, nonlinear integration and spatially
organized inhibition make dendritic locations functionally distinct
\citep{rall1962dendrites,koch1999biophysics,
poirazi2003pyramidal,london2005dendritic,spruston2008pyramidal,
branco2010single,larkum2013cellular}. Once feedback selects a neuron, must it
also distinguish locations within that neuron? We call the set of locations
reached by one signal a \emph{dendritic address}. A branch point, for example,
defines an address containing its descendant compartments and their synaptic
inputs. The indicator patterns of several addresses span a low-dimensional
subspace used to approximate the exact spatial distribution of credit.

The physical meaning of a weight also changes in a conductance-based dendritic
model: the synaptic weight is a conductance rather than an additive coefficient.
Excitatory and inhibitory conductances change both injected current and total
membrane conductance. An inhibitory conductance can therefore lower input
resistance and attenuate other inputs even when its own net current is small;
this is shunting inhibition
\citep{holt1997shunting,chance2002gain,gidon2012inhibition,
lovettbarron2012regulation}. Input resistance also controls how voltage
perturbations propagate, so conductance can rescale the transport of a somatic
loss derivative to a dendritic compartment. We call this scaling
the \emph{route gain}. Neuron identity, dendritic address and route gain specify
which neuron should learn, which locations need distinct signals and how
strongly each signal should act.

Dendrites already contribute to theories of somatic prediction, segregated
basal and apical learning, interneuron-mediated teaching, burst-dependent
plasticity and prospective dynamics
\citep{urbanczik2014dendritic,schiess2016somatodendritic,
guerguiev2017segregated,sacramento2018dendritic,payeur2021burst,
ellenberger2026gle,richards2019dendritic}. Cable sensitivities have also been
used to optimize the input--output function of a reconstructed neuron
\citep{bicknell2021synaptic}. These studies establish that dendrites can
participate in learning. The unresolved question is when the branching
structure of a complete arbor provides useful resolution beyond one learning
signal per neuron.

We therefore ask what information the exact dendritic gradient requires, when
a restricted set of feedback routes can retain useful signal while excluding
noise, and whether reconstructed arbors provide and regulate such routes. We
begin from the exact gradient and derive a local rule for a conductance-based
tree. The point-neuron eligibility--signal factorization remains, but one
neuron-specific error becomes a field over compartments. We compare a
layer-wide scalar, one signal per neuron, several subtree signals and the exact
compartment-resolved error. Grouped-point controls give a non-dendritic model
the same feedback operator, separating signal resolution from dendritic
implementation.

We represent each restricted feedback pathway as a \emph{credit operator} that
maps an exact or noisy gradient to the update available to the local rule. We
derive a stochastic bound on its expected one-step loss reduction and use it to
organize the experiments by feedback bandwidth, task--route alignment and
noise. On image tasks, preserving neuron-specific feedback coordinates explains
most of the improvement over a scalar broadcast; path resolution adds little.
In a controlled branch-conflict task, subtree routes help when branches require
conflicting updates. We distinguish this backward-routing problem from forward
computation: in the mechanism-matched tasks tested, serial depth helps only when
its nonlinear stages match the task hierarchy. Reconstructed arbors provide
sparse candidate routes, and conductance regulates their gain only in a
permissive regime; a one-mouse MICrONS visual-response cohort reveals no
preferential alignment with those routes. Thus dendritic structure helps local
credit assignment when task
distinctions match available addresses and gains, not as a generic consequence
of adding branches or depth.

\section*{Results}

We proceed from the exact gradient to progressively restricted feedback and
then to biological route capacity, gain and alignment. Exact backpropagation is
the information ceiling; point and grouped-point controls distinguish feedback
resolution from a dendritic implementation.

explicitly at each experiment. The controlled network experiments use regular
rooted trees with directed child-to-parent forward coupling. We denote such a

\subsection*{Exact dendritic gradients separate local eligibility from transported error}

Before asking whether a dendritic morphology improves learning, we first need
to specify the information required by an exact weight update. We begin with a
single point node in a network and then replace that node by a conductance-based
tree. This progression defines the local eligibility available at a synapse,
the nonlocal learning signal that must be communicated, and the controls used
in the experiments that follow.

Consider a point neuron \(u\) with presynaptic activities \(x_i\), incoming
weights \(w_i\), preactivation \(z_u\) and output \(y_u\):
\begin{equation}
z_u=\sum_{i\in\operatorname{In}(u)}w_i x_i+b_u,
\qquad y_u=f_u(z_u).
\label{eq:pointforward}
\end{equation}
The weight affects the network loss \(\mathcal L\) through the activity of
neuron \(u\) and all of its downstream targets. Define the exact
neuron-specific learning signal as
\(\delta_u\equiv\partial\mathcal L/\partial y_u\). The chain rule gives
\begin{equation}
\frac{\partial\mathcal L}{\partial w_i}
=\underbrace{x_i f_u'(z_u)}_{e_i:\,\text{local eligibility}}
\underbrace{\delta_u}_{\text{neuron-specific learning signal}} .
\label{eq:pointneuron}
\end{equation}
For a hidden node, backpropagation computes this learning signal recursively from
its downstream neighbors,
\begin{equation}
\delta_u=\sum_{v:\,u\to v}w_{uv}f_v'(z_v)\delta_v,
\label{eq:backproprecursion}
\end{equation}
starting from the loss derivative at the output. Equation~\ref{eq:pointneuron}
separates the exact gradient into a local eligibility \(e_i\), determined by
pre- and postsynaptic variables, and a learning signal \(\delta_u\), which
contains the downstream task information that those local variables cannot
provide.

A local three-factor rule retains the eligibility and replaces the exact
learning signal with an approximation \(\widehat\delta_u\) that is available
to the neuron. With learning rate \(\eta>0\), the update is
\begin{equation}
\Delta w_i=-\eta e_i\widehat\delta_u.
\label{eq:pointlocalrule}
\end{equation}
The rule is exact when \(\widehat\delta_u=\delta_u\). Otherwise, its quality is
limited by the information carried by the feedback pathway. This formulation
does not assume that a biological circuit implements the recursion in
Eq.~\ref{eq:backproprecursion}; it uses backpropagation only to define the
target signal. It also makes the meaning of \emph{local} precise: the synapse
uses its own eligibility and a communicated learning signal, not the full
downstream Jacobian.

We now replace point neuron \(u\) with a rooted dendritic tree whose soma is
compartment \(n=0\). Compartment \(n\) has voltage \(V_n\) and receives
excitatory contacts \(\mathcal S_n^{\mathrm E}\) and inhibitory contacts
\(\mathcal S_n^{\mathrm I}\), with
\(\mathcal S_n=\mathcal S_n^{\mathrm E}\mathbin{\dot\cup}
\mathcal S_n^{\mathrm I}\). A contact of type
\(X\in\{\mathrm E,\mathrm I\}\) has a nonnegative maximal conductance
\(g_i^X\), nonnegative presynaptic activity \(x_i^X\), and open conductance
\(g_i^Xx_i^X\). Its reversal potential is
\(E_i^{\mathrm{rev}}=E_X\), namely \(E_{\mathrm E}\) for excitation and
\(E_{\mathrm I}\) for inhibition. Thus excitation and inhibition are not
positive and negative weights: both conductances are nonnegative, and their
different effects arise from the driving forces
\(E_{\mathrm E}-V_n\) and \(E_{\mathrm I}-V_n\).
When the contact class is not at issue, we suppress the superscript \(X\) and
write \(g_i\), \(x_i\), and \(E_i^{\mathrm{rev}}\).

Define the aggregate open conductances
\(G_n^{\mathrm E}=\sum_{i\in\mathcal S_n^{\mathrm E}}g_i^{\mathrm E}x_i^{\mathrm E}\)
and
\(G_n^{\mathrm I}=\sum_{j\in\mathcal S_n^{\mathrm I}}g_j^{\mathrm I}x_j^{\mathrm I}\).
The compartment also has membrane capacitance \(C_n\), leak conductance
\(g_n^{\mathrm L}\) with reversal potential \(E_{\mathrm L}\), and signals
\(a_c=f_c(V_c)\) from its children \(c\in\mathcal C_n\), coupled by
\(g_{c\to n}^{\mathrm{den}}\). The soma produces the neuronal output
\(y_u=f_0(V_0)\). In the directed-tree model, the voltage obeys the current
balance
\begin{equation}
C_n\frac{dV_n}{dt}
=g_n^{\mathrm L}(E_{\mathrm L}-V_n)
+G_n^{\mathrm E}(E_{\mathrm E}-V_n)
+G_n^{\mathrm I}(E_{\mathrm I}-V_n)
+\sum_{c\in\mathcal C_n}g_{c\to n}^{\mathrm{den}}(a_c-V_n).
\label{eq:directedcurrentbalance}
\end{equation}
When \(E_{\mathrm I}<V_n<E_{\mathrm E}\), excitation is depolarizing and
inhibition is hyperpolarizing. When \(E_{\mathrm I}\simeq V_n\), the direct
inhibitory current is small, but the open inhibitory conductance remains in the
current balance. The E/I label here describes a forward synaptic pathway; it is
independent of the sign of the learning signal that modulates plasticity.

The simulations use the steady state of Eq.~\ref{eq:directedcurrentbalance}.
Define the aggregate child conductance
\(G_n^{\mathrm{child}}=\sum_c g_{c\to n}^{\mathrm{den}}\) and child current
\(J_n^{\mathrm{child}}=\sum_c g_{c\to n}^{\mathrm{den}}a_c\). Collecting the
terms proportional to \(V_n\) gives the total conductance
\(g_n^{\mathrm{tot}}\), the corresponding input resistance
\(R_n^{\mathrm{tot}}\) and the steady-state voltage:
\begin{align}
g_n^{\mathrm{tot}}
&=g_n^{\mathrm L}+G_n^{\mathrm E}+G_n^{\mathrm I}
  +G_n^{\mathrm{child}},\\
V_n
&=R_n^{\mathrm{tot}}\left(
g_n^{\mathrm L}E_{\mathrm L}+G_n^{\mathrm E}E_{\mathrm E}
+G_n^{\mathrm I}E_{\mathrm I}+J_n^{\mathrm{child}}\right),
\qquad R_n^{\mathrm{tot}}=(g_n^{\mathrm{tot}})^{-1}.
\label{eq:directedvoltage}
\end{align}
Equation~\ref{eq:directedvoltage} makes the distinction explicit: excitation
and inhibition enter total conductance with the same positive sign, but enter
the voltage numerator through different reversal potentials. An inhibitory
conductance therefore lowers input resistance even when \(V_n\) is close to
\(E_{\mathrm I}\) and its own net current is small. This
conductance-dependent attenuation is shunting inhibition and is not equivalent
to injecting a matched negative current.

The derivation does not require particular reversal potentials. The directed
artificial-tree simulations use dimensionless
\(g_n^{\mathrm L}=1\), \(E_{\mathrm L}=E_{\mathrm I}=0\), and
\(E_{\mathrm E}=1\). In that convention, excitation enters both numerator and
denominator, whereas inhibition enters only the denominator. The reconstructed
focal-cable experiment instead uses \(E_{\mathrm E}=1\) and
\(E_{\mathrm I}=-0.2\), so an inhibitory perturbation is both hyperpolarizing
and shunting. These are normalized model conventions rather than fitted
millivolt values; the experiment-specific definitions are consolidated in
Methods.

The steady-state equation also gives the local sensitivity to a synaptic
conductance. For a contact \(i\) of type \(X\in\{\mathrm E,\mathrm I\}\),
holding presynaptic activities and child outputs fixed gives
\begin{equation}
\frac{\partial V_n}{\partial g_i^X}
=\frac{x_i^XE_X g_n^{\mathrm{tot}}-x_i^X(g_n^{\mathrm{tot}}V_n)}
       {(g_n^{\mathrm{tot}})^2}
=x_i^XR_n^{\mathrm{tot}}(E_X-V_n).
\label{eq:localsensitivity}
\end{equation}
Write the exact voltage error assigned to compartment \(n\) of neuron \(u\) as
\(\delta^V_{n,u}\equiv\partial\mathcal L/\partial V_n\). Applying the chain
rule from the loss to \(V_n\) then gives
\begin{equation}
\frac{\partial\mathcal L}{\partial g_i}
=\underbrace{x_iR_n^{\mathrm{tot}}(E_i^{\mathrm{rev}}-V_n)}_{\text{local eligibility}}
\underbrace{\delta^V_{n,u}}_{\displaystyle
\partial\mathcal L/\partial V_n:\,\text{compartment error}}.
\label{eq:factorization}
\end{equation}
The first factor contains only presynaptic activity, input resistance and
synaptic driving force, all available at the synapse or its host compartment.
We call it the dendritic eligibility. The second factor is the exact error
assigned to that compartment. Equation~\ref{eq:factorization} therefore
extends the point-neuron three-factor rule without changing its basic logic.
It applies to both contact classes, with their difference confined to the
local driving force:
\begin{equation}
\begin{aligned}
\frac{\partial\mathcal L}{\partial g_i^{\mathrm E}}
&=x_i^{\mathrm E}R_n^{\mathrm{tot}}(E_{\mathrm E}-V_n)
\delta^V_{n,u},
&i&\in\mathcal S_n^{\mathrm E},\\
\frac{\partial\mathcal L}{\partial g_j^{\mathrm I}}
&=x_j^{\mathrm I}R_n^{\mathrm{tot}}(E_{\mathrm I}-V_n)
\delta^V_{n,u},
&j&\in\mathcal S_n^{\mathrm I}.
\end{aligned}
\label{eq:shuntinggradient}
\end{equation}
For \(E_{\mathrm I}<V_n<E_{\mathrm E}\), the two local voltage sensitivities
have opposite signs; the signed compartment error determines the resulting
loss gradient and update. Near the inhibitory reversal, the driving force in
Eq.~\ref{eq:shuntinggradient} can be small even though the conductance still
changes \(R_n^{\mathrm{tot}}\). A shunt may therefore have a small gradient of
its own while changing the gradients of other synapses. We test this distinct
effect on error transport below.

The remaining question is how the somatic error reaches each compartment. Let
\(p(n)\) be the parent of compartment \(n\). The somatic value of this error,
\(\delta^V_{0,u}=f_0'(V_0)\delta_u\), includes the downstream network
derivative. Along one dendritic edge, the chain rule gives
\begin{equation}
\delta^V_{n,u}
=\delta^V_{p(n),u}
 f_n'(V_n)R_{p(n)}^{\mathrm{tot}}g_{n\to p(n)}^{\mathrm{den}}.
\label{eq:compartmentrecursion}
\end{equation}
Because a directed tree has one path from \(n\) to the soma, repeated
application yields
\begin{equation}
\delta^V_{n,u}
=\delta^V_{0,u}\widetilde\alpha_n,\qquad
\widetilde\alpha_n=
\prod_{(i\to k)\in\operatorname{path}(n\to0)}
f_i'(V_i)R_k^{\mathrm{tot}}g_{i\to k}^{\mathrm{den}} .
\label{eq:pathgain}
\end{equation}
The path gain \(\widetilde\alpha_n\) contains the branch derivatives, coupling
conductances and input resistances encountered between compartment \(n\) and
the soma. A point neuron has one exact learning signal. A dendritic tree has a
spatial field of exact compartment errors obtained by transporting the somatic
error through these path gains.

To isolate direct conductance effects from branch-nonlinearity derivatives,
define the conductance-only path gain
\(\alpha_n^{\mathrm{cond}}\equiv
\prod_{(i\to k)\in\operatorname{path}(n\to0)}
R_k^{\mathrm{tot}}g_{i\to k}^{\mathrm{den}}\), obtained from
\(\widetilde\alpha_n\) by omitting the branch derivatives \(f_i'(V_i)\).
Any added open conductance acts directly on this denominator-only factor. Let
\(G_k^{\mathrm I}\) be an added effective inhibitory conductance at compartment
\(k\), analogous to the activity-weighted aggregate \(G_n^{\mathrm I}\) above,
and hold the coupling conductances fixed. Define
\(\mathcal A(n)=\{k:(i\to k)\in\operatorname{path}(n\to0)\}\), the parent
endpoints of the path edges. These are the strict ancestors of \(n\) (including
the soma if its conductance is varied). Then
\begin{equation}
\frac{\partial\log\alpha_n^{\mathrm{cond}}}{\partial G_k^{\mathrm I}}
=-R_k^{\mathrm{tot}}\,\mathbf 1\!\left[k\in\mathcal A(n)\right].
\label{eq:shuntpathgain}
\end{equation}
Here \(\mathbf 1[\cdot]\) is the indicator, equal to one when its
condition holds and zero otherwise. The direct effect is therefore zero
unless \(k\in\mathcal A(n)\), and it attenuates the
route when \(k\in\mathcal A(n)\). Its magnitude is set by the local
input resistance. The reversal potential does not appear because
\(\alpha_n^{\mathrm{cond}}\) retains only total-conductance loading; the same
direct denominator effect would follow from any positive conductance increment.
We call the perturbation a shunt when its inhibitory reversal lies near the
local voltage, making the accompanying direct current small.
Equation~\ref{eq:shuntpathgain} therefore identifies a possible route-gain mechanism,
not a learning advantage: a physical shunt also changes the forward voltage,
driving forces and branch derivatives through \(E_{\mathrm I}\), and the
spatial effect can disappear outside a high-conductance electrotonic regime. Supplementary
Fig.~S1A shows the corresponding reduction in path-gain dispersion in the
regular-tree model; the direct, current-matched test appears below.

The path product above relies on a directed tree. A general differentiable
compartmental model can instead be treated with the Almeida--Pineda
steady-state adjoint \citep{almeida1987asynchronous,pineda1987recurrent}. For
a system
\(\bm F(\bm V,\bm g,\bm x)=\bm 0\), define
\(J_V=\partial\bm F/\partial\bm V\). Implicit differentiation gives
\begin{equation}
J_V^{\mathsf T}\bm q=\nabla_{\bm V}\mathcal L,
\qquad
\frac{\partial\mathcal L}{\partial g_i}
=-\bm q^{\mathsf T}\frac{\partial\bm F}{\partial g_i}.
\label{eq:generaladjoint}
\end{equation}
For the residual convention \(\bm F=G\bm V-\bm b\), the exact conductance
gradient is
\begin{equation}
\frac{\partial\mathcal L}{\partial g_i}
=\underbrace{x_i(E_i^{\mathrm{rev}}-V_n)}_{\text{local synaptic factor}}
\underbrace{q_n}_{\text{compartment adjoint}}.
\label{eq:generalconductancegradient}
\end{equation}
Here \(q_n\) measures how much the loss would change after a small current
injection at compartment \(n\). Excitatory and inhibitory conductances both
load the voltage operator, but their reversal potentials enter its source term
and the local factor \(E_i^{\mathrm{rev}}-V_n\). In the directed model,
\(q_n=R_n^{\mathrm{tot}}\delta^V_{n,u}\):
Eq.~\ref{eq:factorization} displays input resistance in the eligibility,
whereas Eq.~\ref{eq:generalconductancegradient} absorbs it into the adjoint. In a
reciprocal passive cable, the same error is transported by the Green's function
\(G^{-1}\) rather than a single path product \citep{rall1962dendrites}. This
connects the present derivation to recurrent adjoints, cable theory and earlier
detailed-arbor learning based on cable sensitivities
\citep{schiess2016somatodendritic,bicknell2021synaptic}.

We can now define the local dendritic rule. It preserves the dendritic
eligibility and replaces the exact compartment error with an available
learning signal \(\widehat\delta^V_{n,u}\):
\begin{equation}
\widehat\nabla_{g_i}\mathcal L
=x_iR_n^{\mathrm{tot}}(E_i^{\mathrm{rev}}-V_n)\widehat\delta^V_{n,u}.
\label{eq:dendriticlocalrule}
\end{equation}
The rule is exact when
\(\widehat\delta^V_{n,u}=\delta^V_{n,u}\). With limited feedback bandwidth,
we need to specify which compartment-error field is available to the rule. Let
neuron \(u\) have \(N_u\) routed dendritic compartments,
indexed \(n=1,\ldots,N_u\); the soma retains index \(n=0\). The vector
\(\bm\delta^V_u=(\delta^V_{1,u},\ldots,\delta^V_{N_u,u})^{\mathsf T}\)
collects the exact compartment errors, and \(\widehat{\bm\delta}^V_u\)
collects the values available to the local rule. The vector
\(\bm c_u=(c_{u,1},\ldots,c_{u,K})^{\mathsf T}\in\mathbb R^K\) contains the
signed, example-dependent values carried by its \(K\) feedback channels. The
fixed address matrix \(A_u\in\mathbb R^{N_u\times K}\) contains their spatial
delivery profiles: entry \((A_u)_{nk}\) is the weight with which channel \(k\)
is assigned to compartment \(n\), and zero means that the channel does not
reach that compartment. Assuming that the channel contributions superpose,
the available field is their linear combination,
\begin{equation}
\widehat{\bm\delta}^{V}_u=A_u\bm c_u,
\qquad
\widehat\delta^V_{n,u}=\sum_{k=1}^{K}(A_u)_{nk}c_{u,k}.
\label{eq:routedfield}
\end{equation}
Equation~\ref{eq:routedfield} defines the restricted linear delivery model
used here: it is a basis expansion of the available compartment-error field,
not a further identity derived from the conductance equations. The matrix
\(A_u\) is an address matrix, not the dendritic adjacency matrix, and specifies
\emph{where} feedback acts; \(\bm c_u\) specifies \emph{what values} are sent
on the current example. The equation leaves open how a circuit computes those
values. For example,
\(A_u=\left(\begin{smallmatrix}1&0\\1&0\\0&1\end{smallmatrix}\right)\)
gives \(\widehat{\bm\delta}^V_u=(c_{u,1},c_{u,1},c_{u,2})^{\mathsf T}\):
channel 1 reaches compartments 1--2 and channel 2 reaches compartment 3.

At \(K=1\),
\(A_u=\bm 1_{N_u}\) repeats one value throughout the arbor; using the same
coefficient for every \(u\) gives a layer-wide scalar, whereas allowing it to
differ across neurons gives neuron-specific feedback. At the other extreme,
\(K=N_u\), \(A_u=I\) and \(\bm c_u=\bm\delta^V_u\) reproduce the exact
nonsomatic field; the somatic coordinate \(\delta^V_{0,u}\) remains separate.
A binary nested-subtree address sets \((A_u)_{nk}=1\) for descendants of its
branch point and zero elsewhere. Capacity
analyses choose their best-fitting values to measure an upper bound, whereas
trained experiments obtain them from the feedback rule stated for that task.

We call \(\bm\delta^V_u\) the exact nonsomatic \emph{credit field}. Let
\(P_{A_u}=A_uA_u^\dagger\) be the Euclidean orthogonal projector onto the
route span \(\operatorname{col}(A_u)\), where \(\dagger\) denotes the
Moore--Penrose pseudoinverse. For a nonzero field, its unweighted
\emph{field capture} is
\[
\mathcal C(A_u;\bm\delta^V_u)
=\frac{\lVert P_{A_u}\bm\delta^V_u\rVert_2^2}
{\lVert\bm\delta^V_u\rVert_2^2}.
\]
For a field ensemble with covariance \(\Sigma_u^V\), expected capture is
\(\operatorname{tr}(P_{A_u}\Sigma_u^V)/\operatorname{tr}(\Sigma_u^V)\). The
reconstructed-arbor analysis uses the corresponding synaptic-area-weighted
projector defined in Methods.
This vocabulary separates three routing properties. \emph{Neuron identity}
means that different neurons retain distinct feedback coordinates;
\emph{ownership} is the map from each coordinate to its corresponding arbor;
\emph{dendritic address} specifies where that coordinate acts within the arbor.
Route gain specifies how strongly it is transmitted. Figure~\ref{fig:framework}C
gives the visual distinction. The experiments below vary feedback resolution
while keeping the coordinate-to-arbor ownership map correct.
Stacking the routed fields across neurons and applying
the corresponding local eligibilities produces the parameter-space credit
operator defined in the next subsection.

Before comparing feedback resolutions, we also define the non-shunting
forward control used in the regular-tree experiments. It retains the tree
graph, contact masks and branch nonlinearities but replaces the conductance
balance by signed current addition:
\[
\begin{aligned}
J_n^{\mathrm E,\mathrm{add}}
&=\sum_{i\in\mathcal S_n^{\mathrm E}}w_i^{\mathrm E}x_i^{\mathrm E},
&J_n^{\mathrm I,\mathrm{add}}
&=\sum_{j\in\mathcal S_n^{\mathrm I}}w_j^{\mathrm I}x_j^{\mathrm I},\\
J_n^{\mathrm{child},\mathrm{add}}
&=\sum_{c\in\mathcal C_n}w_{c\to n}^{\mathrm{den}}a_c,
&V_n^{\mathrm{add}}
&=J_n^{\mathrm E,\mathrm{add}}-J_n^{\mathrm I,\mathrm{add}}
+J_n^{\mathrm{child},\mathrm{add}}.
\end{aligned}
\]
Here the nonnegative \(w\)'s scale currents rather than conductances, so the
local excitatory and inhibitory sensitivities are \(+x_i^{\mathrm E}\) and
\(-x_j^{\mathrm I}\). This \emph{raw-additive tree} retains signed summation
and dendritic topology but has neither reversal-potential driving forces nor a
total-conductance denominator and therefore cannot shunt. Within each
comparison, contact counts, decoder, feedback condition and training protocol
were matched; initialization was architecture specific (Methods). The
normalized-additive tree in Supplementary Figs.~S1--S3 and S4A,B and the
baseline-current-matched current injection tested later are distinct controls.

Numerical gradient checks confirmed Eqs.~\ref{eq:factorization} and
\ref{eq:pathgain} (Methods). We next add
feedback information in the order implied by the derivation: first neuron
identity, then location within the arbor.

\subsection*{Neuron-specific feedback resolves the dominant information bottleneck}

Equation~\ref{eq:pointlocalrule} identifies the first information bottleneck:
feedback must distinguish neurons that require different updates. Before
testing dendritic addresses, we therefore compared three feedback resolutions
(Fig.~\ref{fig:feedback}A). A layer-wide scalar supplied the same learning
signal to every neuron. Neuron-specific feedback supplied one signal
\(\widehat\delta_u\) to each neuron and repeated it throughout that neuron's
arbor. Exact feedback supplied the complete compartment-error field. The first
comparison tests the established bandwidth limitation of scalar feedback
\citep{werfel2005learning,lillicrap2016feedback}; the second asks whether
resolving dendritic locations within each neuron provides an additional
benefit.

We tested this hierarchy on flattened ten-class MNIST using one layer of 128
regular rooted directed trees with $[3,3]$ branching: three proximal
compartments and nine terminal compartments per soma. We compared a
conductance-based shunting tree with a topology-matched raw-additive tree. The
two architectures retained the same branching graph, contact masks, branch
nonlinearities, decoder and training protocol; they differed in the
compartmental current law and used architecture-specific initialization. This
design asks whether feedback resolution, rather than a change in forward
morphology or task, explains the learning differences in
Fig.~\ref{fig:feedback}A,B.

On MNIST, neuron-specific feedback produced the dominant improvement in both
shunting and topology-matched raw-additive trees. Relative to a strict scalar,
it increased accuracy by 11.2 and 7.8 percentage points, respectively,
whereas replacing the repeated neuronal signal with the exact compartment
field changed accuracy by less than 0.2 percentage points
(Fig.~\ref{fig:feedback}B). Thus nearly all of the scalar-to-exact improvement
came from preserving distinct feedback coordinates across neurons, not from
resolving dendritic paths within them.

A separate control showed that the matched-width scalar-fallback
implementation performed better than strict scalar feedback because it
preserved neuron-specific coordinates for a small set of near-somatic
parameters. We therefore used strict scalar feedback for the primary MNIST
comparison; Methods quantify the affected parameters and compare the two
implementations. Importantly, scalar feedback did not make all neurons
identical. Every synapse still multiplied the shared learning signal by a different
eligibility trace, determined by its input, weight and postsynaptic state.
Scalar feedback limits the dimension of task information; it does not collapse
the network to a single effective neuron.

The same ordering generalized across datasets. Fashion-MNIST again benefited
from neuron-specific feedback, measured against matched-width scalar-fallback
feedback, whereas exact path transport added little (Supplementary
Fig.~S4E). On flattened CIFAR-10, neuron-specific feedback improved over a
strict scalar, whereas exact path transport did not improve further and was
equivalent to matched backpropagation within the predefined margin
(Supplementary Fig.~S4D). These controls extend the ordering beyond MNIST;
they do not establish that task difficulty itself determines the size of the
neuron-identity effect.

Gradient diagnostics supported the same interpretation. At fixed checkpoints
trained with neuron-specific feedback, the parameter-count-weighted
branch-gradient cosine was substantially higher for neuron-specific feedback
than for the matched-width scalar-fallback field
(Fig.~\ref{fig:feedback}C). With exact path transport, the factorized local rule
matched automatic differentiation (Methods) and trained models achieved
similar held-out accuracy to matched backpropagation (Supplementary
Fig.~S3C). The main approximation error
therefore arose in the communicated learning signal, rather than in the local
eligibility derived in Eq.~\ref{eq:factorization}. Higher alignment need not
raise final accuracy on these tasks: positive alignment characterizes local
descent geometry only for a sufficiently small step and does not determine an
entire optimization trajectory or its final solution. This fixed-checkpoint
diagnostic therefore measures the fidelity of the communicated learning
signal rather than predicting the accuracy plateau. The branch-conflict task
below makes distinct path updates behaviorally necessary, converting the
alignment difference into an accuracy difference
(Fig.~\ref{fig:branchconflict}).

We next asked how the exact error field varied within an arbor. Its mean
magnitude can change with depth, and compartments at the same depth can
receive different errors. At the exact-path checkpoints from the MNIST
cohort, the shunting field attenuated from the soma toward distal
compartments, whereas the raw-additive field was amplified at the distal
stage (Fig.~\ref{fig:feedback}D). This contrast reflects the complete local
derivatives, including the learned branch nonlinearities and, only in the
shunting tree, conductance loading. To isolate variation among paths at a
fixed depth, we measured the fraction of exact-error energy left after
replacing, for each example and neuron, all paths at that depth by their mean
(Methods). About 18\% of the exact-error energy was path specific at the
middle stage in both architectures. The fraction rose distally to 32\% in
raw-additive trees and 53\% in shunting trees, with the shunting value larger
in all fifteen paired seeds
(Fig.~\ref{fig:feedback}E). Thus shunting preserved a larger path-specific
fraction distally even though the absolute distal error was smaller, consistent
with its stronger attenuation. MNIST did not benefit materially from
resolving this structure: exact path transport added no more than 0.2
percentage points in either architecture (Fig.~\ref{fig:feedback}B). The
task must also require different paths to act differently.

Both observations follow the factorization in Eq.~\ref{eq:pathgain}. A
neuron's compartment errors equal its somatic error multiplied by positive
path gains, so ordinary feedforward trees primarily create differences in
magnitude rather than sign. In shunting trees, the conductance loading that
shapes these gains is also the quantity manipulated later by focal inhibition
(Eq.~\ref{eq:shuntpathgain}, Fig.~\ref{fig:focal}). These transport
differences did not change the feedback-resolution outcome: both
architectures showed the same qualitative ordering across the ladder, with
no general optimization advantage for shunting
(Fig.~\ref{fig:feedback}B).

A neuron-specific coordinate is useful only if it is delivered to the
corresponding arbor; we refer to this coordinate-to-arbor map as ownership
(Fig.~\ref{fig:feedback}F). We tested ownership in separate MNIST cohorts of
regular directed \([2,2]\) trees (two proximal and four terminal compartments
per soma) and \([2,2,2,2]\) trees (2, 4, 8 and 16 compartments across four
successive stages). Permuting coordinates among arbors preserved total
feedback bandwidth, coordinate values, forward morphology and training
protocol but produced a small, consistent loss. Correct ownership exceeded the fixed
derangement by 0.57 and 0.51 percentage points in two-stage shunting and
raw-additive trees and by 0.38 and 0.39 points at four stages, with a positive
difference in all ten paired seeds in every condition
(Fig.~\ref{fig:feedback}G).
The mean ownership advantage was not larger in four-stage trees with 30
nonsomatic compartments per neuron than in two-stage trees with six
nonsomatic compartments per neuron. Because these cohorts were trained
independently, they test the ownership map rather than the within-arbor
transport fields quantified above. Taken together, the paired comparisons
establish a hierarchy: adding neuron-specific coordinates produced the
dominant gain, resolving address within an arbor added little on MNIST, and
preserving ownership produced a smaller but consistent benefit across the
independent cohorts.

Finally, we varied the number of serial dendritic stages in ordinary image and
noise tasks. Neuron-specific feedback remained the main improvement at every valid depth,
and exact path transport remained close to matched backpropagation
(Supplementary Fig.~S19). Increasing depth by
itself was detrimental at fixed terminal-branch and contact budgets. Physical
depth therefore adds a computational and credit-transport cost unless the task
specifically uses its serial structure.

These benchmarks establish the first boundary of the paper: once separate
feedback coordinates are available across neurons, additional within-arbor
path information added little in these standard-task benchmarks. This boundary
motivates the signal--noise theory developed next: under what conditions can
restricted feedback retain useful credit while excluding noise?

\subsection*{A signal--noise theory predicts when restricted feedback helps}

The feedback ladder showed that removing information can harm learning, but it
did not identify when a restricted route might help by rejecting noise. We
therefore sought a common description that separates the signal retained by a
feedback pathway from the noise and gain that the same pathway introduces.
A feedback pathway changes the exact gradient in three ways: it selects which
components are communicated, assigns them to synapses and scales their
amplitudes. We summarize these operations by a linear \emph{credit operator}
\(M\). Let \(\bm\mu=\nabla_{\bm w}\mathcal L\) denote the exact mean parameter
gradient, and let a mini-batch provide the unbiased estimate
\(\widehat{\bm\mu}=\bm\mu+\bm\xi\), where \(\bm\xi\) has zero mean and covariance
\(\Sigma\). The update available to the local rule is
\begin{equation}
\widetilde{\bm\mu}=M\widehat{\bm\mu},
\qquad
\bm w^+=\bm w-\eta\widetilde{\bm\mu}.
\label{eq:creditoperator}
\end{equation}
Exact backpropagation has \(M=I\). Scalar, neuron-specific and
subtree-targeted feedback correspond to operators with progressively greater
bandwidth (Fig.~\ref{fig:creditphase}A). The column space of \(M\) is the set
of gradient patterns that the feedback pathway can represent, which we call
its \emph{route span}.

For an \(L\)-smooth loss, the expected loss after one routed stochastic update
obeys
\begin{equation}
\mathbb E\mathcal L(\bm w^+)\leq \mathcal L(\bm w)
-\eta\bm\mu^{\mathsf T}M\bm\mu
+\frac{L\eta^2}{2}\left(
\lVert M\bm\mu\rVert_2^2+\operatorname{tr}(M\Sigma M^{\mathsf T})\right).
\label{eq:creditoperatorbound}
\end{equation}
The first term after the current loss measures useful alignment with the exact
gradient. The squared norm measures the finite-step cost of the routed update,
and the trace term measures the stochastic noise admitted by the same pathway.
When the routed update is positively aligned with the exact gradient,
optimizing this bound over step size gives the operator utility
\begin{equation}
U(M)=\frac{[\bm\mu^{\mathsf T}M\bm\mu]^2}
{2L\{\lVert M\bm\mu\rVert_2^2+
\operatorname{tr}(M\Sigma M^{\mathsf T})\}} .
\label{eq:phaseutility}
\end{equation}
A restricted pathway can improve a noisy update only when the noise it rejects
compensates for the useful gradient signal it loses. It cannot outperform the
exact full-batch gradient at matched first-order step norm. The bound is exact
for the isotropic quadratic whose Hessian is \(LI\); for a general quadratic it
remains a curvature upper bound, and for a general smooth loss it describes
guaranteed one-step progress.
Field capture, defined above, measures representation of the exact field by
the route span; \(U(M)\) additionally accounts for alignment, gain and admitted
noise.

Equations~\ref{eq:creditoperatorbound} and \ref{eq:phaseutility} make four
testable predictions. A tree-structured route should become more useful as task
credit aligns with its span. Route resolution should have an interior optimum
when additional channels admit more noise than signal. Projection should help
only on the side of the signal--noise boundary where rejected noise exceeds
discarded signal. Finally, route-specific gains should help only when they are
matched to heterogeneous route reliability.

We tested the predictions in four related synthetic quadratic screens designed
to isolate feedback geometry from forward computation. No forward neuron was
simulated. Instead, 16 parameter-gradient coordinates were organized in the
Haar basis of a balanced binary tree, and nested subspaces of that basis
defined the available feedback routes. The screens independently varied
task--tree alignment, route resolution relative to signal hierarchy, retained
signal and noise, and route-wise reliability
(Fig.~\ref{fig:creditphase}B--F). Panel B uses eight terminals only as a
readable illustration of the 16-coordinate construction.

The four predictions held. First, in the spectral-alignment screen, the
subtree-minus-random capture advantage increased as task covariance rotated
into the subtree span
(Fig.~\ref{fig:creditphase}C). They reached the optimal rank-\(K\) spectral
capture when their span contained the leading covariance eigenspace. The
advantage disappeared under random alignment and at full rank, where both
route families represented the complete space (Supplementary Section~S4).

Second, the resolution screen placed task signal at Haar levels through
\(H_{\mathrm c}\) and allowed feedback to resolve levels through
\(D_{\mathrm r}\). Here \(H_{\mathrm c}\) is the finest credit-hierarchy
level containing signal and \(D_{\mathrm r}\) the finest level resolved by
the feedback pathway; neither is physical dendritic depth. Loss was minimized
when these resolutions matched (Fig.~\ref{fig:creditphase}D). Coarser routes
discarded signal, whereas finer routes admitted irrelevant noise. This is a
controlled validation of the crossover built into the generator, not a claim
that arbitrary tasks obey \(D_{\mathrm r}=H_{\mathrm c}\).

Third, the projection screen varied retained signal and noise independently
and recovered the predicted boundary: projection helped exactly when it
rejected more noise than signal
(Fig.~\ref{fig:creditphase}E). Backpropagation followed by the same projection
remained the appropriate upper control because it used the restricted span
with exact coefficients. Fourth, in the reliability screen, eight abstract
coordinate blocks had different signal-to-noise ratios. Route-specific gains
helped only when they were aligned with the corresponding
signal-to-noise ratios (Fig.~\ref{fig:creditphase}F). Shuffling or reversing
the gains removed the benefit, and a point model supplied with the same gains
matched the routed model. This result parallels conductance-based reliability
weighting in forward sensory integration \citep{jordan2024conductance}.

Positive shunting conductances reproduced the relative ordering of aligned,
global and misplaced gains, but did not improve final loss over the unshunted
noisy rule (Supplementary Figs.~S13 and S24). Same-span controls further showed
that coordinate conditioning changes how efficiently route coefficients are
learned without changing address capacity (Supplementary Fig.~S14). We return
to the conductance mechanism in the focal-shunting experiment below.

To ask whether \(U(M)\) transfers beyond the quadratic screens, we reanalyzed,
without additional training, the eight-context, eight-terminal subtree-address
factorial introduced fully in Fig.~\ref{fig:subtreefactorial}. Among its 540
trained dendritic-tree route conditions, utility correlated with
norm-matched one-step progress at \(\rho=0.937\) and predicted final accuracy
with \(\rho=0.916\), more strongly than field capture alone
(Fig.~\ref{fig:creditphase}G and Supplementary Table~S3). It
located the main route-resolution optima but did not predict the small
training-trajectory advantage of task-matched subtrees in every seed. The
theory therefore predicts large contrasts and within-family progress, not
every difference accumulated during nonlinear training.
Figure~\ref{fig:creditphase}H is a secondary synthesis rather than a fifth
experiment. It places four independently defined experiment families on
normalized alignment and relative-bandwidth coordinates; no common forward
morphology is implied. The plane summarizes the scope of the theory and the
tests that follow.

The operator bound motivates a branch-space question: when does sharing mix
local updates so strongly that the routed direction loses positive alignment
with the exact gradient? We test this branch-conflict boundary, and hierarchy
matching under restricted feedback, in two controlled tasks.

\subsection*{Branch-specific learning signals are required when local updates conflict}

Ordinary image classification did not require distinct learning signals for
different branches. We therefore hypothesized that branch-specific feedback
would become necessary when simultaneously driven branches required updates
of opposing sign. To isolate feedback routing from shunting and serial
dendritic computation, we used a deliberately minimal model: one binary
logistic output unit with \(B\in\{2,4,8\}\) parallel, one-stage branch weight
vectors, with no internal compartments or conductance nonlinearity
(Fig.~\ref{fig:branchconflict}A,B).

On every trial \(i=1,\ldots,N\), all \(B\) branches received a pooled
Fashion-MNIST image \(\bm x_{i,b}\) and formed a nonzero local eligibility
vector. A context cue \(b_i^\star\) selected the single branch whose weighted
input determined the somatic logit, and the class of that selected image
defined the binary target \(y_i\in\{0,1\}\). Each nonselected branch received
the same image at conflict dose \(\chi=0\) and was independently replaced by
an opposite-class image with probability \(\chi\). Thus \(\chi\) changed the
compatibility of branchwise update directions without changing the forward
model or feedback resources within a given \(B\). At \(\chi=0\), the required
branch updates agreed and a neuron-shared signal should suffice. As \(\chi\)
increased, nonselected branches increasingly required the opposite update,
predicting a loss of descent alignment for the shared signal.

Let \(\delta_i=\sigma(z_i)-y_i\) be the output error and let \(\bm d_b\)
denote the update direction for branch \(b\). Branch-specific feedback and one
neuron-shared learning signal produced
\begin{equation}
\bm d_b^{\mathrm{branch}}
=\frac{1}{N}\sum_{i=1}^{N}\delta_i\,\mathbb 1[b_i^\star=b]\,\bm x_{i,b},
\qquad
\bm d_b^{\mathrm{shared}}
=\frac{1}{N}\sum_{i=1}^{N}\delta_i\,\frac{1}{B}\,\bm x_{i,b}.
\label{eq:branchconflictupdates}
\end{equation}
Correct branch-specific feedback contains the selector
\(\mathbb 1[b_i^\star=b]\), which keeps example \(i\)'s error in branch
\(b\)'s update only when \(b\) was the context-selected branch
\(b_i^\star\) on that trial; the shared rule does not. The factor \(1/B\) only matches
update scale and contributes no branch information. The selector can be
carried by the learning signal or, equivalently, by a branch-local eligibility
gate (Fig.~\ref{fig:branchconflict}B).

For centered binary class evidence, the expected compatibility matrix between
the selected and branch-local updates is
\begin{equation}
C_\chi=(1-2\chi)\bm 1\bm 1^{\mathsf T}+2\chi I,
\label{eq:branchcompatibility}
\end{equation}
where \(\bm 1\in\mathbb R^B\) is the all-ones vector and \(I\) is the identity.
Its shared-mode eigenvalue is
\(\lambda_{\mathrm{shared}}=B-2\chi(B-1)\), whereas each of the \(B-1\)
branch-contrast modes has eigenvalue \(2\chi\). The shared-mode eigenvalue is
the branch-space analogue of the retained-signal term
\(\bm\mu^{\mathsf T}M\bm\mu\) in Eq.~\ref{eq:creditoperatorbound}. The shared
update therefore ceases to be a descent direction at
\(\chi_c=B/[2(B-1)]\): \(1\), \(2/3\) and \(4/7\) for \(B=2,4,8\),
respectively. The predicted failure moves to lower conflict as the number of
branches receiving distinct inputs increases (Fig.~\ref{fig:branchconflict}C).

The trained networks followed this prediction (Fig.~\ref{fig:branchconflict}D,E).
At zero conflict, branch-specific and shared feedback were practically
equivalent. Their difference grew monotonically with \(\chi\), and
branch-specific feedback gained 35--58 percentage points at full conflict.
The empirical failure points of the shared rule closely followed the three
analytic boundaries (Fig.~\ref{fig:branchconflict}F), including the predicted
shift toward lower conflict as branch count increased.

The positive effect depended on delivering the signal to the correct branch.
A cyclic route with identical rank and sparsity failed at full conflict.
Conversely, analytic backpropagation and a grouped-point model with the same
explicit branch gate matched correct routing exactly: the three are
algebraically equivalent forms of the same routing matrix, so their numerical
agreement verifies the implementation. The task therefore establishes
when branch-specific information is required by a local update; it does not
claim that a dendritic tree is the only possible implementation
(Fig.~\ref{fig:branchconflict}E and Supplementary Fig.~S29).

The branch-conflict experiment compared one shared learning signal with complete
\(B\)-way resolution. We next asked whether nested subtrees provide an
efficient partial address when only \(K<B\) feedback channels are available.

\subsection*{Tree-structured feedback helps only at matched resolution and topology}

The branch-conflict task compared one neuron-shared signal with complete
branch-specific feedback. The next question is whether nested subtrees provide
an efficient intermediate representation when neither extreme is available.
We hypothesized that such routes would help only when the required update field
had a matching hierarchy and the feedback was neither fully shared nor fully
resolved.

We used a single-output model with eight independent, eight-dimensional
terminal parameter blocks. The blocks occupied the leaves of an abstract
balanced binary routing tree with three bifurcating levels, but only the
context-selected terminal block determined the logit; all eight input streams
remained active and formed eligibility traces. Internal tree nodes defined
nested feedback supports and did not compute serial forward states. The
hierarchy in Fig.~\ref{fig:subtreefactorial}A generates the task, whereas the
tree in Fig.~\ref{fig:subtreefactorial}B is a candidate feedback morphology.

Here \(K\in\{1,2,4,8\}\) is feedback bandwidth within one neuron: the number
of independently communicated route coefficients, not the number or depth of
compartments. At \(K=1\), one coefficient is shared across all terminal blocks;
at \(K=8\), each block receives its own coefficient; intermediate values
address progressively finer nested subtrees. The task-matched route matrix used
supports from the same hierarchy as the distractors. Correct versus cyclically
deranged assignment tested whether each signal reached its intended subtree;
matched versus degree- and depth-preserving rewiring tested task--topology
alignment; and matched subtrees versus rank-matched non-anatomical route
families tested whether ancestry added value beyond bandwidth alone
(Fig.~\ref{fig:subtreefactorial}C,D). Flat, grouped-point and explicitly gated
point implementations receiving the same route matrix tested implementation
equivalence. Forward parameter blocks and feedback rank were matched within
each comparison.

Increasing \(K\) improved the correctly routed model, whereas assigning the
same channels to the wrong subtrees caused large losses
(Fig.~\ref{fig:subtreefactorial}E,F). Thus within-neuron addresses matter when
different parts of the model require different updates. The stronger
anatomical question had a narrower answer. Task-matched subtrees were worse
than the best non-anatomical low-rank control at small bandwidth, better by
only 1.3 percentage points at the intermediate budget \(K=4\), and equivalent
at full resolution. Low-rank task bases were more efficient when very few
signals were available; at full rank, every branch could be addressed and the
choice of basis no longer mattered.

The intermediate effect required alignment between task hierarchy and tree
topology. Degree- and depth-matched rewiring removed the benefit at
\(K=2\) and \(K=4\), but had no effect when the signal was either fully shared
or fully resolved (Fig.~\ref{fig:subtreefactorial}G). Dendritic, flat,
grouped-point and explicitly gated point implementations behaved identically
when they received the same routed field. The effect therefore follows from
the structure of the feedback assignment, not from dendritic material alone.
Accordingly, the large correct-minus-deranged contrast is evidence for
within-neuron address information, whereas the much smaller
matched-minus-non-anatomical contrast is the evidence specific to an ancestry
basis. These two claims are distinct.

As predicted by the operator analysis, field capture explained the large
failures caused by insufficient bandwidth or incorrect assignment, but it did
not determine every trained outcome. Route families with similar capture
sometimes learned differently (Supplementary Fig.~S23), consistent with the
additional roles of alignment, route gain and stochastic noise.

\subsection*{Serial dendritic computation helps only when its operations match the task}

The preceding experiments varied how a learning signal was routed while the
forward computation remained shallow. We next asked a separate question: when
does composing nonlinear operations across serial dendritic compartments help
the forward task? Feedback-route resolution \(D_{\mathrm r}\) describes the
backward pathway, whereas \(D_{\mathrm p}\) is the number of serial stages in
the forward morphology. We display one- through four-stage architectures as
D1--D4; these are cohort-specific model labels, not cell types.

Unlike the abstract branch and routing models in
Figs.~\ref{fig:branchconflict} and \ref{fig:subtreefactorial}, these networks
contained explicit child-to-parent conductance stages whose states were
composed in the forward pass. Each network had one population of 64 somata and
eight nonsomatic compartments per soma. D1 \([8]\) has eight one-stage
branches; D2 \([2,3]\) has two proximal and six distal compartments; and D3
\([2,1,2]\) has two proximal, two middle and four distal compartments. The
four-level experiment additionally used D4 \([1,1,2,2]\), with one, one, two
and four compartments from proximal to distal. These morphologies redistribute
the same eight nonsomatic units across serial stages while preserving the
matched contact and trainable-resource inventory.

Increasing \(D_{\mathrm p}\) was harmful on the ordinary fixed-budget tasks
above, echoing the regular-tree depth boundary (Supplementary Fig.~S4A).
We therefore asked a more specific question: can serial compartments
help when each stage performs an operation required by the task? We designed a
positive-rate classification problem in which the class signal was multiplied
by nuisance gains at fine, coarse and global scales. Schematically,
\begin{equation}
x_j^E=s_y\prod_{\ell=1}^{H_{\mathrm p}}h_{\ell,a_\ell(j)},
\label{eq:physicaldepthtask}
\end{equation}
where \(s_y\) carries the class, \(a_\ell(j)\) maps input \(j\) to its group at
hierarchy level \(\ell\), \(h_{\ell,a_\ell(j)}>0\) is that group's gain and
\(H_{\mathrm p}\) is the number of physical-task gain levels. Separate
inhibitory sensor inputs
reported these gains by opening nonnegative conductances with
\(E_{\mathrm I}=0\). They are forward inputs, not learning signals; in the
normalized conductance equation they increase the denominator without adding
to the numerator. A shunting stage could
divide out one factor, so a serial tree could remove the factors in
distal-to-proximal order before decoding the class
\citep{holt1997shunting,carandini2012normalization}.
The nested-factor, flat-factor and local-ratio task structures used below are
shown in Fig.~\ref{fig:physicaldepth}A. We compared the serial tree with a
resource-identical parallel grouped-point model and a more flexible
parameter-matched point-network ceiling (Fig.~\ref{fig:physicaldepth}B).

The critical manipulation was the relation between sensor placement and this
task hierarchy. In the aligned condition,
each stage received the sensor for the factor acting at that level.
Independent sensors preserved the same distribution but not the trial-wise
factor, trial shuffling broke example-wise correspondence and reversed
placement supplied the correct sensors in the wrong serial order. Across
D1--D3, the serial and grouped-point models had identical numbers of
nonsomatic units, input contacts and trainable parameters. Because the task
and operating point were deliberately chosen to
match serial divisive computation, this experiment is an existence test for a
mechanism, not an estimate of its prevalence in natural tasks.
The design separates three predictions. If ordered divisive composition is
useful, aligned serial trees should improve with depth and outperform the
resource-matched parallel control. This benefit should disappear when sensors
are independent, shuffled across trials, placed in reverse order, or when the
conductance computation is replaced by raw-additive integration. Finally, if
serial differentiation increases the demand for resolved credit, exact
compartment feedback should exceed one somatic learning signal repeated
through the tree. The flexible parameter-matched MLP is an expressivity ceiling
rather than a morphology-matched control.

With backpropagation, aligned D3 models outperformed aligned D1 models by 30.9
percentage points (Fig.~\ref{fig:physicaldepth}C). In matched control conditions,
the D3-minus-D1 effect was near zero for independent and trial-shuffled
sensors, and reversing sensor order removed the benefit (Supplementary
Information and Supplementary Fig.~S18F--H). Additional stages were therefore
useful only when their order matched the latent structure of the task.

The forward benefit remained under local learning, but its size depended on
feedback resolution (Fig.~\ref{fig:physicaldepth}C). Repeating one somatic
learning signal throughout the tree retained part of the D3 benefit, whereas
the exact compartment-resolved signal recovered an additional 11 points at
D3. As serial stages differentiated branch states, a shared somatic signal
became less aligned with the exact gradient. Reversing the sensor order removed
both local-learning benefits. Optimizer-matched automatic-differentiation
controls reproduced this separation (Supplementary Fig.~S28).
Exact-path LocalCA denotes exact path transport, not optimizer identity:
LocalCA and backpropagation used learning rates fixed separately before this
comparison, so their trained endpoints need not coincide.

The remaining controls locate the effect in ordered divisive composition. A
raw-additive tree became worse with depth, and a
resource-identical parallel grouped-point model could not reproduce the
aligned serial computation (Fig.~\ref{fig:physicaldepth}B,C). More flexible
parameter-matched point networks exceeded the serial tree
(Fig.~\ref{fig:physicaldepth}B,C). Serial dendritic depth is therefore a
task-matched inductive bias under constrained architecture, not a general
expressivity advantage over point networks.

Useful depth also saturated. The independent two-level task compared D1
\([8]\) with D2 \([4,1]\), which has four proximal and four distal
compartments per soma; the three- and four-level tasks used the morphology
ladders defined above. The two-level task benefited from D2, whereas the
four-level task reached its best performance at D3 rather
than D4 (Fig.~\ref{fig:physicaldepth}D,E). The fourth serial stage still
outperformed D1 but added transport and optimization costs without improving
the representation beyond D3. Physical depth therefore does not obey a
universal \(D_{\mathrm p}=H_{\mathrm p}\) rule, even when the task contains
\(H_{\mathrm p}\) hierarchical factors.

The benefit required strong task--sensor alignment. We varied alignment
continuously by correlating each sensor with the corresponding latent gain:
\(\alpha=0\) made them independent and \(\alpha=1\) made the sensor exact.
Serial depth provided little benefit until alignment approached one
(Fig.~\ref{fig:physicaldepth}F,G and Supplementary Fig.~S18). A
parameter-matched parallel grouped-point model
remained flat even at complete alignment, and reversing sensor order removed
the serial advantage. These controls separate ordered composition from sensor
availability and parameter count.

To test task specificity directly, we fixed the architecture at D3 and changed
what computation was required (Fig.~\ref{fig:physicaldepth}A,F,G). The
\emph{nested-factor} task was the hierarchical problem above. The
\emph{flat-factor} task preserved the multiplicative factors but distributed
them across non-nested groups. The \emph{local-ratio} task placed each
signal--nuisance ratio within one stage, so no serial cancellation was needed.
The serial model outperformed the parallel grouped-point control on nested and
flat factors, but not when the relevant ratios were already locally available.
With the local learning rule, serial depth was detrimental in the local-ratio
task. Dendritic depth therefore helps only when the forward computation
requires composition across stages; otherwise it adds unnecessary transport
and optimization cost.

\subsection*{Reconstructed arbors provide sparse but mostly coarse feedback routes}

The controlled tasks establish what a dendritic address can compute. The next
question is whether reconstructed dendritic geometry supplies a sparse basis
for compartment-resolved credit. We hypothesized that descendant subtrees
would capture more field energy per feedback connection than equally sparse
dictionaries that ignore branch ancestry. We tested this prediction with both
an independently generated cable-response field and a deliberately
route-generated positive control
\citep{kornfeld2020anatomical,weis2025morphology}.

Here and below, a reconstructed arbor is a soma-rooted MICrONS dendritic
skeleton compressed into branch-to-branch cable segments, with mapped synaptic
contacts assigned to those segments. The morphology and contact locations are
reconstructed data. Conductances, voltages, gradient fields and feedback routes
are modeled unless we explicitly refer to measured visual responses. The
analyses in Figs.~\ref{fig:topology} and \ref{fig:focal} therefore test
structural capacity and biophysical sensitivity, not endogenous use of a
learning signal.

In each reconstructed cell, every branch point defined one nested-subtree
route containing all input-bearing descendant segments
(Fig.~\ref{fig:topology}A,B). At route budget \(K\), the resulting dictionary
spanned a \(K\)-dimensional approximation to a modeled compartmental credit
field. Field capture was the fraction of synaptic-area-weighted field energy
retained by the optimal projection. A dense rank-\(K\) basis provided the
unconstrained ceiling; random anatomical paths, depth bins, site-shuffled
routes and degree--depth surrogate trees tested progressively weaker forms of
anatomical organization.

We first used an initial convenience sample of eight reconstructed
intratelencephalic neurons from one MICrONS mouse. To generate a target
independently of the subtree dictionary, we applied small focal shunts
throughout each reciprocal cable model and measured the resulting exact
gradient-response operator. Nested-subtree routes captured more of this
cable-derived field than random paths, depth bins or site-shuffled routes
(Fig.~\ref{fig:topology}C). Degree--depth surrogate trees recovered much of
the advantage, indicating that its principal contribution came from coarse
depth and branching geometry rather than fine branch identity.

As an aligned positive control, we generated fields by applying independent
coefficients to the conductance-weighted ancestry routes themselves. Subtree
dictionaries also performed best in this deliberately route-generated
condition (Fig.~\ref{fig:topology}D; route-support and direct-type controls in
Supplementary Fig.~S20). This result demonstrates the capacity available under
route--field alignment; it is not independent evidence that biological credit
fields have this form.

The route-generated condition also exposed the wiring trade-off. With eight
channels, subtree routes retained 85\% of the dense-oracle capture while using
about 7\% of its feedback connections (Fig.~\ref{fig:topology}E). Across route
budgets, this corresponded to a 14.2-fold capture-per-connection advantage over
the dense oracle but only a 2.7-fold advantage over the more stringent
density-matched shuffled control (Fig.~\ref{fig:topology}F). These counts do
not estimate cable length, metabolic cost or connection reliability.

We then repeated the predefined \(K=4\) route-generated comparison in two
additional cohorts. A non-overlapping 47-cell cohort from the same mouse
reproduced the route ordering, and all ten qualifying cells from a second
MICrONS mouse showed the same direction relative to random paths, depth bins
and shuffled routes (Fig.~\ref{fig:topology}G and Supplementary Figs.~S10,
S27). The second volume provides one independent-animal replication of
structural capacity; it does not test endogenous route use.

Two additional analyses qualified the interpretation. Tree-Haar modes
confirmed that real arbors are multiscale, but did not establish a fine-topology
enrichment beyond a shuffled subtree control (Supplementary Fig.~S25).
Inhibitory contacts showed class-dependent spatial scales and local
co-targeting, but the effects weakened after aggregation by presynaptic axon
and joint geometric matching (Supplementary Fig.~S12). Reconstructed arbors
therefore provide sparse candidate addresses, predominantly through coarse
geometry; these analyses do not show that the addresses carry learning signals
in vivo.

\subsection*{Focal shunting regulates modeled route gain in high-conductance regimes}

Structural capacity alone does not show that conductance can regulate a route.
We therefore tested a route-gain mechanism: whether a focal inhibitory
conductance changes transport of a fixed somatic loss gradient more strongly
within its descendant subtree than at depth-matched off-route sites. We
compared the shunt with a current injection that matched its baseline focal
current and restored the same somatic voltage. No network was trained; the
endpoint was the change in the exact modeled excitatory-conductance gradient
on reconstructed arbors. In the primary normalized cable model,
\(E_{\mathrm E}=1\) and \(E_{\mathrm I}=-0.2\). For the passive residual
\(G\bm V=\bm b\), \(G\) is the conductance matrix, \(\bm b\) is the source-current
vector and \(\bm e_k\) is the unit vector at compartment \(k\). Adding an
inhibitory conductance \(\kappa_k\geq0\) there changes both the voltage
operator and its source:
\begin{equation*}
G'=G+\kappa_k\bm e_k\bm e_k^{\mathsf T},
\qquad
\bm b'=\bm b+\kappa_k E_{\mathrm I}\bm e_k .
\end{equation*}
At the baseline voltage, these two changes produce the focal current
\(\kappa_k(E_{\mathrm I}-V_k)\). We therefore compared the shunt with a
baseline-current-matched current injection at the same site. This focal
injection is not the raw-additive network defined above: it changes the source
current but not the conductance operator.
After either intervention, a separately solved somatic current restored the
baseline somatic voltage. This control matches focal first-order current and
somatic state, not the local dendritic voltage; only the shunt changes the
conductance operator that transports the error
(Fig.~\ref{fig:focal}A). Regular-tree parameter sweeps provide broader regime
checks (Supplementary Figs.~S1--S4).

Let \(s\) denote the somatic compartment and \(\bm e_s\) its unit vector. Define
\(\bm q=G^{-1}\bm e_s\,\partial\mathcal L/\partial V_s\) as the adjoint of a
somatic loss. Adding a focal shunt \(\kappa_k\) at compartment \(k\) gives, by
the Sherman--Morrison identity,
\begin{equation}
\bm q'=\bm q-
\frac{\kappa_k q_k}{1+\kappa_k(G^{-1})_{kk}}G^{-1}\bm e_k .
\label{eq:sherman}
\end{equation}
The inhibitory reversal does not appear in Eq.~\ref{eq:sherman} because this
equation isolates transport through \(G'\). It enters the forward voltage
through \(\bm b'\) and the complete synaptic gradient through the driving force
\(E_{\mathrm I}-V_k\); the full perturbation calculation includes both effects.
The scalar prefactor sets the magnitude of the change, whereas the
Green's-function column \(G^{-1}\bm e_k\) determines its spatial spread. A
focal site can selectively control a descendant route only if this column is
larger below the branch than at comparable locations elsewhere. Let \(D(k)\)
contain descendants of \(k\), and let \(C(k)\) contain the predefined
depth-matched off-route sites. We quantify this condition by
\begin{equation}
S_k=\frac{\operatorname{median}_{i\in D(k)}|(G^{-1})_{ik}|}
{\operatorname{median}_{j\in C(k)}|(G^{-1})_{jk}|}>1,
\label{eq:selectivitycriterion}
\end{equation}
Thus \(S_k>1\) indicates a descendant-enriched transport
kernel. To measure the perturbation itself, we used a \emph{localization
index}: the median absolute log change in synaptic gradient below the focal
branch minus the same quantity at depth-matched off-route sites. Positive
values mean that the perturbation changes descendant gradients more strongly.
Neither measure assumes that inhibition computes the error signal
\citep{gidon2012inhibition}.

We applied the matched perturbations to the initial eight MICrONS mouse-1
reconstructions. In the permissive dimensionless passive model, the shunt
changed descendant gradients more strongly than ancestral, sister-subtree or
depth-matched off-route gradients, whereas the matched current injection was
less selective (Fig.~\ref{fig:focal}B). The descendant-minus-depth-control
localization index increased with shunt dose (Fig.~\ref{fig:focal}C).
Retaining the post-shunt voltage while replacing the post-shunt adjoint with
its baseline value removed most of the localization
(Fig.~\ref{fig:focal}D), as did a complementary factor decomposition. These
controls attribute the modeled gradient change to conductance-dependent error
transport rather than to the shared baseline focal current or restored somatic
voltage.

Adding voltage-dependent Na, K, Ca, HCN and NMDA conductances preserved the
dose-dependent effect in the permissive high-conductance model
(Fig.~\ref{fig:focal}E). This active-conductance model recomputed the exact local
steady-state Jacobian but did not simulate channel kinetics.

Physical calibration then located the boundary of the effect. We repeated the
same perturbation in both the initial eight-cell sample and a non-overlapping
45-cell cohort from the same MICrONS mouse. Selectivity was absent at standard
passive cable parameters. At
\(R_a=150\,\Omega\,\mathrm{cm}\) and
\(R_m=15{,}000\,\Omega\,\mathrm{cm}^2\), the shunt-minus-current-injection contrast was
effectively zero in both cohorts. Localization emerged only when membrane
resistance was lowered or background conductance was added
(Fig.~\ref{fig:focal}F), consistent with high-conductance in vivo states
\citep{chance2002gain,destexhe2003highconductance}. Spatial selectivity is
therefore governed by the local Green's-function column and electrotonic
length, not by a global inverse-operator norm.

Across cells, the active-model shunt-minus-current-injection contrast remained positive
in that permissive regime (Fig.~\ref{fig:focal}G). The active-conductance model does
not rescue the standard-passive null or show that inhibitory synapses carry
learning signals in vivo. Together, these results identify a state-dependent
mechanism by which shunting can regulate modeled route gain; they do not
establish a general learning benefit of inhibition.

\subsection*{Measured visual responses do not reveal morphology-specific learning signals}

Structural capacity and modeled route gain do not establish that biological
activity uses dendritic routes. We therefore asked whether measured visual
input--output relations were preferentially aligned with reconstructed subtree
spans. The cohort comprised seven of the initial eight MICrONS targets for
which complete reconstructed arbors, mapped functionally imaged presynaptic
partners and repeated visual responses were all available.

For each target, the task was to predict the target cell's response on held-out
stimulus identities. Measured presynaptic responses entered the complete
reconstructed passive tree at their mapped contact locations. The forward
morphology, inputs and initialization were identical across learning
conditions. Exact learning used the trial-specific compartment-error field.
Each restricted rule instead multiplied that trial's scalar output error by
one spatial vector fixed before training: the baseline soma-to-site transfer
profile projected into a four-route nested-subtree, random-path or
site-shuffled dictionary (Fig.~\ref{fig:boundary}A). Thus these conditions
test fixed spatial alignment of a scalar learning signal; they do not provide
four independently varying route coefficients.

If measured task credit were aligned with branch ancestry, the nested-subtree
rule should reduce held-out prediction error and capture more of the exact
trained field than the matched controls. It did neither. Exact compartment
errors gave the lowest normalized mean-squared error, whereas nested subtrees
were indistinguishable from random and site-shuffled routes across the seven
targets (Fig.~\ref{fig:boundary}B,C). A complementary prediction---that
presynaptic partners mapped to the same subtree should have more similar visual
responses after controlling for Euclidean separation and dendritic depth---was
also unsupported (Fig.~\ref{fig:boundary}C). Together, the three predefined
endpoints in panel C provide no evidence for morphology-specific alignment in
this cohort. A coarser major-branch analysis was additionally limited by a
nearly rank-one response-derived field and was also null (Supplementary
Fig.~S22). These within-arbor tests do not contradict broader like-to-like
wiring at the population scale \citep{ding2025wiring}.

The operator theory makes a positive conditional prediction: the same fixed
routes should become useful when the task field is rotated into their span. We
tested this sufficiency claim on all eight initial reconstructions. For each
cell, we fixed an eight-route subtree dictionary and constructed a unit-energy
synthetic gradient
\begin{equation*}
\bm g(a)=\sqrt a\,\bm u_{\parallel}+\sqrt{1-a}\,\bm u_{\perp},
\end{equation*}
where \(a\) is the fraction of field energy in the subtree span
(Fig.~\ref{fig:boundary}D). Anatomy, route count, field norm and curvature
were held fixed while \(a\) varied. Subtree capture rose from zero at
orthogonality to one at complete alignment and crossed the random-path,
depth-bin and site-shuffled controls as alignment increased
(Fig.~\ref{fig:boundary}E). This controlled rescue establishes sufficiency in
the model; the field direction and coefficients were imposed rather than
inferred from biological activity (Supplementary Fig.~S5).

The final comparison addresses neuron-specific coordinates only and uses
neither the MICrONS morphologies nor a within-arbor routing manipulation. At
the neuron level, we reanalyzed the
six-animal causal P+/P- brain--computer-interface experiment of Francioni et
al. \citep{francioni2026vectorized}. Its published mapping assigns opposite
signs to two selected neurons. In a signed-versus-common coordinate basis, the
source contrast for animal \(m\) was
\(s_m=\Delta_m^{P+}-\Delta_m^{P-}\), where each \(\Delta\) is the published
change in soma--dendrite residual. This contrast separated the two neuronal
coordinates in all six animals, with most projection energy in the signed
rather than common mode
(Fig.~\ref{fig:boundary}F). This retrospective re-expression is consistent
with neuron-specific learning signals, but it is not an independent test of
their existence and provides no evidence about routing within an arbor
(Supplementary Fig.~S17).

The resulting evidence ladder separates supported neuron-specific
coordinates, conditional subtree addresses and route gain, and the presently
unestablished endogenous use of morphology-specific routes
(Fig.~\ref{fig:boundary}G).

\section*{Discussion}

Our study separates three questions that are often grouped together as
dendritic credit assignment. First, how does a circuit deliver the appropriate
learning signal to each neuron? Second, when must that signal distinguish
locations within the neuron? Third, can dendritic conductance regulate its
local gain? The exact conductance gradient gives these questions a common
form: a synapse-local eligibility is multiplied by a compartment-specific
error transported through the arbor. Dendrites do not generate the
circuit-level error. They can instead provide addresses and state-dependent
gains for distributing it.

On ordinary image tasks, the dominant limitation was selecting the correct
neuron. One learning signal per neuron recovered most of the deficit produced
by a layer-wide scalar on MNIST, Fashion-MNIST and flattened CIFAR-10. Exact
compartment-resolved feedback then added little and was not consistently
better than repeating the neuronal signal throughout the arbor. This result is
important because it rejects a generic claim: greater dendritic feedback
resolution is not automatically useful on a harder task.

Branch-specific information became necessary only when the task required it.
In the context-gated branch-conflict task, shared and branch-specific signals
were equivalent while all branch inputs supported the same class update. As
off-route inputs increasingly supported the opposite class, the shared update
crossed the predicted branch-count-dependent boundary and ceased to be useful.
The same selector could be implemented by feedback to a dendritic branch or by
a branch-local gate in a grouped-point model. The result establishes the
information needed by the learning rule, not a uniquely dendritic mechanism.

The credit-operator theory generalizes this boundary. A restricted pathway is
useful when the task-aligned gradient signal that it preserves outweighs the
signal it discards and the stochastic noise it admits. This trade-off predicts
the large within-family effects and explains why route resolution has an
interior optimum. Nested-subtree feedback is therefore competitive only when
its bandwidth and hierarchy match the task: unrestricted low-rank bases are
better at very small bandwidth, subtree structure provides a small advantage
at an intermediate budget, and all full-rank bases become equivalent. The
theory does not imply that a restricted update can outperform the exact
full-batch gradient, nor does its one-step bound predict every small advantage
accumulated over a training trajectory.

This framework also clarifies the relation to backpropagation. Backpropagation
computes the exact nonlocal error at every node. A biological local rule must
replace that field with learning signals available to the synapse. Dendritic
addresses can reduce the spatial approximation error within one neuron, but
only after another circuit mechanism has produced a neuron-specific learning
signal. Dendritic routing and feedback alignment therefore address
complementary parts of credit assignment: one specifies the within-neuron
basis, whereas the other concerns how a feedback pathway obtains and aligns
the neuronal signals.

Serial dendritic depth is a separate forward-computation question. At matched
resource budgets, serial shunting stages helped when their distal-to-proximal
order mirrored the divisive operations required by the task. Independent,
shuffled or reversed sensors removed the benefit, and depth became unnecessary
when the relevant ratios were already available locally. Useful depth also
saturated before the maximum task hierarchy. Flexible point networks remained
more expressive, so the result is a constrained inductive bias rather than a
universal advantage. Forward depth also increased the need for spatially
resolved credit because branch states diverged across serial stages.

Reconstructed arbors provide a plausible, wiring-efficient implementation of
such addresses. Subtree routes represented modeled compartment fields with a
small fraction of the connections required by a dense feedback basis, and the
direction of this structural result replicated in a second MICrONS animal.
Most of the capacity was nevertheless explained by coarse depth and branching
geometry; the additional contribution of fine topology was weaker and
field-dependent. The anatomical result is therefore the availability of
sparse, mostly coarse addresses, not their use during learning.

Focal shunting can regulate route gain, but only in particular conductance
states. A shunt changes the Green's-function adjoint, whereas a
baseline-current-matched current injection does not change the transport
operator. The resulting
descendant-localized gradient change appeared in high-conductance and active
steady-state models but vanished at the standard passive calibration. This
state dependence is consistent with high-conductance gain modulation
\citep{chance2002gain,destexhe2003highconductance} and spatial inhibitory
domains \citep{gidon2012inhibition}. Reliability-aligned shunts improved over
misplaced attenuation but not over unshunted noisy learning. This backward
route-gain role differs from forward gain--load robustness
\citep{safaai2026gainload} and from circuits in which inhibition computes the
error itself \citep{rossbroich2023disinhibitory,galloni2026cellular,
greedy2026celltype}.

The measured-response analyses define the biological boundary. Neither the
complete-tree prediction task nor the structure--function analysis detected
morphology-specific alignment in the analyzed MICrONS cells. Rotating a
controlled task field into the same anatomical span rescued capture, showing
sufficiency without endogenous use. The external P+/P- reanalysis was
consistent with distinct neuronal learning signals but did not test
within-arbor routing. Alignment constraints at the population-manifold level
provide a related principle at a different scale
\citep{sadtler2014constraints}.

This separation distinguishes the present work from neighboring dendritic
learning theories. Dendritic nonlinearities expand forward single-neuron computation
\citep{poirazi2003pyramidal,london2005dendritic,branco2010single,chavlis2025dendrites},
whereas our operator theory asks how limited feedback is routed. Segregated,
predictive and burst-based models deliver teaching signals to one or a few
compartments \citep{urbanczik2014dendritic,guerguiev2017segregated,
sacramento2018dendritic,payeur2021burst}; here the object is the address span of
a complete arbor. Detailed-arbor optimization uses cable
sensitivities to train a single neuron's input--output function
\citep{bicknell2021synaptic}; here circuit-derived error defines a compartment
field that must be compressed under bandwidth, alignment and noise
constraints. Engineered active-segment and gating systems demonstrate useful
routing designs \citep{sezener2021gated,iyer2022activedendrites,lv2025dendritic}.
Developmental teaching alignment and signed connectomic error motifs provide
complementary circuit-level precedents
\citep{meier2026criticalperiod,penafernandez2026signedxor}.

The framework yields a branch-resolved experimental prediction. After matching
baseline somatic voltage, focal first-order current and the global error, focal
dendrite-targeting inhibition during learning should alter later plasticity
more strongly below the targeted branch than at electrotonically matched sites
on sister subtrees. The contrast should scale with perturbation conductance and
the focal Green's-function column, strengthen in high-conductance states and
disappear for a baseline-current-matched current injection. Combining
dendritic recording, focal
inhibition and longitudinal spine imaging could separate learning-signal
routing from forward gain control
\citep{francioni2026vectorized,cichon2015branch,bloss2016structured}.

Several limitations keep this conclusion conditional. The theory treats
steady-state, non-spiking trees, and the reconstructed-cell analyses are
sensitivity models rather than physiological fits. The second animal tests
only structural capacity; the functional sample is small; route coefficients
are estimated by oracle projection; and the external animal analysis is
retrospective. The branch-conflict and physical-depth tasks are deliberately
mechanism-matched existence tests, not estimates of how often natural learning
requires the same operations. A branch selector can also reside in feedback or
in local eligibility. The active-conductance analysis linearizes steady states rather
than simulating channel kinetics. Temporal eligibility, recurrence, spikes,
plateau potentials and behavioral-timescale plasticity remain outside the model
\citep{bittner2017btsp,magee2020plasticity}.

Within these limits, dendritic structure has a positive but specific role in
local learning. Neuron-specific learning signals carry most of the useful
feedback. Subtrees can provide sparse within-neuron addresses, conductance can
regulate their gain in high-conductance states, and task alignment determines
whether those resources improve learning or instead add bias, noise and
transport cost.

\section*{Methods}

We first define the conductance tree and local learning rule, then describe the
controlled simulation families and reconstructed-arbor analyses. Related
implementations and controls are grouped together; the Results provide the
scientific order of the argument.

\subsection*{Notation and terminology}

Neuron, compartment and synapse indices are denoted by $u$, $n$ and $i$,
respectively. The sets \(\mathcal S_n^{\mathrm E}\) and
\(\mathcal S_n^{\mathrm I}\) contain the excitatory and inhibitory contacts on
compartment \(n\). For contact \(i\), \(x_i\) is presynaptic activity, \(g_i\)
is its nonnegative maximal conductance, \(g_ix_i\) is its open conductance, and
\(E_i^{\mathrm{rev}}\in\{E_{\mathrm E},E_{\mathrm I}\}\) is its fixed
reversal potential; \(E_{\mathrm L}\) is the leak reversal and \(V_n\) the
voltage of the host compartment. E/I denotes the forward contact class, not
the sign of \(g_i\), the sign of an update, or the identity of the learning
signal. The exact point-neuron learning signal is
$\delta_u=\partial\mathcal L/\partial y_u$, the somatic voltage error is
$\delta^V_{0,u}=\partial\mathcal L/\partial V_0$, and the exact compartment
error is $\delta^V_{n,u}=\partial\mathcal L/\partial V_n$. A hat denotes an
approximate or restricted learning signal. The steady-state adjoint $q_n$ is
the sensitivity of the loss to a small current at compartment $n$; in the
directed tree, $q_n=R_n^{\mathrm{tot}}\delta^V_{n,u}$. The circuit-output
derivative in Fig.~\ref{fig:framework}B is $\delta_{\rm out}$ and is distinct
from the somatic compartment index $n=0$.

For a regular rooted artificial tree, we write the morphology as
$[b_1,\ldots,b_D]$, where $b_d$ is the number of children per compartment at
nonsomatic stage $d$, ordered from the soma toward the distal tips. Stage $d$
therefore contains $\prod_{r=1}^{d}b_r$ compartments per soma, and the whole
arbor contains $\sum_{d=1}^{D}\prod_{r=1}^{d}b_r$ nonsomatic compartments.
Thus $[3,3]$ has three proximal and nine terminal compartments, $[2,2]$ has
two proximal and four terminal compartments, and $[2,2,2,2]$ has 30
nonsomatic compartments. This notation describes the controlled directed
trees only; it is not used for the irregular reconstructed arbors.

Feedback bandwidth is the number of independently communicated learning
signals at the routing level under study. For within-neuron routing, $K$ is the
number of route signals per neuron, and $N_u$ is the number of routed
nonsomatic compartments in neuron $u$. The example-dependent coefficient vector
$\bm c_u\in\mathbb R^K$ contains the values carried by those signals. The
address matrix $A_u\in\mathbb R^{N_u\times K}$ is fixed within a routing
condition; its $k$th column is the compartmental delivery profile of channel
$k$, and its column space is the route span. Equation~\ref{eq:routedfield}
is a linear delivery model and does not prescribe a biological estimator for
$\bm c_u$. We reserve
$D_{\mathrm r}$ for backward feedback-route resolution and
$D_{\mathrm p}$ for the number of serial stages in the forward model. Display
labels D1--D4 mean $D_{\mathrm p}=1,\ldots,4$; they are architecture labels,
not cell types. We use $H_{\mathrm c}$ for task-credit hierarchy in the
operator experiment and $H_{\mathrm p}$ for the number of latent gain levels
in the physical-depth tasks. Display labels H2--H4 mean
$H_{\mathrm p}=2,\ldots,4$. The task--sensor correlation in the physical-depth
experiments is $\alpha$; the imposed route-span energy fraction in
Fig.~\ref{fig:boundary}D,E is $a$.
BP denotes backpropagation, LocalCA denotes the factorized local-credit rule in
Eq.~\ref{eq:dendriticlocalrule}, and MLP denotes a multilayer perceptron.

\subsection*{Directed conductance-tree network}

Each compartment implemented the current balance in
Eq.~\ref{eq:directedcurrentbalance}. Because coupling was directed from child
to parent, a forward pass evaluated the tree from terminal compartments to the
soma and directly produced the steady state in Eq.~\ref{eq:directedvoltage}; no
iterative equilibrium solver was required for these controlled networks.
Excitatory and inhibitory contact identities and reversal potentials were
fixed within each experiment. The conductance-based artificial trees used
dimensionless leak \(g_n^{\mathrm L}=1\) and reversals
\(E_{\mathrm L}=E_{\mathrm I}=0\), \(E_{\mathrm E}=1\). Their separate E/I
contact arrays need not arise from separate modeled E/I cell populations. The
primary reciprocal-cable focal analysis instead used
\(E_{\mathrm E}=1\), \(E_{\mathrm I}=-0.2\); reversal-potential sensitivity
analyses are reported with that experiment. These voltage conventions were not
fits to membrane potentials in millivolts.

Raw trainable parameters were mapped monotonically to nonnegative
conductances. Both active excitatory and inhibitory contacts were trainable in
the regular-tree BP and LocalCA cohorts. By contrast, the focal perturbation
and reliability-matched shunts were imposed experimental variables rather than
learned inhibitory weights. A compartment could apply the branch-output
nonlinearity
$a_n=f_n(V_n)$ before transmission. The implementation calls this operation
reactivation; $f_n$ was the identity when it was disabled. Supplementary
Section~S1 specifies the parameter transform, complete derivatives and update
order. We checked Eqs.~\ref{eq:factorization} and \ref{eq:pathgain} against
PyTorch automatic differentiation on fixed batches and checkpoints. Parameter
tensors, rather than individual elements, were the units of the reconstruction
diagnostic.

\subsection*{Local learning and feedback fields}

For a mini-batch of size $m$, the implemented three-factor gradient estimate
was
\begin{equation}
\widehat{\nabla}_{g_i}\mathcal L
=\frac{1}{m}\sum_{b=1}^{m}
x_i^{(b)}R_n^{\mathrm{tot},(b)}
\bigl(E_i^{\mathrm{rev}}-V_n^{(b)}\bigr)
\widehat\delta^{V,(b)}_{n,u}.
\end{equation}
The tested fields $\widehat\delta^V_{n,u}$ included strict scalar feedback,
matched-width scalar-fallback feedback,
neuron-specific feedback, low-rank random feedback, selected subtree routes and
exact path transport. A neuron-specific field repeats one somatic coordinate
across all descendants of that soma; it does not provide an independent error
to every compartment.
When $\widehat\delta^V_{n,u}=\delta^V_{n,u}$, the three-factor rule
equals the exact conductance gradient. The exact-transport experiment therefore
separates feedback approximation from local eligibility. Four- and five-factor
variants multiply the three-factor update by bounded, slowly estimated
stage-level reliability terms. We treat these terms as preconditioners rather
than theoretically required teaching signals.

Two additive forward models were used in the regular-tree analyses. The
raw-additive model used in the main comparisons computes the voltage
\(V_{sn}^{\mathrm{raw}}=J_{sn}^{\mathrm E}-J_{sn}^{\mathrm I}
+J_{sn}^{\mathrm{child}}\) before reactivation, where the three \(J\) terms
are aggregate excitatory, inhibitory and child currents. It contains signed
current contributions but no reversal-potential driving forces or
total-conductance denominator (Fig.~\ref{fig:feedback}B--E,G). We denote its
current weights by \(w\).
The analyses in Supplementary Figs.~S1--S3 and S4A,B instead standardize this
voltage separately for each example across the output coordinates of a stage,
\(V_{sn}^{\mathrm{norm}}=(V_{sn}^{\mathrm{raw}}-\mu_s)/
(\sigma_s+\epsilon)\), with fixed reactivation parameters \(m=0.1\) and
\(b=0\). We call this the normalized-additive model. Unless stated otherwise,
additive comparisons in the main figures use the raw-additive model. The
baseline-current-matched current injection in the focal-cable experiment is a
separate intervention rather than a network architecture.

Regular-tree feedback comparisons used MNIST classification with matched
$[3,3]$ morphologies, optimizers, decoders, schedules and paired
initializations within each architecture. All main MNIST comparisons used the
raw-additive model.
The complete feedback ladder crossed
strict scalar feedback, neuron-specific feedback and exact path transport with
two architectures and 15 independently initialized seeds, yielding 90 fits.
In the strict-scalar condition, the decoder-derived somatic error was reduced to one
signed value per example and that value was used at every local-rule stage.
Runs were included if they produced a finite held-out metric and a final
checkpoint under the specified configuration. The three feedback conditions
used the same executable code, environment and scientific settings apart from
seed and feedback mode. The separate exact-transport
rule-by-decoder implementation check used five matched shunting seeds per
condition. Test data remained hidden during checkpoint selection.
Supplementary Section~S5 and Source Data provide complete configurations and
hyperparameters.

The matched-width scalar-fallback implementation retained the 128-dimensional
somatic error at
the 128-wide somatic stage and was reduced to one signed scalar at the 384- and
1,152-wide dendritic stages. Thus every feedforward synaptic update---spanning
2,408,448 candidate parameters and 92,160 active contacts per network---used
scalar feedback. Neuron-specific coordinates reached only 384 final
branch-to-soma couplings and 256 somatic gain and threshold parameters (640 of
2,413,312 core parameters, 0.027\%). A separate 30-fit strict-scalar control
tested whether this near-somatic exception affected the reported accuracy
contrast. Before inspecting its outcomes, we defined practical equivalence as
a 95\% paired-seed bootstrap interval contained within $\pm0.5$ percentage
points.

The primary MNIST accuracy contrasts compared strict scalar feedback with
matched neuron-specific and exact-path conditions
(Fig.~\ref{fig:feedback}B). Matched-width scalar-fallback results are reported
separately to document their relation to the preceding analysis
\citep{safaai2026localcredit}.

For the fixed-checkpoint gradient diagnostic, we used a separate cohort of
fifteen checkpoints per architecture, each trained with neuron-specific
feedback (Fig.~\ref{fig:feedback}C). At each checkpoint, the matched-width
scalar-fallback and neuron-specific fields were evaluated without changing the
weights or forward state. For each nonsomatic branch-parameter tensor, we
computed the cosine between the factorized local-rule gradient and the exact
automatic-differentiation gradient. The plotted statistic is the mean of these
tensor-wise cosines weighted by parameter count; the exactly aligned final
soma-coupling tensor was excluded because it does not test within-arbor
transport. Exact path transport reproduces the exact gradient and therefore
has cosine one by definition. The independently trained checkpoint, indexed
by seed, was the inferential unit.

To quantify error transport within an arbor, we analyzed the thirty final
exact-path checkpoints from the same ladder, identified by their recorded
checkpoint hashes (Fig.~\ref{fig:feedback}D,E). These are the
validation-selected models whose held-out accuracies
Fig.~\ref{fig:feedback}B reports; the saved final and best-validation
states were verified identical tensor by tensor. On one fixed held-out batch
(the first 2{,}048 MNIST test images), automatic differentiation provided the
per-example loss gradient
\(g_{bup}^{(d)}=\partial L_b/\partial V_{up}^{(d)}\) at every dendritic
stage and at the soma, where \(V_{up}^{(d)}\) is the pre-reactivation
compartment voltage used in the forward graph. The diagnostic capture and an
ordinary forward pass produced identical logits at all thirty checkpoints.
Here \(b\) indexes examples, \(u\) indexes neurons and \(p\) indexes paths at
depth \(d\). To obtain the depth profile, the root-mean-square magnitude of
\(g_{bup}^{(d)}\) was divided by the root-mean-square somatic error of neuron
\(u\), then averaged over neurons and paths (Fig.~\ref{fig:feedback}D). This is
the empirical transported-error profile corresponding to the path gain in
Eq.~\ref{eq:pathgain}; the same calculation was applied to both architectures.

To quantify variation among paths at a fixed depth
(Fig.~\ref{fig:feedback}E), we set
\(\bar g_{bu}^{(d)}=P_d^{-1}\sum_{p=1}^{P_d}g_{bup}^{(d)}\) and defined
\begin{equation}
\phi_d^{\mathrm{path}}
=\frac{\sum_{b,u,p}\left(g_{bup}^{(d)}-\bar g_{bu}^{(d)}\right)^2}
{\sum_{b,u,p}\left(g_{bup}^{(d)}\right)^2}.
\label{eq:path-specific-energy}
\end{equation}
Thus \(1-\phi_d^{\mathrm{path}}\) is the fraction of exact-error energy
captured by one path-shared value for each example, neuron and depth. The
ratio was computed once per checkpoint, leaving the independently trained
seed as the inferential unit. The mean profile measures variation between
depths, whereas \(\phi_d^{\mathrm{path}}\) measures variation among paths at
the same depth; the two quantities are complementary
(Fig.~\ref{fig:feedback}D,E). Because both are built from per-example
gradients on held-out data, they do not vanish at convergence: at a trained
optimum only the training-set average of each weight gradient approaches
zero, while per-example transported errors remain finite and cancel in that
average. Both quantities are also invariant to the overall gradient scale,
so they characterize the spatial structure of the trained transport operator
rather than how much learning remains; a large per-example distal error does
not mean the distal synapses are untrained. The conductance-only path-gain dispersion in
Supplementary Fig.~S1A
omits branch derivatives and comes from a normalized-additive cohort; it is
therefore a separate diagnostic rather than an earlier estimate of
Eq.~\ref{eq:path-specific-energy}.

The Fashion-MNIST replication (Supplementary Fig.~S4E) changed only the
dataset. It retained the same
regular $[3,3]$ shunting and raw-additive architectures, 128 somata, contact
counts, three-factor rule, local decoder, architecture-specific initialization,
optimizer and validation-based checkpoint selection. Images were flattened to 784 inputs
without normalization or augmentation. For each of ten seeds (10200--10209), the
60,000-image training set was divided into 48,000 training and 12,000
validation examples. The official 10,000-image test set was evaluated only
after checkpoint selection. These seed labels are also used by the unrelated
physical-depth cohort, but the experiments are independent.

Sixty fits crossed two architectures with matched-width scalar-fallback
feedback, neuron-specific feedback and exact path transport. The primary
replication criterion required the paired neuron-specific-minus-scalar-fallback
interval to exclude zero and at least
8/10 seed differences to be positive in each architecture. Intervals used
50,000 paired-seed bootstrap draws, and exact two-sided sign-flip tests
enumerated all $2^{10}$ assignments. Quality-control criteria required
complete finite results and checkpoints, the specified seeds and no fallback
warning; every run passed.

\subsection*{Regular-tree regime and one-step analyses}

The task, inhibition-dose, depth, broadcast-noise, rule-family, error-source,
mechanism-control, feedback-ladder and shunting-only CIFAR-10 analyses use the
regular-tree configurations described in Supplementary Section~S5. Unless noted
otherwise, each condition contains five independent training seeds. The
three-factor, four-factor and five-factor comparison, together with the
local-mismatch control, contains three seeds and is treated descriptively.
Supplementary Section~S5 describes the synthetic context-gating and
noise-resilience classification tasks. CIFAR-10 images were flattened, with no
convolutional front end, data augmentation or large-scale benchmark claim.
Supplementary Figs.~S1--S4 explicitly label the normalized-additive and
raw-additive models. The
flattened CIFAR-10 panel in Supplementary Fig.~S4C contains only the shunting
architecture.

The independent raw-additive CIFAR-10 confirmation in Supplementary Fig.~S4D
used one 20-soma dendritic population with four branching stages
\([3,3,3,3]\), direct signed input streams with 25 contacts of each sign per
branch and a 20--32--16--10 decoder. The model received direct signed
excitatory and inhibitory input streams and did not instantiate a separate
inhibitory-cell population. A validation-only
BP screen selected the coupled adaptive-initialization and empirical
reactivation-calibration procedure before the four feedback conditions were run.
Twenty seeds (10800--10819) paired strict scalar, neuron-specific, exact
path and matched-backpropagation conditions. All conditions used the raw-additive
model, Adam at \(10^{-3}\), at most 200 epochs, early-stopping patience 40,
zero Adam weight decay and a model-specific sparse active-weight maintenance
rate of 0.01. The superiority family used paired directional \(t\) tests with
Holm correction and exact sign-flip sensitivity tests. Exact path transport and
backpropagation were compared by two one-sided paired \(t\) tests with a
prespecified \(\pm1\)-point equivalence margin. All 80 runs met the predefined
completion, checkpoint and convergence criteria.

The depth-by-feedback experiment was specified before outcomes were
examined. It crossed two tasks, raw-additive and shunting neuron models, four
dendritic depths and three local feedback fields (the
matched-width scalar-fallback feedback, neuron-specific feedback and exact path transport)
at ten seeds. One matched
backpropagation model was
also trained for every task--core--depth--seed combination, yielding 480
local-learning and 160 backpropagation runs. All local conditions used the
factorization-derived three-factor rule.

Configurations fixed the decoder, optimizer, training horizon, reactivation
initialization policy, 40 excitatory and 20 inhibitory contacts per distal
branch, and one population of 128 modeled neurons. The single-population
design prevented equal neuron indices in different feedforward populations
from sharing a teaching coordinate. Because nominal depth changed both
compartment and parameter counts, this experiment was treated as a depth stress
test rather than a capacity-matched comparison.

Each analyzed run had to include its resolved configuration, seed record,
checkpoint, complete learning curves, resource record and finite held-out
metrics. Quality control also required every expected dendritic stage and
excluded critical log errors, nonfinite parameters, degenerate coupling stages
and transport-shape fallbacks. A subsequent outcome-independent conductance-validity
rule excluded 160 synthetic-noise shunting runs because a signed transfer
output cannot parameterize positive conductances. This left 480 eligible
runs. Condition means used ten paired seeds. Paired
contrasts used 20,000 bootstrap resamples and exact two-sided Wilcoxon tests
computed from the ten seed differences.

We specified the neuron-to-arbor ownership control separately
(Fig.~\ref{fig:feedback}F,G). It crossed the two tasks and neuron models at
depths two and four, with either correct
neuron-specific routing or a fixed derangement, across seeds 42--51. The

\subsection*{Within-neuron path-demand and subtree-address experiments}

The path-demand experiment (the context-gated branch-conflict task of
Fig.~\ref{fig:branchconflict} and Supplementary Fig.~S29) used Fashion-MNIST
classes 0 (T-shirt/top) and 6
(shirt) \citep{xiao2017fashionmnist}. Images were average-pooled from
\(28\times28\) to \(7\times7\),
standardized using the binary training split only and augmented with a constant
feature. We denote the conflict dose by \(\chi\), reserving \(\alpha\) for the
sensor-alignment parameter used in
the physical-depth experiments. For each seed and \(B\in\{2,4,8\}\), context--label cells were exactly
balanced. The selected view was sampled from the target class. Every
nonselected branch received the same selected image unless its nested conflict
mask fell below
\(\chi\in\{0,0.25,0.50,4/7,0.60,2/3,0.75,1\}\), in which case it
received an independently sampled opposite-class image. The same underlying
uniform random values were thresholded across doses, so every higher-conflict
condition contained every conflict present at lower doses. All \(B\) branches
therefore received nonzero inputs, but only the context-selected branch
contributed to the somatic readout.

For branch weights \(\bm w_b\), the somatic logit and binary-cross-entropy
error were
\begin{equation}
z_i=\bm w_{b_i^\star}^{\mathsf T}\bm x_{i,b_i^\star},
\qquad \delta_i=\sigma(z_i)-y_i.
\end{equation}
Correct path-resolved feedback used the one-hot coefficient
\(\mathbb 1[b_i^\star=b]\). The neuron-shared condition used \(1/B\) on every
branch, the orthogonal rank-one projection onto the shared branch mode. A
fixed cyclic derangement sent the one-hot coefficient to the next branch while
preserving rank and sparsity. Analytic backpropagation and the explicitly gated
grouped-point control used the same one-hot coefficient as correct routing and
served as implementation-equivalence checks rather than independent evidence.

Each seed used 8,192 balanced training trials and 2,000 balanced test trials
sampled with replacement from the official binary train and test splits,
respectively. Full-batch gradient descent used 250 fixed updates, learning rate
0.04 and Gaussian initialization with standard deviation 0.01. Data,
initialization and conflict masks were paired across feedback conditions and
doses. Three exploratory seeds (100--102) were used only to choose a stable
optimizer and verify that the task spanned compatible and conflicting regimes.
One additional implementation-check seed was excluded from inference; the
fixed configuration was then evaluated with 20 paired analysis seeds
(11000--11019). No outcome-dependent early stopping was used.

The independent inferential unit was the paired seed. The primary estimand was
the within-seed least-squares slope of correct-minus-shared test accuracy on
\(\chi\), evaluated separately for each \(B\). Intervals used 20,000
paired-seed bootstrap draws and two-sided Wilcoxon tests used the 20 seed
differences. The predefined criteria required positive slopes in
at least 16/20 seeds, at least a ten-percentage-point correct-minus-shared
effect at \(\chi=1\), an absolute difference below two points at \(\chi=0\),
correct routing above cyclic derangement at full conflict and exact agreement
among correct routing, backpropagation and the gated-point control. All
criteria were met. The largest analytic-gradient versus automatic-differentiation
discrepancy was \(3.43\times10^{-7}\), and the largest endpoint discrepancy
among implementation-equivalent conditions was zero.

A separate two-stream subtree-address experiment (Supplementary Fig.~S19G
and Supplementary Table~S1) provided a minimal version of this continuous task
family. Its configuration, task parameters, ten analysis seeds and
quality-control criteria were specified before the pilot seed was inspected.

Each example contained two 12-dimensional sibling-stream inputs, a binary
context and a balanced binary label. In the context-selected stream, the input
mean was the label sign multiplied by a seed-specific unit teacher vector. The
other stream had the opposite sign at 0.75 times that amplitude. Independent
Gaussian noise with standard deviation 1.15 was then added. Every training and
test split contained identical counts for all four context--label
combinations. Context therefore had zero correlation with label, both streams
were active, and the inactive stream was a structured distractor rather than a
zero mask.

Write \(c\in\{0,1\}\) for the context, \(\bm x_A,\bm x_B\) for the two
sibling-stream inputs and \(\bm w_A,\bm w_B\) for the weights on the two
branches. The context gates which branch drives the soma. With
\(\mathbb 1[\cdot]\) the indicator, exactly one of the two terms survives
and the other is multiplied by zero, so the somatic logit was
\begin{equation}
z=\mathbb 1[c=0]\,\bm w_A^{\mathsf T}\bm x_A+
\mathbb 1[c=1]\,\bm w_B^{\mathsf T}\bm x_B,
\end{equation}
that is, \(z=\bm w_A^{\mathsf T}\bm x_A\) on context \(c=0\) and
\(z=\bm w_B^{\mathsf T}\bm x_B\) on context \(c=1\). The gate acts on the
two branch sums, not on the inputs: \(\bm x_A\) and \(\bm x_B\) both carry
structured, label-dependent signal on every trial, as described above, so the
unselected stream is a distractor the neuron must learn to exclude rather than
an input that has been switched off. This is what makes the credit-assignment
question non-trivial: the correct \(K=2\) rule must deliver the output error
to the branch the context selected, and the derangement control delivers it to
the sibling that was not selected.
All conditions shared the paired initialization, mini-batches and forward
model. The one-neuron and depth-shared fields applied the logistic output error
to both branches. Correct $K=2$ feedback applied the error only to the selected
sibling, whereas fixed derangement applied it to the other sibling. The random
rank-two control rotated the two context coordinates using a seed-fixed
orthogonal matrix. Exact path transport and analytic backpropagation used the
selected-branch derivative. The gated-point emulation used the same two
parameter groups and context-gated input eligibility, providing the explicit
point-model resource needed to reproduce the dendritic address.

Each seed used 2,048 training examples and 2,048 independent test examples.
Mini-batch SGD used batch size 64, learning rate 0.3 and 60 epochs, with
Gaussian weight initialization of standard deviation 0.03. Switch interference
was measured after 12 additional epochs on 1,024 balanced-label examples from
context 1 only, without resetting the optimizer or weights. Gradient cosine
and scaled capture used concatenated per-example parameter gradients. For the
one-step analysis, each candidate batch gradient was norm matched to the exact
gradient before a fixed step of 0.25 was applied.

Preliminary seed 4099 was used only to verify balance, nondegenerate capture,
minimum exact-route accuracy and exact--BP equivalence. The unchanged code and
configuration were then run for analysis seeds 4100--4109. The independent
seed was the paired inferential unit. Intervals used 20,000 paired bootstrap
resamples, and exact two-sided Wilcoxon tests are reported in Source Data.
This experiment tests $K=2$ in one shallow, matched forward architecture and
served as the support check for the larger factorial.

The full subtree-address protocol assigned eight contexts to the leaves of a
balanced binary hierarchy and used eight input streams, each with eight dimensions.
Every context--label cell was exactly balanced. The selected stream carried a
unit label signal. Nonselected streams carried an opposite-sign distractor
whose amplitude increased with tree distance: 0.15 for a sibling, 0.45 within
the same half and 0.75 across halves. Independent Gaussian noise with standard
deviation 1.1 was then added. Each seed supplied 2,048 training, 2,048 test and
1,024 switch examples. Full-batch gradient descent used learning rate 0.3 for
80 training epochs and 20 switch epochs. Analysis seeds 4200--4219 were
fixed before outcomes were inspected; preliminary seed 4199 was excluded from
inference.

Five representations were crossed with $K=1,2,4,8$: the task-matched
dendritic tree, an explicitly context-gated point model, a flat-compartment
model, grouped point subunits, and a degree- and depth-matched tree with a
seed-fixed leaf permutation. The first four implementations deliberately
received identical routed coefficient fields and served as computationally
equivalent controls. Every representation had 64 trainable forward weights,
64 active input contacts, one output nonlinearity and one scalar decoder.
Route fields were normalized to unit Euclidean norm for each context.

The six route families were correct contiguous ancestry subtrees, a fixed
within-neuron derangement, depth-interleaved bins, random sparse groups, an
unrestricted random rank-$K$ projector and a training-derived rank-$K$ PCA
upper bound. Shared neuronal feedback, exact compartment transport and
analytic backpropagation provided references. Random controls were keyed only
by seed, family and bandwidth, which ensured identical stochastic
realizations across implementation-equivalent representations.

The preliminary quality-control run required exact context--label balance,
zero context--label correlation, neuron-shared capture below 0.20, exact capture above
0.999999999, an exact--backprop endpoint difference below $10^{-12}$, exact
implementation equivalence below $10^{-12}$ and zero fallbacks. All criteria
passed before the 2,700 analysis fits were run with unchanged script and
configuration hashes. Outcomes were paired by seed. Intervals used 20,000
paired bootstrap draws, and two-sided Wilcoxon tests used the 20 seed
differences. The per-seed best matched non-anatomical control was prespecified
across route derangement, depth-interleaved, random-sparse and random-rank
conditions. The learned PCA route remained explicitly labeled as an upper
bound.

The trained partition-residual reanalysis deterministically reconstructed all
2,700 fits and evaluated the shared-coefficient partition residual both at
initialization and at the trained checkpoint. Supplementary Section~S5
specifies its construction and statistics, and Supplementary Fig.~S23 shows
the results.

\subsection*{Credit-operator signal--noise experiment and factorial reanalysis}

The signal--noise experiment used 16 Euclidean coordinates represented in the
orthonormal Haar basis of a balanced binary tree, ordered from the global mode
(level 0) to individual sibling contrasts (level 4). The configuration,
50 analysis seeds 7000--7049, two preliminary validation seeds and numerical
tolerances were specified before the analysis outcomes were inspected. The
preliminary runs verified basis orthogonality, projector idempotence,
static-gain span invariance and exact agreement with the explicit point-gain
control. All planned observations were completed: 3,750 spectral, 1,800
depth, 3,750 projection and 1,500 reliability rows.

In the spectral screen, task covariance assigned total energy
$(0.15,0.35,0.30,0.20,0)$ to tree levels 0--4. An alignment coefficient
$\rho\in\{0,0.25,0.5,0.75,1\}$ mixed this covariance with an independently
rotated covariance having the same eigenvalues. Ancestry, random rank-matched
and dense principal-eigenspace projectors were compared at
$K\in\{1,2,4,8,16\}$. The dense value was also calculated as the Ky--Fan sum
of the leading $K$ eigenvalues divided by total covariance energy. Because the
endpoint covariances had equal trace, ancestry-minus-random capture varied
affinely with alignment. Endpoint differences therefore gave the exact
per-seed crossover; seeds already favoring ancestry at zero alignment were
assigned threshold zero. In these unweighted coordinates, let
\(\overline\Sigma_g\) denote the task-gradient covariance; capture was
$\tr(P\overline\Sigma_g)/\tr(\overline\Sigma_g)$.

The same-span diagnostic compared raw nested indicators, their tree-Haar basis
and indicators multiplied by fixed nonzero lognormal column gains. Rank,
coherence, positive-spectrum Gram condition number and capture were calculated
directly.

In the depth screen, a unit-norm target was sampled from modes at levels
$0$ through $H_{\mathrm c}$, with $H_{\mathrm c}\in\{1,2,3,4\}$. The
gradient-noise standard deviation at level $\ell$ was
$0.65[1+1.5\max(\ell-H_{\mathrm c},0)]$. Starting from zero, 80
common-noise updates of size 0.12 used the projector onto levels $0$ through
$D_{\mathrm r}\in\{1,2,3,4\}$. A fixed leaf permutation provided the rewired
control, and the identity provided stochastic backpropagation.

The projection screen independently set retained signal $r$ and retained noise
$n$ to $\{0.25,0.5,0.75,0.9,1\}$. It compared an unprojected stochastic
gradient, backpropagation followed by the same projection, and a routed
estimator with an added total coefficient-noise fraction of 0.05. For a unit
step on the identity-curvature quadratic, expected losses were calculated
analytically and stochastic losses were recorded from paired draws.

In the reliability screen, eight disjoint blocks had signal and noise energies
proportional to $\exp(hx_b)$ and $\exp(-hx_b)$, respectively, with equally
spaced $x_b\in[-1,1]$ and heterogeneity
$h\in\{0,0.5,1,1.5,2\}$. We compared no attenuation, the best common gain,
$S_b/(S_b+N_b)$, seed-shuffled gains, reversed gains and a point-gain control receiving
the same branch factors. Intervals used 20,000 resamples of the 50 paired
seeds, and paired tests were two-sided Wilcoxon signed-rank tests.

The secondary analysis reconstructed the training data,
initialization and route matrices for all 2,700 completed subtree-factorial
fits. For each of 20 seeds, 64 independently sampled minibatches of size 64
estimated gradient-noise energy at initialization. The exact full-data gradient
provided the signal term, the largest logistic Hessian eigenvalue provided
local smoothness, and Eq.~\ref{eq:phaseutility} provided utility. Correlations
were restricted to the 540 dendritic-tree route conditions, and uncertainty
resampled whole seed blocks. This initialization diagnostic involved no
additional model training.

\subsection*{Positive-rate nonlinear physical-depth experiment}

To connect the fixed-state hierarchy result to the rate-based network, we used the
\texttt{hierarchical\_\allowbreak gain\_\allowbreak load} generator and the
population-network model (source module
\texttt{DendriNet}). Inputs were ordered
as nonnegative excitatory and inhibitory rate streams. For binary label $y$,
the distal excitatory input had the schematic form
\begin{equation}
x_j^E=(e_0+y\Delta+\epsilon_j)
\exp\!\left\{\sum_{\ell=1}^{3}\sigma z_{\ell,a_\ell(j)}
-\frac{1}{2}\sum_{\ell=1}^{3}\sigma^2\right\},
\end{equation}
where $a_\ell(j)$ indexes the fine, coarse or global latent factor containing
coordinate $j$. Three disjoint inhibitory blocks measured these factors
separately. At sensor alignment $\alpha$, their log gains were
$\sigma[\alpha z_{\ell,a_\ell(j)}+
\sqrt{1-\alpha^2}z'_{\ell,a_\ell(j)}]$. Thus, $\alpha=1$ supplied matched
branch-local nuisance sensors, whereas $\alpha=0$ preserved the complete
factor marginals but made the sensors independent. A trial-shuffled control
cyclically permuted the sensor field after class balancing, preserving its
marginal distribution while removing example-wise pairing.

At every physical stage, the conductance-based shunting equation was
\begin{equation}
V_n=\frac{G_n^{\mathrm E}+J_n^{\mathrm{child}}}
{1+G_n^{\mathrm E}+G_n^{\mathrm I}+G_n^{\mathrm{child}}+\epsilon}.
\end{equation}
This follows from the general conductance balance after normalizing leak
conductance to one and setting
$E_{\mathrm L}=E_{\mathrm I}=0$ and $E_{\mathrm E}=1$. Here
$G_n^{\mathrm E}$ and
$G_n^{\mathrm I}$ are aggregate excitatory and inhibitory input conductances, whereas
$J_n^{\mathrm{child}}$ and $G_n^{\mathrm{child}}$ are aggregate child current
and conductance. The source code stores these four aggregates under the keys
\texttt{E}, \texttt{I}, \texttt{C} and \texttt{G}, respectively; the code key
\texttt{E} denotes an aggregate excitatory current, not a reversal potential.
All rate and conductance terms were
nonnegative. Reactivation was the identity, making the divisive branch
equation the only intermediate nonlinearity. D1 $[8]$, D2
$[2,3]$ and D3 $[2,1,2]$ contained one, two and three nonsomatic stages,
respectively. Each architecture retained eight nonsomatic branch units per
soma and the same 4/2/2 fine/coarse/proximal sensor inventory. Every model had
64 somata, 16 excitatory and 12 inhibitory contacts per branch, 14,336 active
synapses, 21,760 candidate slots, 66,178 trainable parameters and 2,944
persistent state scalars per sample. Reversing the fine and global feature
ranges supplied the same-resource tree-placement control.

The operating point used signal contrast $\Delta=0.80$, matched per-factor
train/test log-gain standard deviation $0.25$, child conductance 16 and
mechanism-neutral initialization. It was selected after the initial
severe-shift setting failed at every depth and two-seed exploratory sweeps of
gain, coupling and signal strength identified an accessible, non-ceiling
regime (Supplementary Fig.~S15). No exploratory seed entered inference.

Ten paired seeds (10200--10209) crossed aligned, zero-alignment,
trial-shuffled and reversed-placement shunting BP; aligned raw-additive BP; and
aligned or reversed-placement shunting LocalCA with shared-soma or exact-path
transport, for 270 fits. Adam ran for at most 180 epochs with
validation-based early stopping. The learning rate was 0.003 for BP and 0.0008
for LocalCA, and all comparisons were paired by seed.

The prespecified primary effect was aligned D3-minus-D1 accuracy. Topology
specificity required subtracting the corresponding zero-alignment,
shuffled-sensor or rewired-tree depth effect from the aligned depth effect. A
positive LocalCA claim separately required both a positive depth effect and a
positive aligned-minus-rewired interaction. Intervals used 50,000
seed-paired bootstrap draws, and exact two-sided sign-flip tests enumerated all
$2^{10}$ paired sign assignments.

Quality-control criteria required all 270 results to be finite, no LocalCA
fallback message, exact resource equality, at least nine of ten aligned BP seeds above
0.55 at every depth, and condition means below 0.98. A dedicated checkpoint
replay measured branch voltage, total conductance, input resistance,
activation derivative, path-gain dispersion and local-versus-autograd
conductance-gradient cosine on a fixed held-out batch.

\subsection*{Fixed-depth task-family and alignment factorial}

To test task specificity without adding physical depth, we fixed every network
at D3 $[2,1,2]$ and crossed three data-generating families, sensor alignment
$\alpha\in\{0,0.5,1\}$, serial versus literal grouped-point composition, and
BP versus exact-path LocalCA. The nested-factor positive control retained
the calibrated distal signal and three multiplicative gain factors. If
$z_{\ell,g_\ell(j)}$ is the zero-mean Gaussian log gain assigned to coordinate
$j$ at level $\ell$, the signal-bearing excitatory coordinate was proportional to
\begin{equation*}
 (b_E+y\delta)\exp\!\left(\sum_{\ell=1}^{3}
 \sigma_{\ell}z_{\ell,g_\ell(j)}
 -\frac{1}{2}\sum_{\ell=1}^{3}\sigma_{\ell}^{2}\right),
\end{equation*}
where $b_E$ is the excitatory baseline, $y\in\{0,1\}$ is the class label,
$\delta$ is the class-signal contrast and $\sigma_{\ell}$ is the log-gain
standard deviation at level $\ell$. All three levels used
$\sigma_{\ell}=0.25$. Subtracting half the summed variance keeps the expected
multiplicative gain equal to one.

The maps $g_\ell$ form nested fine-to-coarse groups. Inhibitory sensor block
$\ell$ measured
\begin{equation*}
 s_{\ell,j}(\alpha)=\alpha z_{\ell,g_\ell(j)}
 +\sqrt{1-\alpha^2}\,\xi_{\ell,j},
\end{equation*}
where $\xi_{\ell}$ is an independent standard-normal nuisance factor. Here,
$\alpha\in[0,1]$ controls task--sensor alignment: $\alpha=0$ makes the observed
sensor independent of the latent gain, whereas $\alpha=1$ reveals it exactly.
Changing $\alpha$ therefore changes trial-wise task--sensor correspondence
while preserving each sensor's marginal log-gain variance.

The flat-factor control retained the same product and level-wise variances but
replaced the nested maps by unrelated group assignments
$\widetilde g_\ell$:
\begin{equation*}
x_{j}^{E,\mathrm{flat}}\propto (b_E+y\delta)
\exp\!\left(\sum_{\ell=1}^{3}
\sigma_\ell z_{\ell,\widetilde g_\ell(j)}
-\frac12\sum_{\ell=1}^{3}\sigma_\ell^2\right).
\end{equation*}
The local-ratio control instead used a cumulative hierarchical log field
$r_j$ in both streams. Omitting the independently added zero-mean input noise
for clarity, its coordinates were
\begin{equation*}
x_j^{E,\mathrm{local}}
=(b_E+y\delta\,\mathbf 1_{j\in\mathrm{distal}})
e^{r_j-v_j/2},\qquad
x_j^{I,\mathrm{local}}
=b_Ie^{\alpha r_j+\sqrt{1-\alpha^2}\,\zeta_j-v_j/2},
\end{equation*}
where $v_j=\operatorname{Var}(r_j)=\operatorname{Var}(\zeta_j)$. At
$\alpha=1$, the gain cancels in the local ratio, so serial cancellation of
separate factors is unnecessary.

All task families used 10,000 balanced examples, 64 excitatory and 64
inhibitory features, a distal-only excitatory class signal, signal contrast
0.80, gain SD 0.25, input-noise SD 0.08, and the previously selected optimizer,
stopping and conductance settings. Serial and grouped-point models had
identical branch modules, contacts, candidate slots, trainable parameters and
input tensors; only child-to-parent composition differed. Ten paired seeds
(10500--10509) produced 360 fits.

Prespecified estimands were the within-seed serial-minus-grouped contrast, its
$\alpha=1$ minus $0$ interaction, the nested-family interaction minus each
mismatch-family interaction, and the corresponding LocalCA-minus-BP credit
interaction. Directional claims required a 95\% paired-seed bootstrap interval
excluding zero and at least eight of ten seed differences in the predicted
direction. The complete family scan was reported regardless of direction.
Configurations and run-level outcomes are included with the Source Data.

\subsection*{State-matched positive-conductance reliability experiment}

The state-matched mechanism experiment used eight branches, four nonnegative rate
inputs per branch, 512 training examples, 2,048 test examples and one learned
positive excitatory conductance per input. Branch voltage was
$V_b=g_b^E/(g_b^L+g_b^E)$. A nonnegative shunt $\kappa_b$ with reversal zero
was paired with the oracle current $\kappa_bV_b$, making the post-intervention
voltage exactly
$(g_b^E+\kappa_bV_b)/(g_b^L+g_b^E+\kappa_b)=V_b$. At the same time, local
eligibility was attenuated by
$(g_b^L+g_b^E)/(g_b^L+g_b^E+\kappa_b)$. This state clamp therefore separated
physical input-resistance attenuation from suppression of the forward
feature.

Initial full-data gradients defined branch signal energy $S_b$. Independent
coefficient noise was scaled so that
$N_b=S_b\exp(-2hx_b)$ for eight equally spaced $x_b\in[-1,1]$ and
$h\in\{0,0.5,1,1.5,2\}$. With the actual step $\eta=c/L$ and $c=0.5$, shunts
were fixed from the initial oracle attenuation
$\min\{1,S_b/[c(S_b+N_b)]\}$ or from the step-consistent best global,
shuffled or reversed control. The shunts were not learned. Additional controls
were clean exact backpropagation, noisy credit without a shunt, a state-matched
unattenuated-eligibility control, an explicit point-gain control receiving the same factors, and
aligned attenuation with clean credit.

Forty common-noise full-data updates used one half of the numerically estimated
initial smoothness limit. A pilot identified an inconsistency between this
step size and the gain formula; the corrected analysis preceded 50 paired
analysis seeds (8100--8149), with two implementation-check seeds excluded from
inference. Numerical criteria required nonnegative inputs and shunts, voltage
matching, and independently computed point-gain and unattenuated-eligibility
equivalence within $10^{-12}$, together with
relative finite-difference errors below $10^{-5}$ for both the unshunted
objective and the shunted state-clamp surrogate. The observed maxima were
$2.22\times10^{-16}$ for state mismatch,
$4.00\times10^{-15}$ and $1.31\times10^{-14}$ for the two equivalence checks,
and $3.60\times10^{-8}$ for the physical finite-difference error. Intervals
used 20,000 resamples of paired seeds, and paired tests were two-sided
Wilcoxon signed-rank tests. The configuration and all 2,250 seed--condition
rows are supplied with the Source Data.

The adaptive analysis used the same task, model and state clamp but
replaced oracle moments with running estimates from paired, conditionally
independent noisy observations of the local branch gradient. The design was
fixed before any outcome was inspected. Fifty paired seeds completed all 1,050
planned outcomes, and an independently computed adaptive point-gain control
again matched to numerical precision.
Supplementary Section~S4 (``Adaptive local reliability estimation'') specifies
the estimator, gain bounds, seed protocol and complete statistics; seed-level
outcomes are provided in the Source Data.

\subsection*{Same-span noisy coefficient-learning experiment}

The rate-based coefficient experiment fixed a 16-coordinate balanced-tree
space and the rank-eight span through depth three. Three parameterizations
shared the same projector: eight orthonormal Haar columns, 15 redundant raw
nested indicators, and the same indicators multiplied by fixed positive gains
ranging from $\exp(-3)$ to $\exp(3)$. Their positive Gram condition numbers
were 1, 15 and 388.52. Each seed supplied a unit-norm target in the common span
and 80 common noisy target estimates. Observation standard deviation was
$2/\sqrt{n_{\mathrm{eff}}}$ for
$n_{\mathrm{eff}}\in\{4,16,64,256\}$. Vanilla coefficient descent used 0.2
of each dictionary's stability limit. A separate oracle control multiplied
the coefficient gradient by the pseudoinverse Gram matrix, producing the same
projected field step in all three parameterizations.

The design and predictions were fixed before two implementation-check seeds,
excluded from inference, and 50 paired analysis seeds (9100--9149) were run.
All 4,800 checkpoint rows
completed. Projectors agreed to $9.44\times10^{-16}$, the target address
residual was at most $1.45\times10^{-30}$, and Gram-preconditioned trajectories
agreed to $1.16\times10^{-15}$. The prediction of an unconditional
orthonormal-coordinate advantage failed in the low-data regime. We therefore
report both the prespecified contrast and the exact post-result bias--variance
decomposition rather than relabelling the outcome as confirmatory. Intervals
used 20,000 resamples of paired seeds, and tests were two-sided Wilcoxon
signed-rank tests.

An initial inhibitory-dose experiment used the noise-resilience task and
crossed two neuron models, five inhibitory-contact counts per branch
(0, 5, 10, 20 and 40), backpropagation or one of three local feedback fields,
and ten paired seeds, yielding 400 runs. Its prespecified endpoint was the
shunting-minus-raw-additive contrast. Because every shunting cell used the
invalid signed-input convention, this experiment was excluded from figures and
inference.

The same-seed computational rerun crossed exact path transport and backpropagation over two
tasks, two cores, depths one through four and paired seeds 42--51, yielding
320 runs and 160 method pairs. Versioned source and data-generator identifiers
are provided in the Source Data. The raw-additive core retained signed inputs on the noise
task, whereas the positive-conductance shunting core applied an explicit ReLU before
forming conductances.

Inclusion required the specified configurations and seeds, complete learning
summaries, finite held-out metrics and stage-complete checkpoints, with no fatal
run error or transport-shape fallback. Exact-minus-backpropagation effects were paired within task,
core, depth and seed. The plotted task--core contrasts first averaged the four
depths within each seed. Incomplete setup or resource attempts produced no
endpoint and were excluded independently of outcome.

The fixed-topology experiment contained 320 depth-four runs crossing two tasks,
two neuron models, backpropagation or three local feedback fields, random or
spatially partitioned sparse input indices, and ten paired seeds. Both maps
used 21 contacts per distal branch. The spatial map recursively divided the
$28\times28$ feature plane into 16 disjoint rectangles per neuron, whereas the
random map sampled each branch independently from all 784 coordinates. We
quantified unique coordinate coverage and
cross-branch overlap for the same ten topology seeds. The validity rule
removed 80 synthetic-noise shunting runs, leaving 240 comparisons
(Supplementary Fig.~S7). Because a
spatial effect shared by backpropagation reflects forward connectivity, this
experiment was not used to support topology-specific credit transport.

The fixed-budget depth experiment used the synthetic task and contained 320 runs.
The eligible 160 raw-additive runs crossed four depths, three local feedback
fields and matched backpropagation at ten paired seeds while fixing 16
terminal branches and 960--968 active contacts per soma. The experiment therefore
matches terminal branches and input contacts, but not compartment count or
trainable-parameter count.

For the fixed-checkpoint diagnostic, matched-width scalar-fallback,
neuron-specific and exact teaching fields were evaluated at 120 conductance-valid backpropagation
checkpoints on one held-out batch of 128 examples. Only nonsomatic
dendritic stages and their trainable branch parameters entered the field and
gradient vectors. Scaled capture was one minus the squared residual after the
candidate vector was optimally rescaled to the exact vector (Supplementary
Fig.~S9).

For the learning endpoint, each candidate gradient was normalized to the
exact-gradient norm and applied without additional training. The step size was
$r\lVert\theta\rVert/\lVert\nabla\mathcal L\rVert$ for
$r\in\{10^{-6},10^{-5},10^{-4},10^{-3}\}$. The primary plotted operating
point was $10^{-5}$, and all four values are supplied in the Source Data.
Relative progress was the candidate loss decrease divided by the loss decrease
from the norm-matched exact update. The association interval resampled
checkpoints while preserving the paired scalar and neuron-specific fields.

\subsection*{MICrONS morphology processing}

Cells were drawn from the functionally co-registered MICrONS cohort and
resolved from stable nucleus identifiers to roots in materialization 1822 of
\texttt{minnie65\_public}. Skeletons were obtained through the MICrONS skeleton
service, and incoming synapses came from \texttt{synapses\_pni\_2}. The
initial eight cells formed a convenience sample rather than a random or
representative sample. Anatomical
claims from this cohort are therefore explicitly single-animal and
descriptive.

Degree-two dendritic chains were collapsed into branch-to-branch segments.
Synapses were assigned to the nearest dendritic cable node and retained when
the distance was at most $5\,\mu$m. Presynaptic coarse type provided E/I
identity where available. Otherwise, a high-confidence target-structure
prediction supplied a secondary proxy from the in-development
\texttt{synapse\_target\_predictions\_ssa\_v2} table. This table does not yet
have a stable public release identifier and is not required for the
direct-type-only or disjoint-v661 analyses. The direct-type-only analysis
removed all proxy-classified contacts.

Raw axial coupling was proportional to radius squared divided by cable length.
It was normalized by the nonzero median within each cell and clipped to
0.05--20. Raw leak was proportional to radius multiplied by the larger of cable
length and radius. It was likewise normalized by the nonzero cell median and
clipped to 0.1--10. Excitatory and inhibitory synaptic areas were normalized
by the median nonzero total synaptic area within each cell. These quantities
serve as sensitivity weights rather than fitted physical conductances. The
soma was the root of every compressed tree. Ancestry matrices were constructed
by explicit parent traversal and checked for acyclicity and a unique path to
the soma.

For the disjoint sensitivity cohort, a 55-cell candidate set was defined before
outcomes were inspected. All candidates were mapped to the public
MICrONS v661 static release, and the original eight cells were excluded by
stable nucleus identifier. The remaining 47 cells all passed the structural
criteria. Only direct presynaptic E/I annotations were used. Before spatial
mapping, direct labels were available for 11,024 of 234,301 incoming synapses
(4.71\%); 10,516 contacts mapped to retained cables, with a median of 212
directly typed synapses per cell. The cohort was not a population-random
sample and contained 34 L2 IT, 2 L3 IT, 10 L4 IT and 1 L5 ET cell. The same
structural-capacity procedure was applied to both cohorts, but their results
were not pooled.

For the independent-animal replication, we used the public MICrONS phase-1
layer-2/3 ``Pinky'' v185 release, a
$250\times140\times90\,\mu$m visual-cortex volume from a P36 male mouse that
is biologically distinct from \texttt{minnie65}
\citep{turner2022neocortex,microns_pinky_v185}. Before mesh topology or
selected-cell synapse counts were opened, the 362 rows labeled excitatory in
the archived soma-valence table were ordered along the second volume
coordinate and divided into 12 equal-count strata. Within each stratum, we
selected the cell nearest the global median of the first and third coordinates,
using root ID to break ties. This outcome-independent rule spans the volume
while reducing edge truncation; it is not a random population sample.

For each selected HDF5 mesh, we added the published
\texttt{link\_edges} and retained the largest connected component. This step
removed detached segmentation fragments before the soma root was selected.
The retained mesh was skeletonized with the meshparty TEASAR implementation
using a $7.5\,\mu$m soma-collapse radius and a $12\,\mu$m invalidation
distance. Cable radius was estimated as half the opposite-surface ray distance
at skeleton mesh anchors using an Embree ray index.

Incoming synapses came from the archived dense v185 table. E/I identity was
assigned only when the presynaptic root had an excitatory or inhibitory label
in the same soma-valence table. We then applied the same $5\,\mu$m mapping
gate, branch-chain compression, electrical normalization and route
dictionaries used in the v661 analysis, without retuning. Predefined inclusion
criteria required at least 20 mapped typed inputs, including at least three
inhibitory inputs. Selected cells and exclusion reasons are reported in Source
Data. The
primary endpoint was sign agreement with \texttt{minnie65} for K=4
ancestry-route capture relative to random paths, depth bins and shuffled
ancestry. The mouse, not the 12 nested cells, is the biological replication
unit; cell-bootstrap intervals describe only within-volume stability.

\subsection*{MICrONS inhibitory-census analysis}

Before evaluating any endpoint, the inhibitory analysis joined the 47-cell
v661 cohort to the published v795 census using stable nucleus identifiers. All
20 overlapping targets were retained. We used the published cell-type table,
inhibitory-synapse table, complete input-synapse table and target SWCs
\citep{schneidermizell2025inhibitory}. Raw all-input coordinates were mapped
to the published slanted micrometre frame with an affine transformation fitted
from 80,114 synapse locations present in both coordinate systems. The maximum
transformation residual was $1.64\times10^{-12}\,\mu$m. Input and known
inhibitory locations were mapped to the nearest target skeleton node and
retained within $5\,\mu$m. Inputs without a known presynaptic inhibitory cell
are described as generic rather than excitatory because the census does not
label every incoming contact.

For each multisynaptic inhibitory connection, the largest contact was retained
within every published axonal clump. Each retained contact was matched to 64
generic input segments in the same compartment with the nearest log path
distance to the soma. Five hundred independent matched assignments estimated
the null distribution within each connection. Pairwise outcomes were
cable-tree distance, normalized shared path to the lowest common ancestor, and
cosine overlap between the two input-size-weighted binary descendant domains.
Outcomes were first averaged over inhibitory connections within each
postsynaptic target. The target, rather than an individual contact or
connection, was the inferential unit.

Two sensitivity analyses addressed dependence and spatial matching. First,
connection-level contrasts were averaged within each of 92 presynaptic axons
before inference. Second, candidate locations were ranked jointly by log path
distance and three-dimensional Euclidean proximity to the observed contact.
The ranking used the sum of the two within-pool percentile ranks, after which
the same 500 matched assignments were repeated. These analyses test whether a
target-level contrast persists after clustering repeated connections from the
same axon and after incorporating local tissue proximity into the null.

For the route-capacity analysis, rows represented segments with mapped input
and columns represented segments bearing at least one known inhibitory
contact. The binary ancestry matrix was weighted by the square root of mapped
input size across rows and known inhibitory size across columns. Actual sites
were ranked by column norm. At each budget, selected columns were used to
reconstruct the full weighted actual-route matrix. Controls comprised 200
random subsets of actual sites, depth bins, depth-preserving within-column
ancestry shuffles and an unconstrained SVD oracle.

Leverage selection is a capacity diagnostic rather than a biological learning
rule. Because both the selected columns and the reconstruction target come
from the same actual-route matrix, this endpoint measures internal dictionary
compressibility, not generalization to an independently generated credit
field.

\subsection*{Credit dictionaries and capture}

The weighted direct route matrix was $\Gamma_{ik}=A_{ik}\beta_k$, where
$A_{ik}$ indicates whether excitatory site $i$ descends from route site $k$ and
$\beta_k$ is the normalized inhibitory-conductance fraction at that route site. It is a
normalized route-sensitivity proxy rather than the exact derivative of the
reciprocal passive-cable solve. Perturbation fields were generated by
multiplying independent route amplitudes by $\Gamma$. At each channel budget,
nested-subtree routes were ranked by $\beta_k$ multiplied by the fraction of total
mapped excitatory synaptic area among their descendants. Controls were an
unconstrained principal-component basis, random nonempty real paths, cable-depth
bins and column-wise ancestry shuffles. Channel count and the number of
evaluated examples were matched. Feedback wiring density was defined as the
fraction of nonzero entries in the site-by-channel dictionary.

For each dictionary, weighted least squares provided the optimal projection
after both the field and dictionary were left-multiplied by $W^{1/2}$, where
$W$ contains mapped excitatory synaptic area. Numerical sensitivity was assessed with
twenty independent Monte Carlo streams, each containing 384 perturbation fields
and 64 random or shuffled dictionaries per cell and channel count. Streams
were not treated as biological replicates. Primary comparisons were averaged
within each cell before paired testing.

For the independent-generator control, the reconstruction target was not
sampled from $\Gamma$. We added a small focal shunt at every
inhibitory-bearing segment of the reciprocal passive-cable system, restored
baseline somatic voltage with an independently solved state-matching
compensatory current, and finite-differenced the log magnitude of the exact
excitatory-conductance gradient at every excitatory-bearing segment. The
derivative dose was $10^{-3}$ times the focal segment's
membrane-plus-synaptic conductance. This procedure produced a weighted response
operator $H$ whose columns were exact focal responses.

For a dictionary $\Phi$, expected field-energy capture was calculated without
Monte Carlo sampling as
\begin{equation}
\label{eq:fieldcapture}
\frac{\lVert P_{W^{1/2}\Phi}W^{1/2}H\rVert_F^2}
{\lVert W^{1/2}H\rVert_F^2},
\end{equation}
where $P$ denotes the orthogonal projector onto the stated column space. In addition to the primary
controls, 200 surrogate trees per cell reassigned child subtrees among parent
slots at the preceding depth. This preserved all node and edge attributes,
each node's topological depth, and each parent's out-degree while changing
ancestral membership. A separate row shuffle preserved selected route values
and sparsity but broke their assignment to excitatory segments.

The coarse-to-fine analysis of the non-scalar ancestry-route field
(Supplementary Fig.~S25) used a deterministic weighted tree-Haar construction
on each unbalanced reconstructed arbor. Supplementary Section~S7 defines the
construction, column-permuted ancestry control and cohort statistics.

\subsection*{Focal conductance perturbations}

Before the focal analysis, we fixed the site-selection rule, primary dose,
comparison groups and localization endpoint. A depth-stratified rule selected
sites with at least three excitatory descendants and three comparison sites,
with at most 16 sites per cell sampled across topological-depth quartiles.
Primary excitatory and inhibitory synaptic scales were both 0.35, with
normalized reversal potentials
$E_{\mathrm E}=1$ and $E_{\mathrm I}=-0.2$. Conductance doses were
0.25, 0.5, 1 and 2 times the local membrane-plus-synaptic conductance. The
baseline-current-matched current injection applied the first-order current
$\kappa_k(E_{\mathrm I}-V_k)$ at the same node without changing $G$. After either
intervention, an independently solved compensatory current restored baseline
somatic voltage. This intervention is not the derivative of a continuously
adjusted voltage-clamp controller, and no focal dendritic voltage was clamped
or matched between interventions.

The objective was squared somatic error, with target voltage set one normalized
unit below baseline. Excitatory-conductance gradients were obtained by an
adjoint solve, with the solved compensatory current treated as fixed during
the post-intervention derivative, and were checked by finite differences. Let
$d_i=E_{\mathrm E}-V_i$ and $d'_i=E_{\mathrm E}-V'_i$. The post-shunt gradient $q'_id'_i$ was
decomposed algebraically into an adjoint-only substitution $q'_id_i$ and a
driving-force-only substitution $q_id'_i$, alongside the full-shunt and
current-injection gradients.

Two-factor Shapley values allocated the nonlinear
shunt-minus-current-injection localization difference between adjoint and driving-force
changes and reconciled exactly to the observed contrast at each site. Because
the current-injection reference is not a literal no-factor physical
intervention, we also calculated an unperturbed-reference allocation as a
sensitivity analysis. These substitutions are algebraic controls rather than
independent biological interventions.

Synapses were classified as descendants, ancestors, sister-subtree sites or
unrelated sites. Within each template, unrelated synapses were matched to
descendant cable depth. For baseline gradient $\gamma_i$ and perturbed gradient
$\gamma_i'$, we defined
$m_i=\left|\log[(|\gamma_i'|+\varepsilon)/(|\gamma_i|+\varepsilon)]\right|$, where
$\varepsilon=10^{-15}\max(1,\max_i|\gamma_i|)$. The prespecified site-level localization
index was the median $m_i$ among descendants minus the median among
depth-matched unrelated synapses. Site effects were averaged within cells, and
the primary paired contrast used the eight cell means. A topology control
sampled 200 relation templates from other focal sites, stratified by focal-site
topological-depth quartile when another site was available; otherwise, it used
another site in the same cell. Supplementary Section~S6 specifies axial and
leak normalization and clipping.

We also calibrated the passive cable in physical units. Nonroot segments were
modeled as cylinders with axial conductance $\pi r^2/(R_a\ell)$ and leak
conductance $2\pi r\ell/R_m$, while the root used spherical membrane area
$4\pi r^2$. Conductances were expressed in nS. Because synaptic areas are not
conductance measurements, excitatory and inhibitory synaptic conductances
retained their prespecified relative scale and were referenced to the
cell-median physical leak conductance.

We evaluated axial resistivities
\[
R_a\in\{100,150,250\}\,\Omega\,\mathrm{cm}
\]
at $R_m=15{,}000\,\Omega\,\mathrm{cm}^2$. In a separate sweep with
$R_a=150\,\Omega\,\mathrm{cm}$, membrane resistivity took the values
\[
R_m\in\{300,1000,3000,5000,15{,}000,30{,}000\}\,
\Omega\,\mathrm{cm}^2.
\]
The same sites, state-matching current, adjoint gradient, unit relative dose
and current-injection comparison were used. Two
zero-length nonroot segments in the v661 source skeletons used their radius as
the cable length. This fallback and all electrotonic ratios are recorded in
the Source Data.

The passive focal-sensitivity analysis used the initial eight cells at
$R_a=150\,\Omega\,\mathrm{cm}$. We crossed membrane resistivities of 300,
1000 and $15{,}000\,\Omega\,\mathrm{cm}^2$ with distributed leak-like
background conductance equal to 0, 1 or 4 times each segment's baseline leak.
At every selected site, three dose schemes were evaluated: 0.25, 1 and 2 times
local membrane-plus-synaptic conductance; fixed doses of 0.05, 0.5 and 5 nS;
and 0.25, 1 and 4 times local input conductance
$[(G^{-1})_{kk}]^{-1}$. Rank-one voltage and adjoint updates were calculated
exactly with Sherman--Morrison, followed by the same state-matching somatic
current.

In addition to absolute localization, recorded outcomes included signed
log-magnitude change, attenuated and enhanced fractions, sign-flip fraction,
descendant gradient-energy ratio, local input resistance and $S_k$ from
Eq.~\ref{eq:selectivitycriterion}. Site values were averaged within cells
before eight-cell intervals and shunt-minus-current-injection contrasts were computed.
A preliminary numerical check required positive-definite matrices and a
somatic residual below $10^{-10}$ before the full matrix was run with unchanged
code and configuration.

For the active steady-state sensitivity, voltage-dependent Na, K, Ca, HCN and
NMDA currents were added to the physical passive system at
\(R_a=150\,\Omega\,\mathrm{cm}\),
\(R_m=1{,}000\,\Omega\,\mathrm{cm}^2\) and one
baseline-leak unit of distributed background conductance. Channel activation
used sigmoidal steady-state gates with channel-specific half-activation,
slope, power and reversal values fixed in the machine-readable protocol.
Global and segment-level maximal-conductance multipliers were independent
lognormal draws. Newton iterations with a residual-reducing line search solved
the full nonlinear equilibrium.

Draws were accepted only when voltage remained within the prespecified range,
the residual was below $10^{-10}$ and the symmetrized local Jacobian was
positive definite above $10^{-8}$. With purely local voltage-dependent gates,
off-diagonal Jacobian entries are the reciprocal axial couplings. The
steady-state Jacobian is therefore symmetric, so the symmetrized gate and the
plain inverse used below are exact rather than approximate.

For every accepted equilibrium, the adjoint used the exact inverse of the
local Jacobian. Focal rank-one shunts and baseline-current-matched current
injections were evaluated at 0.25, 1 and 4 times local input conductance, followed
by the same state-matching compensatory current at the soma. We required 64
accepted draws in every cell, allowing up to 256 attempts; all 512 first
attempts were accepted. The 64 channel draws and up to 16 focal sites were
averaged within each reconstructed cell before bootstrap intervals and paired
tests. The active ensemble is a steady-state local-linearization sensitivity
analysis, not a simulation of channel kinetics or spikes.

The focal analysis was repeated after all proxy-classified contacts were
removed. In the disjoint v661 sensitivity cohort, 45 of 47 cells provided 235
eligible focal sites for the primary shunt--current-injection comparison. Forty cells
with at least two eligible sites provided the reassigned-relation control.
Cells, not focal sites, remained the inferential units.

\subsection*{Measured-response analyses}

Functionally imaged presynaptic partners were linked to anatomical contacts
through the MICrONS/CAVE and DANDI mappings. The predefined single-scan
cohort contained 69 partners across seven targets. The scan-complete analysis
deterministically retained every automatic-conservative
target--session--scan cohort with at least five unique connected imaged
presynaptic roots, yielding 13 scan observations nested within the same seven
targets. Each scan contained 464 trials, 280 stimulus identities and 136
repeated identities.

Multiple contacts from one presynaptic partner were pooled, and its analysis
site was the segment with the greatest summed contact area. Functional
similarity was the Pearson correlation of condition-mean responses over
repeated identities. For each target, the partial-rank analysis rank
transformed functional similarity and shared ancestry, residualized each
against log Euclidean separation and path-depth difference, and correlated the
two residuals. Scan-level statistics were averaged within targets before the
target bootstrap and signed-rank test. The target neuron, not an individual
scan or synaptic pair, was the inferential unit.

For task-derived credit, a small branch model predicted each postsynaptic
response from the responses of its connected presynaptic partners. Complete
visual-stimulus identities were assigned to held-out splits. Exact branch
errors were calculated on training trials, and dictionary projectors were fit
without using held-out identities. Matched models were then trained from the
same initialization with exact or projected branch errors. Ten fixed
split/initialization replicates were averaged within each of seven target
cells.

Because the projection coefficients used exact errors, these analyses estimate
the capacity of a feedback family rather than a biological encoder. Only
input-weight errors were projected; branch-readout weights and bias received
exact gradients. Normalized MSE was held-out MSE divided by the held-out error
of the training-mean predictor. Supplementary Section~S9 provides complete
model and optimizer specifications.

For the segment-resolved analysis, each complete compressed reconstruction
was instantiated as a reciprocal passive conductance system. A trainable
nonnegative excitatory conductance was placed at the dominant mapped contact
of every imaged partner. Exact gradients of somatic squared prediction error
used the trial-specific inverse conductance operator and factorized into
$x_i(E_{\mathrm E}-V_i)$ multiplied by the segment adjoint.

Restricted methods first projected the baseline soma-to-site transfer vector
into one of three four-channel dictionaries: conductance-weighted ancestry, a
column-value-preserving site shuffle, or an equal-rank random set of nonempty
anatomical routes. This vector was calibrated once without target responses
and then frozen during learning. Each restricted update used only scalar
output error, the fixed site vector and local eligibility. All methods used
exact readout and bias gradients.

Ten seed-fixed splits held out complete stimulus identities within every scan.
Replicates were averaged within scans, and all eligible scans were then
averaged within targets before seven-cell inference. Finite-difference checks
verified one exact conductance coordinate per run. No route was absent, and no
scan had a rank mismatch, nonfinite value or incomplete endpoint.

The capture--learning association excluded exact and dense oracles. Both
variables were centered within targets before Spearman's $\rho$ was computed.
Its interval used 20,000 target-level bootstrap draws. The two-sided null used
20,000 independent reassignments of learning outcomes among method labels
within each target.

\subsection*{Alignment-controlled optimization}

For each reconstructed cell, we rebuilt the conductance-weighted ancestry
kernel and, before generating gradient fields, selected eight routes according
to inhibitory fraction multiplied by descendant excitatory synaptic-area
fraction. Segment coordinates were weighted by the square root of summed
mapped excitatory synaptic area. If $Q$ is an orthonormal basis for the
selected routes, each unit-energy exact gradient was constructed as
\begin{equation}
\bm g(a)=\sqrt{a}\,\bm u_{\parallel}+\sqrt{1-a}\,\bm u_{\perp},
\end{equation}
where $\bm u_{\parallel}\in\operatorname{span}(Q)$,
$\bm u_{\perp}\perp\operatorname{span}(Q)$ and
$a\in\{0,0.2,0.4,0.6,0.8,1\}$. Directions were paired across alignment
levels. Controls were eight random real paths, eight cable-depth bins and
row-permuted nested-subtree routes. The permutation preserved column values and
nonzero count while breaking ancestry.

Each cell contributed 40 nested Monte Carlo streams with 256 gradients per
stream. The objective was a positive diagonal quadratic with an
anatomy-independent curvature spectrum from 0.5 to 1.5, permuted within each
stream and held fixed across methods and alignment levels. One-step updates
had a norm equal to 0.1 times the exact-gradient norm. Iterative projected
descent used learning rate 0.25 for 20 steps. Both outcomes were normalized by
the corresponding full-gradient progress. Streams and gradient fields assessed
numerical sensitivity, while cell-level means served as the inferential
units.

\subsection*{Static task-interference calculation}

The task-interference identity follows from an exact quadratic expansion around
a Task-A optimum, where the linear term is zero. In the equal-route
illustration, each task occupied 1,000 coordinates, route overlap ranged from
zero to one, and the Task-B target opposed Task A on shared coordinates.
Off-route leakage supplied an update of relative magnitude $\lambda$ on
Task-A-only coordinates. We evaluated a $101\times101$ grid over overlap and
leakage at step size 0.2 and compared explicit vector updates with the closed
form at every grid point. This analysis contains no temporal or spiking neural
dynamics. The published motor-learning study is used only for qualitative
cross-study interpretation.

\subsection*{Alignment-by-bandwidth synthesis plane}

The synthesis panel in Fig.~\ref{fig:creditphase}H is a deterministic
secondary display assembled from existing outputs; it does not rerun any
experiment. Its horizontal coordinate is task--anatomy alignment, defined as
the fraction of task-gradient or field energy in the anatomical route span.
Its vertical coordinate is relative feedback bandwidth
$K/r_{\mathrm{eff}}$ on a logarithmic scale, where effective task-credit rank
is
$r_{\mathrm{eff}}=(\sum_i\lambda_i)^2/\sum_i\lambda_i^2$ for the relevant
credit spectrum. Both coordinates are estimated separately for each
experimental family.

For the 2,700-fit factorial, alignment is the mean initial exact-gradient
capture of the correct-ancestry span in the dendritic-tree implementation, and
$r_{\mathrm{eff}}=7.99$ comes from the precomputed task spectra. For the spectral
sweep, alignment is the imposed covariance-mixture coefficient $\rho$, and
$r_{\mathrm{eff}}(\rho)$ is estimated within seeds from dense-PCA cumulative
capture. For the alignment-controlled MICrONS experiment, alignment is the
imposed aligned-energy fraction $a$. Its bandwidth coordinate is derived
analytically from the documented field generator as the geometric mean across
cells of $a^2+8(1-a)^2/(n-8)$, where $n$ is the cell's weighted coordinate
count; it is not read from a results table. For the coarse measured-response
null, alignment is mean held-out field capture by nested-subtree routes, and
$r_{\mathrm{eff}}=1.07$ is estimated from dense-oracle capture at one through
eight channels. For the two-stream credit-reversal task, alignment is the
initial scaled capture of correct two-subtree routing, and
$r_{\mathrm{eff}}\approx2.0$ follows from the algebraic rank-two expression
$1/[c^2+(1-c)^2]$, with $c=0.510$ denoting shared-coordinate capture.

The full-tree measured-response null is not plotted because its task rank was
not estimated comparably. Marker fill records each family's observed win, tie or
loss for the ancestry-versus-control contrast, and region tints are derived
from theory rather than fit to the results. Every coordinate, definition and
source is listed in
\texttt{source\_data/credit\_phase\_plane/points.csv}.

\subsection*{Interior-optimum and wiring-normalized reanalyses}

Two deterministic secondary analyses of existing outputs support
Supplementary Fig.~S16 and Fig.~\ref{fig:topology}E,F. Neither analysis alters
or reruns a training outcome. For the interior-optimum analysis, per-seed
initialization utility from Eq.~\ref{eq:phaseutility} was taken from the
operator metrics of the 2,700-fit factorial and from the fixed
depth-routing tables. The predicted optimum was the maximum utility over routed
depth, or the maximum ancestry-minus-best-control utility contrast over
budget. The observed optimum was the minimum final population loss, or the
maximum corresponding held-out-accuracy contrast. Before reporting any new
quantity, the pipeline reproduced the published $K=4$
ancestry-minus-best-control accuracy contrast
(0.0127; 15 of 20 seeds) from the seed-level outcomes.

For the wiring-normalized analysis, capture per unit wiring was defined as
weighted field-energy capture divided by feedback wiring density. It was
calculated within cells from the routing-capacity curves after Monte Carlo
streams were averaged within each cell. The published eight-channel capture
and wiring anchors were reproduced before any ratio was formed. Intervals are
95\% seed- or cell-bootstrap intervals based on 20,000 resamples. The
laminar-capture proposition and marginal utility condition
(Supplementary Section~S4) are verified numerically in the released test
suite.

\subsection*{Statistics and reproducibility}

For analyses designated confirmatory, configurations, seed sets, estimands and
exclusion criteria were specified before outcome analysis. Pilot runs used to
select stable numerical settings were excluded from inference. Versioned
configurations, completion criteria and exclusion records are provided in
Source Data.

Unless a directional hypothesis was specified before analysis, all tests were
two-sided. Central comparisons are reported with effect sizes and 95\%
intervals. Reconstructed-cell intervals resampled cells first and, when
appropriate, one Monte Carlo stream within each cell. Textual
focal-attribution intervals used a hierarchical bootstrap over cells and
sites. By contrast, the dose-response display in
Fig.~\ref{fig:focal}C shows cell-bootstrap intervals after site values were
averaged within each cell. Measured-response intervals resampled target cells.
Artificial-network summaries treated the initialization seed as the independent
unit; intervals were obtained by seed-level bootstrap as specified for each
experiment. Exact Wilcoxon signed-rank tests were used for small
paired cell cohorts. No site, trial, epoch, or Monte Carlo stream was treated
as an independent biological replicate. Null results are described as a lack
of reliable evidence rather than as proof of equality.

Bootstrap intervals used 20,000 draws unless stated otherwise in the Methods.
The primary MNIST and Fashion-MNIST ladders, physical-depth, H4, task-family,
and external-animal analyses used 50,000 seed-bootstrap draws, preserving
within-seed pairing for contrasts. Benjamini--Hochberg
correction was applied within each prespecified comparison family: the
four-budget subtree scan, the six bandwidth-matched routing contrasts, and the H4 primary
family. Other parameter sweeps and sensitivity analyses are labeled secondary
and are not treated as independent confirmation.

Seed counts reflected the evidential role of each cohort rather than a
single pooled power calculation. Three to five seeds were reserved for
numerical or mechanism diagnostics, ten for paired confirmation analyses with
interval and sign-agreement criteria, 15--20 for previously completed
trained factorials, and 50 for signal--noise boundary and crossover distributions.
Because effect sizes were unknown before the new simulation families were
run, we did not use a prospective parametric power calculation. Positive
confirmatory claims required both a paired 95\% interval excluding zero and
the prespecified fraction of concordant seed signs. Diagnostic cohorts were
not promoted to inferential evidence. A machine-readable table in Source Data
maps every headline endpoint to its independent unit and identifies nested or
descriptive observations.

The analysis code records configurations, seeds, software versions, source
tables, and machine-readable summaries. Numerical source data are organized by
figure and panel in the accompanying package. The test suite covers tree
construction, projection identities, and exact-gradient checks.
