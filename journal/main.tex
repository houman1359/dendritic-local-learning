\begin{abstract}
Learning in neural networks requires assigning task error to individual weights. Real neurons distribute these weights across dendritic branches: when must learning distinguish locations within a neuron? We derive conductance-tree gradients as local sensitivity multiplied by transported error, and describe restricted delivery through a dictionary of spatial profiles. One signal per neuron captures most of the benefit in image classifiers. Conflicting branch inputs instead require selective updates, and higher-order interactions favor example-dependent credit even when input-sensitivity spectra are matched. In conductance-neuron populations, an inhibitory resistance gate improves distractor robustness but fails on a nonlinear-branch interaction task. Supplying the missing parent-voltage derivative rescues learning with Adam; plain SGD remains inaccurate even with exact credit. Serial compartments also help remove nuisance gains when the necessary information is distributed across modules. Reconstructed arbors sparsely compress modeled perturbation fields, whereas measured visual responses show no detected preferential ancestry alignment in the sampled cells. Together, these results separate the spatial signals a task requires from the routes and gains dendrites can supply, without assuming that biological teaching signals use the modeled routes.
\end{abstract}

\section*{Introduction}

Learning requires assigning task error to individual weights. Backpropagation (BP) computes this assignment by applying the chain rule through a network \citep{rumelhart1986learning}; related sensitivity calculations apply to recurrent and steady-state systems \citep{almeida1987asynchronous,pineda1987recurrent}. For a point neuron, the gradient separates into a weight's local effect on output and that output's downstream effect on loss. Biologically, these factors correspond to a synaptic eligibility and a learning signal. Hebbian plasticity associates local pre- and postsynaptic variables \citep{hebb1949organization}, whereas three-factor rules combine eligibility with an outcome-dependent signal \citep{fremaux2016threefactor}. A local multiplication does not imply that its learning signal was computed locally.

Learning theories differ in how they obtain that signal. Feedback alignment uses separate error pathways \citep{lillicrap2016feedback,nokland2016dfa}; equilibrium, predictive and prospective methods infer target states or errors through dynamics \citep{scellier2017equilibrium,whittington2017predictive,song2024prospective}; eligibility propagation combines temporal traces with neuron-specific signals \citep{bellec2020eprop}. Preserving neuronal identity can convey more information than sharing one scalar across neurons \citep{werfel2005learning,whittington2019theories,lillicrap2020backprop}. Evidence for distinct instructive signals across neuronal populations motivates asking which additional distinctions matter within one arbor \citep{francioni2026vectorized}.

Real neurons distribute synapses across dendrites, where cable filtering, nonlinear integration and inhibition shape somatic output \citep{rall1962dendrites,koch1999biophysics,poirazi2003pyramidal,london2005dendritic,spruston2008pyramidal,branco2010single,larkum2013cellular}. Knowing which neuron contributed to an error need not identify which branch should change. Conversely, distinct branch computations need not require distinct learning signals. We ask when one signal per neuron suffices and when learning benefits from finer spatial information.

A learning signal has a value and a set of recipients. We describe its available spatial profiles as a \emph{route dictionary}: each column specifies the relative delivery amplitudes at recipient compartments, and an example-dependent coefficient scales that profile. One shared profile broadcasts through the arbor; several profiles can distinguish subtrees. A basis has independent columns, whereas a dictionary may be redundant. Conductance changes can modify delivery gains: inhibition lowers local resistance and attenuates other inputs even when its own current is small \citep{koch1983nonlinear,holt1997shunting,chance2002gain,gidon2012inhibition,lovettbarron2012regulation}.

Dendritic models already connect compartmental computation and plasticity to memory, feature binding and forward capacity \citep{poirazi2001capacity,legenstein2011branch,jones2021successive,beniaguev2021single}. Learning theories propose somatic prediction, segregated teaching, interneuron-mediated errors, bursts and prospective dynamics \citep{urbanczik2014dendritic,schiess2016somatodendritic,guerguiev2017segregated,sacramento2018dendritic,payeur2021burst,ellenberger2026gle,richards2019dendritic}; cable-learning models optimize reconstructed neurons through synaptic sensitivities \citep{bicknell2021synaptic}. Our question concerns the spatial information these mechanisms must preserve.

Building on our conductance-tree preprint \citep{safaai2026localcredit}, we derive the gradient and then test a progression from neuronal identity to branch selection and input-dependent transport. Conductance experiments ask which factors inhibition supplies and which it misses. Serial-depth controls separate forward computation from credit delivery. Reconstructed arbors and measured responses then test route availability and evidence of use separately. Throughout, representability is checked before attributing a learning deficit to credit assignment. The central distinction is between selecting a recipient branch and supplying the input-dependent sensitivity its update requires.

\section*{Results}

\subsection*{Exact gradients separate local sensitivity from downstream credit}

For a point neuron $u$ with output $y_u=f_u(\sum_iw_ix_i+b_u)$ and task loss $\mathcal L$, the chain rule gives $\partial\mathcal L/\partial w_i=x_if'_u\delta_u$. Here $i$ indexes inputs, $x_i$ and $w_i$ are input activity and weight, $b_u$ is bias, $f_u$ is the activation function, and $\delta_u=\partial\mathcal L/\partial y_u$ is the neuronal error. The derivative $f'_u$ is evaluated at the current input sum. Local eligibility $x_if'_u$ and task-derived credit therefore supply different information (Fig.~\ref{fig:framework}A). We use eligibility for this instantaneous local derivative; the present steady-state models do not include a temporal eligibility trace. Gradient descent changes a weight by minus its gradient times a positive learning rate $\eta$.

A directed compartment tree replaces the point neuron, with soma \(n=0\) and compartment voltages \(V_n\), suppressing the neuron index $u$ where unambiguous. A contact with maximal conductance \(g_i\geq0\), activity \(x_i\geq0\), and reversal potential \(E_i^{\mathrm{rev}}\) contributes current \(g_ix_i(E_i^{\mathrm{rev}}-V_n)\). A child \(c\) supplies output \(a_c=f_c(V_c)\) to its parent through coupling conductance \(g_{c\to n}^{\rm den}\). Let \(\mathcal S_n^X\) be the contacts of class \(X\in\{\mathrm E,\mathrm I\}\) on compartment $n$, and \(G_n^X=\sum_{i\in\mathcal S_n^X}g_ix_i\) their aggregate open conductance. Leak conductance and reversal potential are \(g_n^{\rm L}\) and \(E_{\rm L}\). Summing over children of $n$, the directed model imposes zero net current:
\[
0=g_n^{\rm L}(E_{\rm L}-V_n)
 +G_n^{\rm E}(E_{\rm E}-V_n)+G_n^{\rm I}(E_{\rm I}-V_n)
 +\sum_c g_{c\to n}^{\rm den}(a_c-V_n).
\]
Collecting the terms in \(V_n\) gives the steady state
\begin{equation}
\begin{aligned}
V_n&=R_n^{\rm tot}\left(g_n^{\rm L}E_{\rm L}+G_n^{\rm E}E_{\rm E}
 +G_n^{\rm I}E_{\rm I}+\sum_cg_{c\to n}^{\rm den}a_c\right),\\
(R_n^{\rm tot})^{-1}&=g_n^{\rm L}+G_n^{\rm E}+G_n^{\rm I}
 +\sum_cg_{c\to n}^{\rm den}.
\end{aligned}
\label{eq:directedvoltage}
\end{equation}
Here \(R_n^{\rm tot}\) is the reciprocal of the compartment's total conductance, with incoming child outputs held fixed. It is a local resistance in the directed model, not the driving-point resistance of a reciprocal cable, where neighboring voltages also respond to an injected current. Excitation and inhibition differ through their reversal potentials, not through a negative inhibitory conductance. The artificial trees use dimensionless \(E_{\rm E}=1\) and \(E_{\rm I}=E_{\rm L}=0\). Inhibition therefore contributes to the denominator but not the numerator: increasing \(G_n^{\rm I}\) lowers local resistance and attenuates excitation and child input. This is shunting inhibition. The division concerns steady-state voltage, not a general divisive effect on firing rate \citep{holt1997shunting}. These directed steady states are evaluated from terminals to soma; reciprocal reconstructed cables are treated separately below.

Holding the incoming child outputs fixed, differentiating Eq.~\ref{eq:directedvoltage} gives \(\partial V_n/\partial g_i=x_iR_n^{\rm tot}(E_i^{\rm rev}-V_n)\). Applying the chain rule then yields
\begin{equation}
\frac{\partial\mathcal L}{\partial g_i}
=\underbrace{x_iR_n^{\mathrm{tot}}(E_i^{\mathrm{rev}}-V_n)}_{\mathrm{local\ eligibility}}
\underbrace{\delta^V_{n,u}}_{\partial\mathcal L/\partial V_n}.
\label{eq:factorization}
\end{equation}
Excitatory and inhibitory contacts share this factorization (Fig.~\ref{fig:framework}A): eligibility measures conductance-to-voltage sensitivity, and credit measures voltage-to-loss sensitivity. For a coupling conductance, the corresponding local factor is $R_n^{\rm tot}(a_c-V_n)$. When $g=\exp\theta$ is optimized in log coordinates, the chain rule gives $\partial\mathcal L/\partial\theta=g\,\partial\mathcal L/\partial g$ (Supplementary Section~S1).

An additive control retains the graph while summing signed inputs without conductance division or reversal-potential driving forces. Its eligibility is differentiated from that additive computation (Methods).

Voltage error denotes a loss derivative. Each compartment has one directed path to the soma, giving
\begin{equation}
\delta^V_{n,u}=\delta^V_{0,u}\widetilde\alpha_n,
\qquad
\widetilde\alpha_n=
\prod_{(i\to k)\in\operatorname{path}(n\to0)}
f_i'(V_i)R_k^{\mathrm{tot}}g_{i\to k}^{\mathrm{den}}.
\label{eq:pathgain}
\end{equation}
Here \(f'_i(V_i)\) is the child compartment's output derivative, \(g_{i\to k}^{\mathrm{den}}\) is its coupling conductance to parent \(k\), and \(\delta^V_{0,u}=f'_0(V_0)\delta_u\) is the somatic voltage error. The path multiplier \(\widetilde\alpha_n\) converts one somatic error into a spatial field. The conductance-only component of this product is attenuated by additional conductance on a path's ancestors; branch nonlinearities and forward voltages can change as well (Supplementary Section~S1 and Fig.~S1).

Reciprocal cables instead require a joint adjoint calculation of how local currents affect task loss (Methods). These mathematical sensitivities do not establish a biological error-transmission mechanism.

Local credit assignment (LocalCA) retains eligibility and supplies an approximate compartment signal, denoted by a hat (Fig.~\ref{fig:framework}B shows a strict scalar, one signal per neuron and the exact path, each on a generic tree):
\begin{align}
\widehat\nabla_{g_i}\mathcal L
=x_iR_n^{\mathrm{tot}}(E_i^{\mathrm{rev}}-V_n)\widehat\delta^V_{n,u},
\label{eq:dendriticlocalrule}
\\
\widehat{\bm\delta}^{V}_u=A_u\bm c_u.
\label{eq:routedfield}
\end{align}
Columns of \(A_u\in\mathbb R^{N_u\times K}\) are fixed spatial delivery profiles over \(N_u\) routed nonsomatic compartments; \(\bm c_u\) contains their example-dependent coefficients. To distinguish coefficient generation from delivery gain, we can write \(\bm c_u=\Gamma_u\bm c_u^{\rm source}\), where diagonal \(\Gamma_u\) scales each profile and \(\bm c_u^{\rm source}\) is the supplied signal (Fig.~\ref{fig:framework}A, gain dial). Fixed nonzero gains leave the dictionary span and its oracle capture unchanged while altering conditioning and reliability-weighted learning (Supplementary Figs.~S4--S5). Broadcast, subtree and compartment profiles give increasingly detailed spatial addresses (Fig.~\ref{fig:framework}C). This is a delivery model, distinct from the forward cable equations and the mechanism estimating coefficients.


At \(K=1\), the all-ones column \(A_u=\bm1\) broadcasts one coefficient through the arbor; at \(K=N_u\), the identity matrix \(A_u=I\) can reproduce the full nonsomatic field. Nested subtrees provide intermediate dictionaries. Profile count, rank (the number of independent profiles) and coefficient information are distinct resources. Exact path transport combines one somatic scalar with state-dependent local derivatives; it does not require an independent external error for every compartment. We call a coefficient rule \emph{oracle} when it uses an exact field unavailable to the restricted learner. Such a rule tests what the dictionary could express, not how a biological circuit would calculate its coefficients.

Capture measures the fraction of learning-signal energy reproduced by a dictionary:
\[
\mathcal C(A;\bm\delta)=\frac{\|P_A\bm\delta\|^2}{\|\bm\delta\|^2},\qquad P_A=AA^\dagger.
\]
Here $A^\dagger$ is the Moore--Penrose pseudoinverse. Averaging these ratios weights fields equally; $\tr(P_AC)/\tr(C)$, with uncentered second moment $C=\E[\bm\delta\bm\delta^{\mathsf T}]$, weights them by energy. Both use oracle least-squares coefficients and measure reconstruction, not task performance.

The field coordinate also matters. In nonlinear image models, we route errors of compartment outputs and retain the local output derivative in eligibility; voltage-error capture is reported separately. Identity-output conductance trees use voltage errors directly. Supplementary Table~S2 compares the coordinates, coefficient sources and state dependence. Exact-transport, activation and additive-integration controls are reported in Supplementary Fig.~S2. Learning experiments test whether this available capacity improves performance.

Projection can also filter update noise outside a dictionary's span. Retaining most of the useful gradient while admitting less noise can improve a one-step guarantee (Supplementary Fig.~S3G). If the span contains the entire gradient, its mean is preserved. A smoothness bound formalizes this balance between retained descent and update variance (Methods). Its initialization utility did not select the best final morphology: in a separate 12,800-fit prospective experiment, it lost to a fixed maximum-budget tree in all twenty seed averages in both selection arms (Supplementary Fig.~S34). We therefore use the bound to interpret local filtering, not to select a final tree.

\subsection*{One signal per neuron captures most of the image-task learning benefit}

Image classification establishes a reference for within-arbor resolution. DendriNet implements directed artificial conductance trees \citep{safaai2026gainload}, not reconstructed or spiking neurons. The MNIST networks used one layer of 128 $[3,3]$ trees, each with three proximal and nine terminal compartments, followed by a trainable readout. Branching vectors list daughter counts from soma to tips. Shunting and raw-additive controls shared the graph, contacts, nonlinearities and protocol, with architecture-specific initialization; the additive model removed the conductance denominator and reversal-potential driving forces.

Six rules separated neuronal identity, spatial resolution and core learning (Fig.~\ref{fig:framework}B--D). A strict scalar shared one signal across neurons; per-neuron feedback broadcast each neuron's readout-derived output error through its arbor. Projected $K=1$ and $K=3$ rules instead averaged the exact activation-error field across the arbor or within each proximal subtree. Per-neuron and projected $K=1$ feedback therefore shared a spatial profile but differed in coefficient source. Exact paths retained every compartment error; a decoder-only reference froze the dendritic core. Three development seeds selected rates from three common multipliers, followed by ten fresh paired seeds per architecture at selected and common rates over 180 epochs (Methods; Supplementary Fig.~S7).

Per-neuron feedback exceeded the strict scalar by 9.23 percentage points in shunting trees and 7.46 in additive trees, reaching 97.12\% and 97.11\% accuracy; decoder-only learning reached 80.96\% and 89.57\% (Fig.~\ref{fig:framework}D,E). Increasing the projected dictionary from one to three profiles added only 0.049 points in shunting trees (95\% paired interval, $-0.048$ to 0.141) and 0.036 in additive trees ($-0.056$ to 0.122), with similarly small common-rate differences. Exact paths added 0.010 points over per-neuron feedback in shunting trees and 0.182 in additive trees (0.114--0.252), while underperforming projected $K=3$ by 0.09 and 0.04 points. Most benefit came from preserving neuronal identity; even the smaller additive improvement was attainable with one projected profile.

Direct feedback alignment (DFA) replaced the readout derivative with a fixed random feedback matrix \citep{nokland2016dfa}. Per-neuron feedback then gained 11.03 and 10.80 points over the strict scalar, whereas exact paths added at most 0.09 points (fifteen paired seeds; Fig.~\ref{fig:framework}E,F). Fashion-MNIST similarly favored per-neuron feedback by 4.46 and 3.78 points over its scalar-fallback control, with exact paths within 0.14 points (ten seeds). That fallback retains neuronal signals for a subset of parameters, unlike the strict scalar. On flattened CIFAR-10, exact paths reduced accuracy relative to per-neuron feedback by 0.86 points (0.55--1.17), while matching BP within a prespecified one-point equivalence margin ($-0.115$ points, $-0.457$ to 0.226; two one-sided tests $P=1.6\times10^{-5}$; twenty seeds). These cohorts differ in feedback source, scalar construction and tree. Complete feedback, input-coverage and ordinary-task depth controls are in Supplementary Figs.~S6--S9.

Richer dictionaries nevertheless captured more trained activation-error energy: mean capture rose from 0.622 to 0.655 in shunting trees and from 0.764 to 0.859 in additive trees when moving from one to three profiles (Fig.~\ref{fig:framework}G). The identity dictionary reproduces the field by construction. These averages over example--neuron fields show that improved reconstruction need not yield a comparable accuracy gain (Supplementary Section~S2). We next make spatial selection explicitly relevant to the task.

\subsection*{Branch-selective information prevents updates from inactive distractors}

Branch selection matters when local activity comes from irrelevant inputs. A logistic classifier had $B\in\{2,4,8\}$ parallel branch weight vectors, without internal forward compartments or conductance nonlinearities (Fig.~\ref{fig:branchconflict}A). Context selected the branch determining the output, but every branch formed an ungated eligibility. Inputs were pooled Fashion-MNIST images from two classes, giving 50\% chance accuracy. At conflict dose $\chi=0$, all branches received the selected image; increasing $\chi$ replaced nonselected images independently with opposite-class examples.

For example $i$, selected branch $b_i^\star$, input $\bm x_{i,b}$ and target $y_i\in\{0,1\}$,
\begin{equation}
z_i=\bm w_{b_i^\star}^{\mathsf T}\bm x_{i,b_i^\star},\qquad
\delta_i=\sigma(z_i)-y_i,
\label{eq:branchconflictforward}
\end{equation}
where $\sigma$ is the logistic function. Unselected branches have zero exact derivative despite nonzero eligibility. For $N$ examples, branch-specific and neuron-shared updates use
\begin{equation}
\bm d_b^{\rm selected}=N^{-1}\sum_i\delta_i\mathbf1[b_i^\star=b]\bm x_{i,b},\qquad
\bm d_b^{\rm shared}=N^{-1}\sum_i\delta_i B^{-1}\bm x_{i,b}.
\label{eq:branchconflictupdates}
\end{equation}
Weights change by $-\eta\bm d_b$. The factor $1/B$ matches summed delivery coefficients, not update norms. A feedback selector and an eligibility gate are algebraically equivalent. In dictionary notation, $A=I_B$, $\Gamma_{bb}=\mathbf1[b_i^\star=b]$ and $\bm c^{\rm source}=\delta_i\bm1_B$: one error and a context cue control $B$ branch profiles, rather than a fixed $K=1$ profile. Context $c$ is distinct from coefficient vector $\bm c_u$. Deranging the route preserves rank and sparsity while changing recipients (Fig.~\ref{fig:branchconflict}B).

Initial signed utility, $\langle\bm d^{\rm shared},\bm d^{\rm selected}\rangle/\|\bm d^{\rm selected}\|^2$, predicts descent when positive and ascent when negative. Centered symmetric evidence gives the initialization prediction $s(\chi)=1-2\chi(B-1)/B$, crossing zero at $\chi_c=B/[2(B-1)]$. Measured utility differed by at most 0.018 at all twenty-four sampled settings, although eleven bootstrap intervals excluded the prediction (Fig.~\ref{fig:branchconflict}C). Trained chance crossings were displaced because alignment changed during learning, but followed $B=8<4<2$ in all twenty seeds; five two-branch seeds never crossed chance (Fig.~\ref{fig:branchconflict}D; Supplementary Fig.~S10).

In a separate synthetic interference task, shared credit erased a previously acquired context, losing 55.7 points [53.8, 57.6], while subtree selection lost none in ten seeds (Fig.~\ref{fig:branchconflict}E).

Correct selection gained 34.9--58.2 accuracy points over shared credit at full conflict; its advantage increased with conflict in every seed. Derangement was harmful even at zero conflict, losing 12--25 points, and approached 22\% accuracy at high conflict (Fig.~\ref{fig:branchconflict}F--H). BP and the gated point control matched branch-specific selection exactly. Branch-count comparisons do not fix capacity. These results identify recipient assignment, rather than the number of external errors, as the relevant information.

\subsection*{Ancestry provides a modest advantage at an intermediate feedback budget}

Nested subtree profiles offer intermediate resolution between broadcast and branch-specific delivery. Eight independent eight-dimensional terminal weight blocks occupied a balanced binary feedback tree; only the context-selected block determined the logit. Internal nodes defined feedback supports without serial forward computation (Fig.~\ref{fig:subtreefactorial}A). Distractors opposed the selected class increasingly with hierarchical distance, deliberately favoring the matched task-to-route assignment.

Budgets $K\in\{1,2,4,8\}$ supplied independent unit-length patterns grouping all terminals, halves, sibling pairs or single terminals. The selected stream's class coefficient was one; sibling, same-half nonsibling and other-half coefficients were $-0.15$, $-0.45$ and $-0.75$. Summing within the selected ancestry group gave $-3.05$, $-0.05$, $0.85$ and $1$ across the four budgets. Unit-length normalization preserves these signs: sibling pairs are the first intermediate grouping with positive signal. This budget follows from task design, not discovery of an optimal anatomical resolution.

Rank-matched controls changed assignment, support geometry or sparsity through cyclic derangement, depth-interleaving, random-sparse routes and dense random fields. Figure~\ref{fig:subtreefactorial}B preserves the signs of the delivered coefficients $\Phi_{cb}$, normalized by each row's maximum absolute value. Permuting task streams across leaves leaves forward resources fixed. Matched partitions had coincident field capture, so capture alone cannot explain performance (Supplementary Fig.~S11A).

Correct routing improved with resolution, while coarse pooling and derangement produced below-chance outcomes (Fig.~\ref{fig:subtreefactorial}C). Degree--depth-preserving rewiring cost 23.15 and 5.02 points at $K=2,4$ but left fully shared and fully resolved routes tied (Fig.~\ref{fig:subtreefactorial}D). The ancestry-specific effect was smaller: ancestry lost to the best matched control at low budgets, gained 1.27 points at $K=4$ (95\% paired interval, 0.59--1.95; 15/20 positive; Holm-adjusted signed-rank $P=0.0101$ across budgets), and tied at full resolution. Its $K=4$ advantages over dense, random-sparse, depth-interleaved and deranged controls were 2.31, 3.77, 7.11 and 61.06 points (Fig.~\ref{fig:subtreefactorial}E).

A separate twenty-seed cohort learned route coefficients from noisy cues. An encoder trained on 256 cues with noise SD 0.5 improved over a frozen profile by 7.16 points but remained 54.47 below oracle routing. Exploratory hard selection of its most probable route reduced that gap to 16.26 points (Fig.~\ref{fig:subtreefactorial}F). With noise-free cues, hard selection matched the oracle at every calibration size; soft delivery lost 60.90 points with sixteen calibration cues but only 0.31 with 256. Thus leakage into incompatible routes depends on coefficient quality. Delaying either readout across independent contexts removed its benefit (Supplementary Section~S3).

\subsection*{Cross-branch interactions change the spatial credit that learning uses}

Branch interactions can change credit between examples even when input-sensitivity spectra match. Seven scalar computational units allowed an exact representability test before comparing learning. Each unit computed $u=a+bu_L+cu_R+du_Lu_R$, affine in either child while the other is fixed. Eight independent inputs were equally likely to be $-1$ or $+1$. Pairwise targets summed four disjoint products, $f_M=\frac12\sum_{(i,j)\in M}s_{ij}x_ix_j$; quartic targets combined complementary quartets, $f_A=\frac12(s_A\prod_{i\in A}x_i+s_{\bar A}\prod_{i\notin A}x_i)$. Signs were independently sampled from $\{-1,+1\}$; here $A$ is an input set, not a delivery matrix. Paired targets shared the compatible tree, input assignment, initial weights and examples (Fig.~\ref{fig:prospective}A).

Both targets have input-sensitivity second moment $\E[\nabla_xf\nabla_xf^{\mathsf T}]=I_8/4$. However, orthogonality of binary-input products gives $\E\|\nabla_xf\|^2=d\operatorname{Var}(f)$ for homogeneous degree $d$. Matching this spectrum therefore requires clean variances one and one-half for pairwise and quartic targets; equal absolute label noise gives twice the quartic relative noise floor. Both tasks use squared-error loss. Spectrum matching controls first-derivative sensitivity, not interaction order or relative noise.

Compatibility means that some parameter setting represents the target exactly. At every subtree boundary, the interaction-coefficient matrix between inside and outside input products must have rank at most one after removing the constant inside row. This condition is necessary and sufficient across boundaries; discarded singular values bound representation error. Logical-rule examples show why particular input groupings and depths can be required before learning is considered (Methods; Supplementary Section~S4 and Figs.~S14--S15).

All rules used exact local eligibilities and the same output error. Exact paths were compared with unit broadcast and a calibrated six-site profile, frozen from mean path derivatives on 256 unlabeled initialization examples (Fig.~\ref{fig:prospective}B). Three development seeds selected rates with equal budgets; twenty fresh paired seeds evaluated them. A separate nested target used prefix interactions on its own compatible depth-four tree, without the matched spectrum (Supplementary Fig.~S12F).

NMSE divides prediction MSE by clean target variance. At 1,024 updates, exact and calibrated means were 0.0317 and 0.0236 for pairwise targets, but 0.1516 and 0.9813 for quartic targets (Fig.~\ref{fig:prospective}C,D). The predefined quartic-minus-pairwise difference in calibrated-minus-exact gaps was 0.838 (95\% paired interval, 0.719--0.931), positive in all twenty seeds; a common rate gave 0.843 (0.727--0.935). Seventeen exact quartic fits were near the noise floor; three stalled fits resolved between 1,024 and 4,096 updates. One slow exact pairwise fit also affected its mean, although exact credit won in fifteen seeds. Nested outcomes are retained in Supplementary Figs.~S16--S17.

Twenty additional paired seeds tested fixed absolute, zero and matched relative label noise, using inherited selected and common Adam rates. At 16,384 updates, the clean full-domain interaction deficit was 0.963 (0.898--1.020), 1.030 (0.935--1.120) and 1.007 (0.930--1.084), respectively, positive in every seed. The selected-rate comparison is shown in Fig.~\ref{fig:prospective}E. Thus unequal relative noise does not explain this fixed-profile deficit under the tested settings. This sensitivity uses new seeds without noise-specific retuning, not a convergence claim (Supplementary Section~S4).

Extending every trajectory to 16,384 updates without retuning removed the exact pairwise lag but preserved the interaction deficit: 0.952 (0.883--1.012) at endpoints and 0.790 (0.691--0.880) at validation-selected states, positive in all twenty seeds at all four budgets (Fig.~\ref{fig:prospective}F). These are previously observed seeds, with bounded dynamics: calibrated arms contacted coefficient bounds and exact arms did not. Common-rate and optimizer controls remain in Supplementary Table~S8.

Learned fields reveal the distinction missed by the input spectrum. Let $\bm q(x)$ contain the six nonsomatic derivatives of root output with respect to branch output. At 1,024 updates, the best rank-one profile with oracle amplitudes captured 99.7\% of exact-trained path energy for pairwise targets, but 46.1\% for quartic and 44.8\% for nested targets; at 16,384 updates these became approximately 100\%, 39.6\% and 40.5\%. Reaching 95\% required one direction for pairwise targets and about five for the others (Fig.~\ref{fig:prospective}G). Uniform-profile capture was only 0.122, 0.169 and 0.176: a low-dimensional field can have a nonuniform signed direction. Alternative weightings and replay checks preserve the spectral separation (Supplementary Section~S4).

The same noise-control seeds retained the deficit at common rate 0.003 (Fig.~\ref{fig:prospective}H).

These results favor input-dependent credit without establishing that all six exact channels are necessary. Existing one- and two-profile oracle learners test intermediate resolution. Leaf-assignment, Boolean, positive-conductance and optimizer controls delimit the claim: calibrated Adam can learn a compatible positive-conductance teacher, and broadcast can learn aligned XOR-of-AND (Supplementary Figs.~S13--S18). Finite-calibration construction and direct learning tests remain in Supplementary Fig.~S36. The interaction structure motivates particular credit comparisons, rather than a universal resolution law.

\subsection*{Local inhibitory selection preserves opposing branch tuning}

We next tested whether inhibition supplies useful spatial selection in a conductance neuron. A seven-compartment teacher and student shared four terminals, two proximal compartments and a soma, guaranteeing representability. Both subtrees received $\exp(\pm z_j)$ for independent $z_j\sim\mathcal U[-2,2]$. Binary context inhibited one proximal compartment. Teacher tuning increased with features in both subtrees for aligned targets, but increased in one and decreased in the other for opposed targets (Fig.~\ref{fig:conductancecredit}A). All 24 excitatory, inhibitory and coupling conductances learned from paired initial states and examples. A simpler monotonic teacher was already learnable with broadcast despite a varying path field (Supplementary Fig.~S19).

Context changes distal transport while leaving proximal credit context invariant. A local terminal rule delivered $\widehat\delta^V_i=\delta^V_0\mathbf1[a_p=0]$, where parent inhibitory activity $a_p$ was zero or ten. Proximal and somatic signals remained ungated. The rule uses supplied context and somatic error with exact local eligibilities, without evaluating path products. Two fixed distal profiles with oracle amplitudes and unit proximal credit supplied a capacity control (Fig.~\ref{fig:conductancecredit}B).

Twenty paired seeds tested nine rules at three rates through 16,384 updates, with primary rate and 4,096-update window fixed beforehand. On opposed targets, validation-selected NMSE was $2.18\times10^{-5}$ for exact credit, $2.33\times10^{-5}$ for the gate, $2.28\times10^{-5}$ for the oracle and 0.487 for broadcast. Aligned-target exact, gate and broadcast errors were $7.53\times10^{-6}$, $1.06\times10^{-5}$ and $5.53\times10^{-4}$ (Fig.~\ref{fig:conductancecredit}C,D). The opposed-minus-aligned change in broadcast-minus-gate error was 0.487 (95\% paired interval, 0.360--0.615), positive in all twenty seeds, and remained 0.468 (0.332--0.604) at the longer window (Fig.~\ref{fig:conductancecredit}E).

Reversing distal selection gave opposed NMSE 0.949. Gating proximal updates as well gave 0.123 and froze both proximal inhibitory gains: their eligibility is nonzero precisely when that gate closes. Correct distal gating changed all 24 parameters and succeeded across tested rates; its continuous version reached $2.32\times10^{-5}$ (Fig.~\ref{fig:conductancecredit}F). For context-specific gradients $\bm v_c$ with probabilities $p_c$, the fraction surviving averaging is $\|\sum_c p_c\bm v_c\|/\sum_c p_c\|\bm v_c\|$; one means no cancellation. In an earlier cohort, this fraction was 0.64 for exact credit at initial and broadcast-trained weights, but fell from 0.33 to 0.17 for calibrated broadcast (Fig.~\ref{fig:conductancecredit}G). Eighteen opposed broadcast fits contacted bounds by 4,096 updates, compared with none for exact or correct distal gating; wider-bound controls remain in Supplementary Fig.~S20.

Independent-input follow-ups extended the comparison to graded teacher, sensory-selection and sensory-mixture targets. Relative input resistance improved over broadcast in all twenty seeds of each task, whereas the earlier proportional gate failed on graded mixtures. Residual errors and bound contacts limit this extension (Supplementary Section~S5 and Supplementary Table~S13).

\subsection*{Branch selection leaves an input-dependent sensitivity requirement}

For a population test, sixteen DendriNet $[4,2]$ neurons each pooled four two-feature streams. A cue $c_b$ selected one stream, and inhibition $a_b^{\rm I}=4(1-c_b)$ suppressed the other proximal branches. All models retained cue inputs. The externally specified target was
\[
y=\sum_{b=0}^3c_b(-1)^b\frac{\tanh z_{b1}+\tanh z_{b2}}2.
\]
Figure~\ref{fig:conductancepopulation}A summarizes the task and forward model. Features were independently uniform on $[-2,2]$ and encoded as $\exp(\pm z_{bj})$. Stress replaced features by $[1+(s-1)(1-c_b)]z_{bj}$ at severity $s$, keeping selected features, cues and labels fixed. The continuous gate is $h_{up}=D_{up}^0/(D_{up}^0+g_{up}^{\rm I}a_b^{\rm I})$, with baseline parent denominator $D_{up}^0$. Terminals received $\delta_u^Vh_{up}$; proximal/somatic signals remained ungated. Wrong-branch gates cyclically permuted the four gains. A uniform RMS control preserved gate-vector norm but discarded assignment; it does not equalize eligibility-weighted update norms.

The gate's benefit was strongest under distractor stress. Across twenty fresh paired seeds, it reduced ordinary-test mean NMSE approximately 1.7-fold. Under severity-three stress, broadcast, gate and exact means were 0.0105, 0.000121 and 0.000119. The approximately 87-fold broadcast/gate ratio uses development-selected rates 0.03 and 0.1; at common rate 0.1 it was 6.6-fold, with a 0.000681 paired reduction positive in every seed (Fig.~\ref{fig:conductancepopulation}B). Uniform RMS and wrong-branch controls were worse, supporting correct assignment rather than attenuation alone. Tonic inhibition and matched current injection also increased stress error under exact BP (Fig.~\ref{fig:conductancepopulation}C). Forward selection and credit delivery therefore contribute separately. Figure~\ref{fig:conductancepopulation}D places the selected- and common-rate ratios side by side.

The chain rule identifies the gate's boundary. For terminal $i$, parent $p$ and soma $u$,
\begin{equation}
\delta^V_{ui}=\delta^V_u\,\kappa_{ui}\,h_{up}\,f'_p(V_p),\qquad
\kappa_{ui}=\frac{g_{p\to u}^{\rm den}g_{i\to p}^{\rm den}}{D_uD_{up}^0},
\label{eq:populationtransport}
\end{equation}
where $D_u=1+\sum_p g_{p\to u}^{\rm den}$. The prefactor $\kappa_{ui}$ is constant across examples at fixed weights but changes during learning. Identity parents give $f'_p=1$; nonlinear parents add input-dependent sensitivity, $1-\tanh^2(V_p)$ for $\tanh$. Resistance alone omits it.

The gate did not improve the nonlinear-parent interaction task: ordinary-test mean NMSE was 0.0511 for gating, 0.0471 for broadcast and $5.06\times10^{-5}$ for exact BP. The gate-minus-broadcast difference was 0.00397 (descriptive paired interval, 0.00040--0.00794). Bounds were contacted during training in 18/20 gate, 19/20 broadcast and 2/20 exact fits, not necessarily at selected states. Here both the target and parent nonlinearity changed. A smaller graded-mixture population pilot also failed, with a separate representation limit (Supplementary Table~S14).

We tested the missing factor directly, holding the nonlinear task and forward model fixed. Augmentation delivered $\delta_u^Vh_{up}f'_p(V_p)$; its control shuffled $f'_p$ across examples within each parent and context. Twenty new paired seeds followed separate validation-only rate selection. Adam augmentation reduced resistance-only NMSE from 0.0504 to $6.02\times10^{-5}$, close to but above exact BP's $4.49\times10^{-5}$. Shuffling left 0.0436. Both primary advantages held in all twenty seeds (Holm-adjusted $P=3.81\times10^{-6}$ each; Fig.~\ref{fig:conductancepopulation}E; Supplementary Table~S15).

The rescue persisted at common rate 0.03 (Fig.~\ref{fig:conductancepopulation}F) and wider bounds. Resistance and augmentation never contacted bounds at their new selected rates, so saturation does not explain their difference. With SGD, augmentation improved 0.0767 only to 0.0755 (Supplementary Table~S15). Full-factor delivery matched BP algebraically. Exact SGD also remained inaccurate; an expanded development grid at 32,768 updates failed the predefined low-error criterion (Supplementary Section~S5). Thus the SGD comparison does not isolate a derivative-specific failure. Under independent symmetric features, a cue-only gate gives zero expected target-interaction contribution to terminal updates; parent sensitivity breaks this factorization. This concerns that component, not the entire gradient (Supplementary Section~S5). Supplying parent sensitivity to terminals remains an assumed information pathway, not a demonstrated biological mechanism. With the same nonlinear parents but a separable target, resistance alone reached $9.32\times10^{-5}$ NMSE versus $7.52\times10^{-5}$ for augmentation at common rate 0.03. Removing the interaction largely removed the deficit despite retaining parent nonlinearity (same rescue seeds; Fig.~\ref{fig:conductancepopulation}G; Supplementary Section~S5).

\subsection*{Serial dendritic computation helps when nuisance information is distributed}

The previous experiments fixed a compatible forward model while changing credit. Varying serial depth instead asks whether successive compartments help remove multiplicative nuisance gains. Physical depth $D_{\rm p}$ counts forward stages; feedback resolution counts backward distinctions.

DendriNet networks had 64 somata and eight nonsomatic compartments per soma. D1 $[8]$, D2 $[2,3]$ and D3 $[2,1,2]$ distributed them over one to three stages; a four-tier task added D4 $[1,1,2,2]$. The two-tier D2 tree used $[4,1]$. These designs retained 66,178 trainable parameters and 14,336 active synapses. A resource-identical grouped-point control connected all modules directly to the soma; raw-additive trees removed divisive normalization. Approximately parameter-matched point networks supplied a separate reference (Fig.~\ref{fig:physicaldepth}A).

Excitation carried class information multiplied by nuisance gains: $x_{\rm E}=\max\{b_{\rm E}+y\Delta+\epsilon_{\rm E},10^{-4}\}\prod_\ell\exp(\sigma_\ell z_\ell)$, with independent standard Gaussian $z_\ell$, $\Delta=0.80$ and $\sigma_\ell=0.25$. Inhibitory sensors reported those gains with fidelity $\alpha$: zero preserved sensor distributions but removed trial-specific information; one reported the factor exactly. With inhibitory reversal zero, sensors could support successive divisions \citep{carandini2012normalization}. Nested gains acted on fine, coarse and global groups; flat gains had equal-resolution supports; local-ratio tasks placed all required information within each module (Fig.~\ref{fig:physicaldepth}B). The families differ in spatial support, not whether multiplication commutes. Supplementary Section~S6 specifies generators and the development-selected operating point.

Under exact BP at full fidelity, serial trees exceeded the grouped-point control by 30.32 accuracy points for nested gains (95\% paired interval, 30.02--30.62), 22.20 for flat gains (21.73--22.65), and exactly zero for local ratios. Removing sensor information eliminated the benefit (Fig.~\ref{fig:physicaldepth}C). Nested-task accuracy rose from 61.0\% at D1 to 67.5\% at D2 and 91.8\% at D3; grouped and reversed controls remained near 61\%, while an approximately matched point network reached 99.0\% (Fig.~\ref{fig:physicaldepth}D). A fourth stage did not help the four-tier task: D4 minus D3 was $-1.46$ points ($-1.74$ to $-1.16$; Supplementary Figs.~S22--S24). Serial structure helped when needed information was distributed across modules.

Credit rankings depended on training duration. Ten paired seeds restarted D1 exact BP and five D3 conditions to 600 epochs, retaining original rates, parameter groups and thirty-epoch validation patience. These were source-consistent restarts, not checkpoint continuations, because optimizer/random states were unavailable. At validation-selected states, exact-BP D3 exceeded D1 by 30.82 points at 180 epochs and 38.17 at 600. Eight D1 fits stopped early; every D3 fit reached the cap with validation loss still falling (Fig.~\ref{fig:physicaldepth}E,F).

Within D3, exact-path-minus-shared-soma LocalCA accuracy changed from $+10.86$ points at 180 epochs to $-1.52$ at 600 ($-1.83$ to $-1.23$), reversing in all ten seeds. The mean remained negative from epoch 315, but intervals intermittently straddled zero between epochs 300 and 325 (Fig.~\ref{fig:physicaldepth}G). Exact-path LocalCA retained lower cross-entropy, ending at 0.254 versus 0.276 nats, with nine negative paired differences (Fig.~\ref{fig:physicaldepth}H). Under the BP recipe, exact-minus-broadcast accuracy instead remained positive at 0.48 points (0.40--0.55). BP and LocalCA recipes differ only in base rate and parameter grouping; clipping, decay and masks are matched. Supplementary Fig.~S24C retains optimizer-matched contrasts. Forward usefulness does not establish an eventual winner among credit rules.

\subsection*{Reconstructed arbors provide spatial routes beyond a shared broadcast}

The learning tasks motivate asking which delivery patterns real arbors supply. MICrONS combines mouse visual-cortex anatomy, calcium-imaging responses and mapped synaptic partners \citep{microns2025}. Observed geometry defines soma-rooted ancestry; conductances, voltages and gradient fields are modeled.

Each inhibitory-bearing segment supplied a candidate route over its input-bearing descendants (Fig.~\ref{fig:topology}A,B). Focal shunts generated signed fields $t_i=d_{\rm sh}^{-1}\log[(|\gamma_i'|+\epsilon)/(|\gamma_i|+\epsilon)]$, where $\gamma_i,\gamma_i'$ are excitatory-conductance gradients before and after intervention and $d_{\rm sh}=0.001$ is dose relative to local leak-plus-synaptic conductance. For route matrix $A_K$, diagonal excitatory-area weights $W$ and weighted least-squares projector $P_{A_K,W}$,
\begin{equation}
\mathcal C(A_K;\bm t)=\frac{\|P_{A_K,W}\bm t\|_W^2}{\|\bm t\|_W^2},\qquad
\|\bm v\|_W^2=\bm v^{\mathsf T}W\bm v.
\label{eq:reconstructioncapture}
\end{equation}
Ensemble capture sums energies over perturbations. A common-constrained singular-value-decomposition dictionary supplies a rank-budget ceiling. Random anatomical routes, depth bins, density-preserving shuffles and degree--depth surrogate trees control spatial organization (Fig.~\ref{fig:topology}C).

These passive fields favor ancestry under somatic loss by construction. The test measures compression of the tree's own responses, not observed teaching. Broadcast alone captured 31.4\% in the initial eight cells, near the 32.6\% rank-one ceiling. Every dictionary therefore included broadcast plus $K-1$ spatial profiles, fixed before testing 47 disjoint cells from the same mouse and a second-mouse cohort. For each cell, spatial share is $C-C_0$ and residual capture is $C_{\rm res}=(C-C_0)/(1-C_0)$, where $C_0$ is broadcast capture. We calculate these within each cell before averaging across cells.

Varying $K$ separates the common signal from additional spatial capture. At eight columns in the 47-cell cohort, total capture was 0.203 for broadcast, 0.619 for ancestry, 0.578 for degree--depth surrogates, 0.511 for depth bins and 0.436 for shuffled routes (Fig.~\ref{fig:topology}D,E). Ancestry exceeded each cell's surrogate mean in 38 cells, but at least half the surrogates matched or exceeded it in eleven (Fig.~\ref{fig:topology}F). Its paired surplus over surrogates was 0.041 of total energy (95\% cell-bootstrap interval, 0.020--0.062), or 5.08 percentage points of residual energy (2.44--7.68). Against depth bins, residual gain was 13.51 points (9.86--16.84; 45/47 positive; Fig.~\ref{fig:topology}G). Coarse geometry thus explains much of the compression.

Ancestry used 18.75\% of dense-dictionary entries on average, including 12.5\% for broadcast. Shuffled routes preserved this nonzero count at lower capture. Nonzero density is a delivery-cost proxy, not measured cable length, synapse count or metabolic expenditure; equal column budgets also need not give equal rank.

The ancestry--surrogate--depth ordering held in the initial cohort and eight eligible Pinky cells from a second mouse (Fig.~\ref{fig:topology}H). Pinky's smaller arbors approach the residual-capture ceiling; lower-budget outcomes and exclusions remain separate. Labeling, geometry and compression controls are in Supplementary Figs.~S25--S28. No inhibitory-targeting endpoint persisted after joint three-dimensional matching, and the initial anatomy-specific coarse-energy excess did not replicate in the 47-cell cohort. These constraints limit the anatomical specificity of the modeled advantage.

\subsection*{Focal shunts set ancestry gains, with spatial selectivity controlled by cable state}

A focal shunt links anatomical routes to conductance-dependent gains. In reconstructed reciprocal cables, we compared inhibition with an injection matching its baseline focal current, plus a separately solved somatic current restoring baseline somatic voltage (Fig.~\ref{fig:focal}A).

Baseline voltages satisfy $G\bm V=\bm b$. Adding conductance $\kappa_k$ at site $k$ changes $G$ to $G+\kappa_k\bm e_k\bm e_k^{\mathsf T}$ and the source to $\bm b+\kappa_kE_{\rm I}\bm e_k$; matched injection supplies $\kappa_k(E_{\rm I}-V_k)$ without changing $G$. The adjoint $\bm q=G^{-\mathsf T}\nabla_{\bm V}\mathcal L$ measures loss sensitivity to injected current, distinct from local voltage credit or the scalar-tree path vector. For fixed somatic loss derivative,
\begin{equation}
\bm q'=\bm q-\frac{\kappa_kq_k}{1+\kappa_k(G^{-1})_{kk}}G^{-1}\bm e_k.
\label{eq:sherman}
\end{equation}
Here $G^{-1}\bm e_k$ is the voltage response to unit current at $k$, and $(G^{-1})_{kk}$ is driving-point resistance. All descendants share attenuation $[1+\kappa_k(G^{-1})_{kk}]^{-1}$; sister blocks along the soma path and the soma-side remainder each share another factor. Baseline-transfer-weighted indicators of these disjoint ancestry blocks form a dictionary on which the shunt acts through diagonal gains $\Gamma_u$ (Fig.~\ref{fig:focal}B). This identity need not hold in an arbitrary overlapping route dictionary.

The full excitatory-conductance gradient is $\gamma_i=q_id_i$, with driving force $d_i=E_{\rm E}-V_i$, which can vary within a block. In the small-dose fields of Fig.~\ref{fig:topology}, driving-force and adjoint terms strongly opposed one another, yet 97.1--99.9\% of full-field energy remained within the focal ancestry partitions (Supplementary Section~S8).

We measured absolute log gradient change $m_i=|\log[(|\gamma_i'|+\epsilon_\gamma)/(|\gamma_i|+\epsilon_\gamma)]|$, and localization $\Lambda_k=\operatorname{median}_{D(k)}m_i-\operatorname{median}_{C(k)}m_i$ between descendants $D(k)$ and depth-matched off-route sites $C(k)$. In the permissive normalized model, shunt localization increased with dose, while injection changed descendant gradients roughly threefold less (Fig.~\ref{fig:focal}C,D). Injection's unrelated-site changes were zero under the soma-restoring construction, not in general.

The contrast $\Delta\Lambda_k=\Lambda_k(\bm q'\odot\bm d')-\Lambda_k(\bm q\odot\bm d')$ substitutes the adjoint while holding post-shunt driving force fixed; each localization is always relative to the same baseline. This increased localization by 0.079 log units, positive in all eight cells. Driving-force substitution alone gave 0.026 against 0.104 for the full shunt (Fig.~\ref{fig:focal}E). This intervention separates sensitivity transport from local voltage effects.

Physical calibration constrained selectivity. At $R_a=150\,\Omega\,\mathrm{cm}$ and $R_m=15{,}000\,\Omega\,\mathrm{cm}^2$, shunt-minus-injection localization was small and opposite-signed in the initial eight and disjoint 45 cells: $-0.0019$ and $+0.0024$. Shunts attenuated descendant and off-route gradients; lower membrane resistance increased descendant attenuation, whereas matched injection enhanced gradients (Fig.~\ref{fig:focal}F,G). Background conductance restored localization at high resistance: contrasts were $-0.0004$, $+0.121$ and $+0.259$ at zero, one and four background-leak units, positive in all eight cells for the latter two conditions (Fig.~\ref{fig:focal}H). Thus selectivity depends on electrotonic state \citep{chance2002gain,destexhe2003highconductance}.

Fixed-absolute, relative-local and input-normalized dose controls remain in Supplementary Fig.~S29A. Weak voltage-dependent currents gave similar responses around the tested steady states, but their baseline Jacobian was fixed across doses; this does not establish robustness to strongly active dendrites or channel kinetics (Supplementary Fig.~S30D,E). The ancestry identity supplies a modeled transport mechanism \citep{gidon2012inhibition}, not evidence that these routes carry endogenous errors.

\subsection*{Measured responses bound the anatomical alignment proposal}

Measured responses test whether functional relationships follow the ancestry structure suggested by modeled capacity and transport. Here a target is a postsynaptic neuron, and its partners are presynaptic neurons mapped onto that arbor. Seven MICrONS targets had complete arbors and imaged partners: 69 partners in the selected-scan dataset and thirteen eligible scans in the scan-complete analysis. These recordings sampled stimulus responses rather than learning, so no credit was delivered (Fig.~\ref{fig:boundary}A).

Functional similarity was the Pearson correlation between partners' mean fluorescence responses across repeated stimulus conditions. Shared ancestry was the fraction of their soma-to-contact paths held in common. We ranked both measures and removed their associations with the two distance controls before correlating the residuals, yielding a partial rank correlation. Partners with more shared dendritic ancestry did not have reliably more similar condition-mean responses after controlling Euclidean separation and soma-to-contact path-length differences (shared-path comparison, Fig.~\ref{fig:boundary}A; estimate, Fig.~\ref{fig:boundary}B). Mean partial rank correlations were $-0.069$ for selected scans and $-0.048$ for all eligible scans, the same seven targets re-analyzed, and both target-bootstrap intervals included zero (Fig.~\ref{fig:boundary}B,C). The null did not depend on the measure: raw shared-path ($-0.025$), tree-distance ($-0.017$) and same-major-branch ($-0.003$) associations were also centered on zero (Fig.~\ref{fig:boundary}C; Supplementary Fig.~S31). This provides no evidence of preferential ancestry alignment in the sampled partners, at a different scale from population-level like-to-like wiring \citep{ding2025wiring}.

To assess sensitivity, response-level simulations preserved observed partners, shared inputs, repeated stimuli and seven-target inference, with noise calibrated to measured repeat reliabilities. Under the specified Gaussian ancestry-signal model, 80\% detection required a mean simulated target-level partial rank correlation of approximately 0.25 (0.249 by interpolation); the observed estimate and its whole interval lie below that point (Fig.~\ref{fig:boundary}D). Perfect reliability gave a similar threshold on this observed-correlation scale (0.248), but reduced the required underlying ancestry-signal fraction from $\lambda=0.589$ to $0.206$. Here $\lambda$ is the fraction of reliable tuning variance assigned to the ancestry covariance. Measurement noise therefore increased the underlying signal needed for detection, even though the required observed effect was similar. With measured reliability, the lower Monte Carlo confidence limit first exceeded 80\% detection at $\lambda=0.65$. Repeat reliabilities varied across recordings (Fig.~\ref{fig:boundary}D, inset). These conditional thresholds leave weaker effects, different signal geometries and unobserved partners unresolved (Methods; Supplementary Section~S9).

A separate passive-tree model predicted each target's responses from its recorded partners. Its selected ancestry routes reached only 48.0\% of mapped inputs, and in six of the thirteen scans every route reached a single input (Fig.~\ref{fig:boundary}E,F), so restricting the transfer profile to these supports tests transfer geometry more than example-dependent credit, and no measured positive control exists for this comparison. Held-out prediction, input-removal and reconstruction controls are grouped in SI (Supplementary Figs.~S31--S32), where the ancestry-minus-ridge difference (0.029; 95\% target-bootstrap interval, $-0.013$ to 0.074) is matched by random anatomical routes (0.031; $-0.009$ to 0.068). This model diagnostic and the measured ancestry-similarity test constrain different parts of the anatomical proposal.

\section*{Discussion}

Learning benefits from spatial selection when a common signal mixes incompatible weight changes. Dendritic morphology supplies candidate delivery patterns, teaching mechanisms supply their coefficients, and conductance regulates their gains. The image classifiers establish a useful reference: preserving neuronal identity supplies most of the learning benefit, including under random between-neuron feedback. Within-neuron selection becomes useful when branches receive conflicting evidence. Thus a dendrite's computational complexity does not, by itself, determine how finely its learning signal must be resolved.

The controlled routing tasks separate having a suitable dictionary from obtaining its coefficients. Hierarchical distractors favor ancestry routes at intermediate bandwidth, but only when the routes align with the task. The encoder experiment exposes two further limitations: identifying a route from noisy cues and preventing small coefficients from reaching incompatible routes (Fig.~\ref{fig:subtreefactorial}F). More calibration data reduced this leakage; exploratory hard selection removed it but retained a noisy-cue deficit. Exact paths and projected coefficients elsewhere remain information-access controls. An adequate span alone does not ensure useful delivery.

The interaction comparison shows why the input-sensitivity spectrum is also insufficient. Pairwise and quartic targets share that spectrum and a compatible tree, yet develop different credit fields and tolerate fixed profiles differently. Direction matters alongside dimension: even a nearly one-dimensional field can be poorly captured by uniform broadcast. These learned-state properties do not rescue the failed initialization-based selector. Forward compatibility poses a separate constraint: the scalar multi-affine cut criterion connects input grouping to hierarchical tensor representations and supports structure estimation from noisy examples \citep{hackbusch2009tensor,grasedyck2010hierarchical,cohen2016tensor}. A representation deficit should not be attributed to a learning rule.

Conductance trees provide a mechanism for locally available selection. In the seven-compartment neuron, a distal inhibitory gate supports opposing branch tuning without oracle path coefficients, provided proximal updates remain ungated. Cortical circuits select task-relevant sensory evidence, and earlier dendritic-disinhibition models connect pathway selection to plasticity \citep{mante2013context,yang2016gating}. Calcium- and reward-dependent plasticity, together with inhibitory plasticity, can also support nonlinear feature binding in a detailed striatal neuron \citep{khodadadi2025binding}. Our population experiment asks a narrower question by changing credit delivery at fixed forward computation: which spatial factors must a supplied learning signal retain? Correctly assigned resistance gates improve distractor robustness, with benefits depending strongly on stress and learning rate; uniform or wrong-branch attenuation does not reproduce them. Replacing forward shunting remains costly even with exact credit. Forward input selection and spatially selective learning therefore contribute separately in this task.

The nonlinear rescue clarifies why resistance gating is a conditional approximation. Inhibition selects a branch, but its current voltage sensitivity also depends on the input. Supplying that missing derivative substantially improves learning with Adam; shuffling it within the same branch and context does not reproduce the rescue. The much smaller SGD benefit cannot isolate a derivative-specific failure: exact SGD also remained inaccurate across the expanded development grid. These results leave open how learning-rate schedules, parameterization and update scaling affect convergence. The augmented rule assumes access to a parent derivative, and all these tasks supply context and somatic error. Learning or transmitting those signals, temporal evidence accumulation and reciprocal cable dynamics remain separate questions. Likewise, serial compartments help remove distributed nuisance gains, but do not guarantee an advantage for a particular credit rule: the exact-path LocalCA accuracy advantage reverses at the longer training budget while exact credit retains lower cross-entropy. Forward depth, error delivery and optimization time must be distinguished.

Reconstructed arbors compress their modeled passive response fields beyond a common broadcast. Degree--depth surrogates explain much of this capacity, and the target fields themselves favor ancestry through passive transport under a somatic loss. Testing alignment beyond that construction requires measured fields or a model with different error sources or active dynamics; changing the passive perturbation family alone would not suffice. Focal shunting supplies a biophysical link by reweighting a baseline-weighted ancestry partition. Driving-force changes partly cancel adjoint changes, while cable state sets the spatial selectivity of the resulting gradient. This is sensitivity transport, distinct from inhibition that computes errors or regulates forward gain and load \citep{rossbroich2023disinhibitory,galloni2026cellular,greedy2026celltype,safaai2026gainload}.

The small recorded cohort provided no evidence of preferential ancestry alignment; its offline learning diagnostic chiefly tests an almost fixed transfer profile. A direct experiment would compare plasticity below a focal inhibitory site with electrotonically matched off-route sites while matching somatic voltage, first-order current and outcome signal. Changing conductance state would test the predicted separation between shared and ancestry-selective effects \citep{francioni2026vectorized,cichon2015branch,bloss2016structured}. The anatomical calculations motivate this test but do not establish that the modeled routes carry endogenous teaching signals.

The framework complements somatic prediction, segregated teaching, interneuron-mediated errors and burst plasticity \citep{urbanczik2014dendritic,guerguiev2017segregated,sacramento2018dendritic,payeur2021burst}, alongside cable-learning and engineered gating models \citep{bicknell2021synaptic,chavlis2025dendrites,sezener2021gated,iyer2022activedendrites,lv2025dendritic}. Spikes, temporal eligibility, recurrence and channel kinetics may change both the available profiles and the way their coefficients are estimated \citep{bittner2017btsp,magee2020plasticity}. The organizing question is which task-relevant distinctions the arbor and learning mechanism can jointly preserve.

\subsection*{Model classes and biological evidence}

Image and depth experiments train populations of directed DendriNet trees with conductance or matched additive integration. Context-gated classifiers isolate feedback assignment without serial forward compartments. Scalar multi-affine trees permit exact representability tests. The seven-compartment conductance teacher uses an independent implementation of the directed balance; its population extension uses production DendriNet. Reconstructed arbors instead support modeled reciprocal cable transport. MICrONS visual responses are measured, but their learning-signal fields are modeled or imposed. None of these analyses records endogenous dendritic error delivery.



\subsection*{Conductance models and delivery coordinates}

In a directed tree, $[b_1,\ldots,b_D]$ lists branching factors from soma to tips, giving $\sum_{d=1}^D\prod_{r=1}^db_r$ nonsomatic compartments. Equation~\ref{eq:directedvoltage} specifies the forward steady state. Artificial conductance trees use dimensionless leak one and reversals $E_{\rm L}=E_{\rm I}=0$, $E_{\rm E}=1$. Monotone parameter transforms enforce nonnegative conductances. Branch-output nonlinearities, termed reactivations in the implementation, are identity functions when disabled. Both excitatory and inhibitory contacts learn in the regular-tree experiments.

For a reciprocal cable residual $\bm F(\bm V,\bm g,\bm x)=0$, the nonsingular voltage Jacobian $J_V$ gives the adjoint
\begin{equation}
J_V^{\mathsf T}\bm q=\nabla_{\bm V}\mathcal L,
\qquad \partial\mathcal L/\partial g_i=-\bm q^{\mathsf T}\partial\bm F/\partial g_i.
\label{eq:generaladjoint}
\end{equation}
With passive current balance, the synaptic gradient is $x_i(E_i^{\rm rev}-V_n)q_n$. This calculation supplies the reference \citep{almeida1987asynchronous,pineda1987recurrent,schiess2016somatodendritic,bicknell2021synaptic}. For output $a_n=f_n(V_n)$, activation error $\delta^a_n=\partial\mathcal L/\partial a_n$ gives voltage error $\delta^V_n=f_n'(V_n)\delta^a_n$. Image LocalCA replaces $\delta^a_n$ while retaining $f_n'$ and exact local gate derivatives in eligibility. Fixed activation-space profiles can therefore vary in voltage space; exact supplied fields recover exact selected gradients.

The raw-additive control retains the graph but sums signed inputs without the conductance denominator or reversal-potential driving force. Normalized-additive controls additionally standardize voltage across stage coordinates within each example; Supplementary Section~S2 defines those variants. Additional preconditioners are defined in Supplementary Section~S1.

Nonzero diagonal gains in $A\Gamma$ preserve span while changing conditioning (Supplementary Fig.~S5). Stage count, feedback rank and external error dimension remain distinct (Supplementary Tables~S1--S2).

\subsection*{Image feedback ladders and checkpoint diagnostics}

The decoder supplies neuronal activation errors. Strict scalar feedback shares their mean, substituting the largest-magnitude signed coordinate when the mean's magnitude is at most $10^{-6}$. Per-neuron feedback preserves neuronal identity. The historical scalar fallback retained that identity at the soma-width stage (640 of 2,413,312 core parameters); the separate strict-scalar control removes this exception.

MNIST networks use 128 $[3,3]$ trees with 40 excitatory and 20 inhibitory contacts per nonsomatic compartment. Rules share initialization and data streams within architecture. Pixels are flattened and divided by 255. Seed-specific splits contain 48,000 training and 12,000 validation images, with the official 10,000-image test set held out. Adam trains for 180 epochs with batches of 256, standard moment coefficients, no decay and validation-minimum checkpoint selection. Original synapse/decoder, coupling and gate rates are 0.0015, 0.0007 and 0.0005. Three development seeds select multipliers 0.3, 1 or 3 using validation alone; ten fresh seeds compare selected and original common rates (190 unique fits).

Projected $K=1,3$ rules average exact activation errors over the specified supports; decoder-only controls freeze the core. Capture uses 2,048 held-out images at initial and exact-trained states, with activation and voltage coordinates kept separate. Exact transport is checked against automatic differentiation.

Supplementary Section~S2 specifies the earlier fifteen-seed MNIST \citep{lecun1998mnist}, ten-seed Fashion-MNIST \citep{xiao2017fashionmnist}, twenty-seed CIFAR-10 \citep{krizhevsky2009cifar} and fifteen-seed DFA protocols. DFA uses a fixed Gaussian output-error matrix scaled by inverse square root of output dimension. Common-state diagnostics, recipient permutations, clipping, input coverage and task-identity records remain in that section.



\subsection*{Contextual conflict and ancestry routing}

The branch-conflict study crosses twenty paired seeds, three branch counts and eight opposite-class replacement probabilities. Equations~\ref{eq:branchconflictforward}--\ref{eq:branchconflictupdates} define the classifier and updates. BP and gated-point controls are equivalent; derangement changes recipients. Initialization utility is $\langle\bm d^{\rm shared},\bm d^{\rm selected}\rangle/\|\bm d^{\rm selected}\|^2$, distinct from nonnegative one-step utility below. Trained chance crossings use interpolation and each seed's first sampled crossing, retaining non-crossings. The separate ten-seed interference task trains both contexts for sixty epochs, then context 1 for twelve, measuring context-0 accuracy loss on 1,024 held-out examples.

The ancestry factorial has eight eight-dimensional blocks with balanced contexts and labels. Inputs combine unit teacher directions, Gaussian noise of SD 1.1 and context-relative coefficients $1,-0.15,-0.45,-0.75$. Unit-norm ancestry rows obey $\Phi^{(K)}_{cb}=\sqrt{K/8}\,\mathbf1[g_K(\pi(c))=g_K(b)]$, where $\pi$ permutes leaves and $g_K$ identifies contiguous groups. Updates are $\Delta\bm w_b=-(8\eta/N)\sum_i\delta_i\Phi^{(K)}_{c_ib}\bm x_{i,\pi^{-1}(b)}$. Each seed supplies 2,048 training, 2,048 test and 1,024 switch examples; full-batch descent uses rate 0.3, eighty training and twenty switch epochs.

The best matched control is each seed's maximum among four non-PCA controls. Integer correct counts preserve signed-rank ties; Holm adjustment covers four budgets. Generator, encoder, cue-delay and checkpoint-replay details are in Supplementary Section~S3; historical alternative tests remain labeled separately.



\subsection*{Update utility and prospective selection}

Let the exact gradient be $\bm\mu$ and the delivered update estimator have mean $\bm m$ and covariance $\Sigma_{\rm route}$ at the current weights. Here smoothness $L$ bounds how fast the loss gradient changes, $[z]_+=\max(z,0)$, and covariance is over the stated update randomness. For an $L$-smooth loss and a nonnegative step $\eta$, expected loss after the update is bounded above by $\mathcal L-\eta\bm\mu^{\mathsf T}\bm m+(L\eta^2/2)(\|\bm m\|^2+\operatorname{tr}\Sigma_{\rm route})$. Optimizing this expression gives utility $U=[\bm\mu^{\mathsf T}\bm m]_+^2/[2L(\|\bm m\|^2+\operatorname{tr}\Sigma_{\rm route})]$, with zero for a zero denominator. Utility certifies one-step progress under the stated moments; it is not a long-horizon ordering.

Synthetic quadratic screens use sixteen Haar coordinates and a designed signal/noise crossover, without a forward neuron (Supplementary Fig.~S3). Retrospective factorial utility uses actual full-batch updates and a global logistic-curvature bound; maximum bandwidth matches its selection success. Supplementary Figs.~S34--S35 retain the failed 12,800-fit prospective selector, its loss to fixed maximum-budget and rank-only baselines in every seed, and the 25,600-fit dynamics extension with evolving noise, observed-context-count controls, sealed choices; the computational-cost accounting is indexed in Supplementary Table~S12.

\subsection*{Interaction compatibility, fixed profiles and learned spectra}

For subtree leaf set $S$, the Fourier coefficient matrix $C_S$ indexes inside and outside input products. Removing its constant inside row gives $C_S^\circ$. A scalar multi-affine tree is compatible exactly when every centered cut has rank at most one. With proper cuts $\mathcal S(T)$,
\begin{equation}
\operatorname{MSE}(f,\widehat f_T)\geq B(T;f):=\max_{S\in\mathcal S(T)}\sum_{j\geq2}\sigma_j(C_S^\circ)^2.
\label{eq:morphologyselection}
\end{equation}
Overlapping cut tails cannot be summed. Supplementary Section~S4 gives the constructive proof, minimum-depth algorithm, candidate census and noisy-query estimator. These assumptions do not automatically extend to conductance ancestors.

Three development seeds select rates; twenty fresh blocks pair tasks, trees, initialization, inputs, noise and minibatches. Exact, unit, calibrated and sign-only profiles share eligibilities. Calibration averages path derivatives on 256 unlabeled examples. SGD/Adam selected and common rates yield 432 development and 1,200 fresh fits, with coefficients bounded to $[-2,2]$. The balanced extension replays original checkpoints before continuing all 720 unique algebraic trajectories to 16,384 updates. Original noise variance is 0.0225; NMSE divides by clean variance, one for pairwise/nested and one-half for quartic.

The new noise sensitivity uses twenty additional paired seeds, the inherited Adam rates, unchanged clipping/bounds and three noise conditions. It trains 720 trajectories to 16,384 updates; the primary contrast uses exact clean-domain NMSE over all 256 inputs. No fresh outcome selects rates. Independent endpoint replay and complete seed tables accompany Supplementary Section~S4.

For example-by-site path matrix $Q$, rank-one capture is $\sigma_1(Q)^2/\sum_j\sigma_j(Q)^2$. It permits oracle example-dependent amplitudes. Loss-weighted, eligibility-weighted and site-normalized diagnostics, relabeling controls and replay of 600 earlier fits are retained separately.



\subsection*{Conductance trees with context-dependent feature tuning}

Teacher and student share a seven-compartment directed circuit with identity outputs and 24 plastic E/I/coupling conductances. Independent log-conductance perturbations have SD 0.4; terminal gains begin near one. Paired rules share inputs and initial states. Aligned/opposed targets change the teacher's feature tuning while preserving representability.

Hard distal selection multiplies supplied somatic voltage error by $\mathbf1[a_p=0]$, with parent inhibitory activity zero or ten. Continuous selection uses $1/(1+g_p^{\rm I}a_p)$; proximal and somatic credit remain ungated. Neither rule uses exact path derivatives. Controls include exact credit, broadcast, oracle distal profiles, reversed selection and gating at both levels.

Twenty new paired seeds test all nine rules at three rates to 16,384 updates; the primary rate 0.03 and 4,096-update validation-selection window are fixed beforehand. Two primary sign-flip tests compare opposed broadcast-minus-gate error and its opposed-minus-aligned change, with joint Holm correction. Other intervals are descriptive. Earlier development, graded-target follow-ups, bound checks and context-cancellation definitions are retained in Supplementary Section~S5 and Figs.~S19--S21.



\subsection*{Sensory selection and inhibitory credit in DendriNet}

Sixteen $[4,2]$ neurons receive four independent two-feature streams, encoded as $\exp(\pm z)$, and excitatory cue channels. Cue-selected targets and proximal inhibition are defined in Results. Tonic inhibition has activity three; the current control fixes its matching voltage at initialization. Forward controls preserve context access and all 1,297 active trainable parameters.

Relative-resistance, wrong-branch and uniform-RMS rules differ only in terminal delivery. Proximal/somatic signals and readout gradients remain ungated. Intercompartment outputs are detached for local differentiation, and supplied learning signals are detached before multiplication by eligibilities. Tonic/current controls retain the cue-derived gate. Three development seeds select Adam rates 0.01, 0.03 or 0.1; twenty fresh seeds run 400 conditions for 4,096 updates. Validation alone chooses checkpoints. The two primary severity-three broadcast/RMS contrasts against resistance use Holm-adjusted paired sign-flip tests (Supplementary Table~S14).

The nonlinear rescue fixes the $\tanh$ parents and interaction target. It adds $hf'$, within-parent/context example shuffling and an algebraically exact full-factor diagnostic. Three development seeds tune Adam and SGD separately; twenty new seeds evaluate original and wider bounds (320 trajectories), followed by sixty missing common-rate trajectories on the same blocks. Two original-bound Adam contrasts, resistance-minus-augmented and shuffled-minus-augmented ordinary error, define the Holm family. Bound occupancy and interaction-gradient diagnostics never select settings. A further 100 same-seed trajectories keep nonlinear parents but remove target interactions at common Adam rate 0.03.

The archived context matrix compares delivered and exact gradients at identical selected states for all 400 original checkpoints, separately for terminal, proximal, somatic and readout parameters. Context entries are averaged within seeds before inference. This is a descriptive first-order diagnostic, not an Adam-step or continual-learning test. Supplementary Section~S5 retains all protocols and outcomes.



\subsection*{Serial depth, sensor fidelity and optimization}

Networks contain 64 somata and eight nonsomatic modules each; branching vectors and matched resources are given in Results. Grouped-point controls connect modules directly to soma; additive controls remove division. Approximately matched MLPs provide a separate reference.

Excitation carries class evidence multiplied by lognormal factors. Inhibitory sensors preserve their marginal distribution while fidelity $\alpha$ changes trial-specific correspondence. Nested, flat and local-ratio supports distinguish distributed information from locally available cancellation. Full generators, floors, contact inventories and development calibration are in Supplementary Section~S6.

Original cohorts use ten paired seeds, a 180-epoch cap, thirty-epoch patience and validation-minimum selection. Sixty source-consistent restarts extend ten exact-BP D1 references and fifty D3 fits to 600 epochs; optimizer/random states were unavailable for continuation. All D3 fits reach the cap with falling validation loss, while eight D1 fits stop early. BP and LocalCA rates/parameter groups differ, with clipping, decay and masks otherwise matched. Complete histories, optimizer-matched contrasts and restart discrepancies remain in Supplementary Section~S6.



\subsection*{Anatomical dictionaries and common-mode controls}

Observed MICrONS skeletons and mapped contacts define soma-rooted branch-to-branch segments. Initial eight and disjoint 47-cell cohorts come from the same mouse; Pinky is a second mouse, with ten of twelve selected cells meeting the inherited typed-contact criterion. Each subtree route contains the input-bearing descendants of its origin. Contact labels are direct where available and otherwise proxy-based as specified in Supplementary Section~S7. Compression preserves path length but only approximates resistance; direct-label, mapping and geometry sensitivities are retained.

The modeled passive perturbation field consists of reciprocal passive-cable gradient changes induced by small focal shunts. Every corrected dictionary receives one constant column and $K-1$ spatial columns. Ancestry selection uses inhibitory fraction times excitatory-area-weighted descendant fraction without field outcomes. Depth bins are reparameterized with the same constant while preserving their span; random routes, independent site shuffles and degree--depth surrogate trees provide controls. The weighted common component is removed before computing residual-energy capture. A common-constrained SVD oracle supplies the rank-budget ceiling. Numerical rank, coverage and nonzero density are reported separately; equal column count alone does not match those resources.

The initial eight cells provided post hoc development for common-mode correction; the protocol preceded evaluation of new v661 and Pinky outcomes. Two hundred randomized controls are averaged within each cell. At eight columns, all 47 v661 cells and eight Pinky cells qualify; other eligible budgets are retained without substituting for missing eight-column outcomes. Paired cell-bootstrap intervals and Holm-adjusted comparisons describe within-cohort consistency, not animal-population replication. The older route-generated positive controls use separate fields and endpoint definitions (Supplementary Section~S7).

\subsection*{Focal shunting and the electrotonic boundary}

Up to sixteen sites per cell span depth quartiles, each with at least three excitatory descendants and comparison sites. Excitatory/inhibitory area-scaled conductances use factors 0.35 and reversals one/$-0.2$. Doses are 0.25, 0.5, one and two times local leak-plus-synaptic conductance. Matched injection supplies $\kappa_k(E_{\rm I}-V_k)$ without changing the conductance matrix. A separately solved somatic current restores baseline voltage and remains fixed during differentiation; the squared-loss target is one unit below baseline. Finite differences check adjoint gradients.

Localization subtracts depth-matched off-route from descendant medians of absolute log gradient change, with floor $\epsilon=10^{-15}\max(1,\max_i|\gamma_i|)$. Signed changes and adjoint/driving-force substitutions are reported separately. Sites and control templates remain nested within cells.

Cylindrical axial conductance is $\pi r^2/(R_a\ell)$ and leak $2\pi r\ell/R_m$, with spherical soma area $4\pi r^2$. Sweeps span $R_a=100,150,250\,\Omega\,\mathrm{cm}$, $R_m=300$--$30,000\,\Omega\,\mathrm{cm}^2$, several dose normalizations and background conductance; the disjoint cohort has 235 sites in 45 cells. Weak-channel checks use sixty-four accepted draws per cell at $R_a=150$, $R_m=1,000$ and one background-leak unit. Fixed baseline Jacobians include voltage-gate derivatives; dose responses are local linearizations, not newly solved active equilibria. Channel strengths, exclusions and geometric fallbacks are in Supplementary Section~S8.



\subsection*{Measured-response prediction and geometric diagnostics}

The seven-target cohort includes thirteen eligible scans. Trial responses are the mean of the supplied ROI fluorescence traces in \texttt{RoiResponseSeries} over each stimulus interval; our analysis did not deconvolve the traces or apply a reliability correction. Repeated responses are averaged by stimulus condition for the ancestry-similarity analysis; partial rank correlations control Euclidean separation and soma-to-contact path-length differences. Offline learning holds out stimulus identities. Training-only percentile transforms produce nonnegative presynaptic proxies, and each partner enters at its dominant mapped contact segment. A linear somatic readout predicts the standardized target response. Only input-conductance credit differs across rules; readout and bias gradients remain exact.

Four-route dictionaries are selected without target responses and receive the projected baseline transfer profile multiplied by the scalar readout error. Supplementary Section~S9 defines delivery and reconstruction. Fig.~S31 reconstructs supports from saved segment identifiers, illustrating the median-input-count scan with identifier-based tie breaking; all scan supports are available. At common exact-trained states, field and eligibility-weighted update reconstruction compare the fixed profile, per-trial field projection and the best within-span update. These are oracle diagnostics rather than newly trained rules. Endpoint discrepancies are reported for 130 re-executions.

Ridge regularization uses training data within each outer split and the same measured predictors. Input removal, predictor noise and reliability masks are separate sensitivities; none uses held-out information for selection. Ten split/initialization replicates are averaged within scans and then within seven targets. Imposed route-span-alignment quadratic fields and the six-animal external signed-credit reanalysis are separate datasets and tests, described in Supplementary Sections~S7 and S9 and Supplementary Fig.~S33, respectively.

\subsection*{Statistics and computational provenance}

Internally frozen confirmatory choices precede outcome inspection but are not public preregistration. Pilots, post hoc analyses, same-seed sensitivities and prospective cohorts remain distinct. Intervals are experiment-specific 95\% intervals or prespecified adjusted 97.5\% intervals. Tests are two-sided unless stated; multiplicity families and ties are retained in Source Data. Null results imply equivalence only when a margin is tested.

The response-sensitivity simulation uses a positive-semidefinite shared-path covariance for 102 presynaptic roots, mixed with independent reliable tuning and recording-specific noise. Four thousand datasets at each of 21 signal fractions use the original partial-rank statistic and exact seven-target signed-rank test. Detection requires two-sided $P\leq0.05$ and positive mean; Wilson intervals quantify Monte Carlo uncertainty. Supplementary Section~S9 specifies the frozen Gaussian model and reliability assumptions.

Independent units are seeds, reconstructed cells, postsynaptic targets or external animals; sites, scans, splits and checkpoints remain nested. No prospective parametric power calculation set experimental seed counts. New sensitivities use 10,000 whole-seed bootstrap resamples and report all outcomes. Hashes identify code, protocols and checkpoints; replay tests check numerical outputs. Cohort-specific runtime records distinguish scientific execution from reviewer-installation checks (Supplementary Section~S10). New NumPy controls used NumPy 2.2.6; DendriNet analyses used PyTorch 2.9.1.
