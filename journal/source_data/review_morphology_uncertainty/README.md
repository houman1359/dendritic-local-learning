# Morphology preprocessing and label uncertainty

Eight cells from one mouse. Direct label availability is observed, not assumed random. Radius perturbations and mapping thresholds are sensitivity analyses, not calibrated uncertainty. Field-capture probes are fixed nominal model-generated fields; they do not test endogenous task credit. Chain compression preserves path length and the length-weighted radius product, but not axial resistance for heterogeneous radii.

All perturbations retained. Five radius draws are averaged within each cell before summaries; no additional animal replication is inferred.
