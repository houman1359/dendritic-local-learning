# Exploratory hard selection of learned route coefficients

Exploratory follow-up specified after observing the soft-encoder results. The identical learned context estimator uses a deterministic maximum-probability subtree readout. Original seeds and task data are paired sensitivity units, not a new independent replication. The encoder is unchanged; no task outcome selects its readout parameters. An imposed local branch-context cue is available during forward activation. The encoder learns its mapping to four subtree coefficients using local branch activation targets on separate calibration trials. It never receives exact parameter gradients or held-out task labels. Its weights are frozen before task training. Trial delay is a cue/eligibility mismatch under independent contexts, not a calibrated physiological time constant.

The twenty original seeds and fitted encoders are reused; this is a paired sensitivity analysis, not a fresh replication. The 256-trial, noise-SD0.5, zero-delay condition is retained as a reference to the primary soft experiment, not a new primary family. All intervals and unadjusted P values are descriptive; no exploratory row is assigned a primary-family Holm adjustment. Numerical learning outcomes and the original soft experiment are unchanged.
