\caption{\textbf{Task-dependent credit resolution in a conductance tree.}
\textbf{A}, Directed tree with four terminal compartments, two proximal
compartments and one soma. All 24 conductances are trainable. Two excitatory
and two inhibitory channels at each leaf receive activities
$\exp(\pm z_j)$; the same latent features $z_1,z_2$ reach both subtrees.
Binary context $c$ sets proximal inhibition.
\textbf{B}, Nominal leaf voltage versus latent input. Teacher E/I tuning
produces aligned or opposed branch responses with identical input samples.
\textbf{C,D}, Adam test NMSE at fixed checkpoints in 20 paired seeds.
The dotted line marks 4,096 updates; all fits continue with unchanged
optimizer state to 16,384. Near-overlapping unit and calibrated broadcast
curves share a legend entry. The three-profile control uses oracle
projection coefficients.
\textbf{E}, Calibrated-minus-exact NMSE deficit on opposed minus aligned
targets, using validation-selected checkpoints within each budget.
Small points show paired seeds; large symbols show means. Frozen
rule-specific and common rates coincide.
\textbf{F}, Fraction of distal gradient magnitude retained when the two
context-specific averages are mixed. Both evaluated rules use the same
initial or broadcast-trained weights, inputs and eligibilities. Trained
weights are selected within the 16,384-update window; zero indicates
complete cancellation and one none. Bands and whiskers in
\textbf{C--F} are descriptive 95\% whole-seed bootstrap intervals from
20,000 draws.}
