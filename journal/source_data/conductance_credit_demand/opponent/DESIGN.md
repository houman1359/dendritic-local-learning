# Separate second-stage development: context selects opposite E/I tuning

This design was specified after the complete first-family development and fresh outcomes, and after its symmetric budget extension was launched. It does not replace the retained first study, alter its source or protocol, or count as an independent confirmation of its hypotheses. It changes each leaf from a single E and I feature to ordinary two-channel E and I synapse blocks, using the same directed shunting equation as DendriNet. All 24 positive conductances are trained. Leak is 1, reversals are E_E=1 and E_I=E_L=0, and reactivation is identity; this remains a directed balance, not a reciprocal cable model.

Each leaf receives exp(z) and exp(-z), with z uniform on [-2,2]. Two distinct latent coordinates drive the two leaves in each subtree; both subtrees receive byte-identical latent features. A uniform independent binary context supplies inhibitory activity to the inactive parent: gate*(context != parent). The local voltage is E/(1+E+I), a parent voltage is sum(g_child*v_child)/(1+sum(g_child)+g_I*context_input), and the soma uses the same weighted balance without its own E/I input. Teacher responses supply noiseless labels and a constructive zero forward floor.

For opposed tuning, one teacher subtree has local gains(E+,E-,I+,I-)=(8,.25,.25,8), and the other has(.25,8,8,.25). The aligned control uses the first pattern in both. Teacher log gains receive independent seed-specific N(0,.15^2) perturbations. Students start with four local gains all 1, parent I gains 15, daughter coupling pattern(20,.2) in each subtree, and soma gains 4, with independent N(0,.4^2) log perturbations to every one of the 24 parameters. Students, inputs, contexts and minibatches are identical across paired aligned/opposed conditions. No exact symmetry is imposed on student parameters.

At any fixed parameters the six-coordinate path field has at most two distinct rows because only context changes parent transmission. This tests whether context-dependent branch selection can matter for learning in a conductance tree. It is not a quartic-task representation claim, an interaction-order continuum, or evidence for six independent external errors. All q factors are positive: any individual-example fixed-positive-profile update has a nonnegative inner product with that example's exact gradient. A learning gap, if present, must arise from combining conflicting examples and the resulting optimization dynamics.

In addition to exact, unit broadcast and initial calibrated broadcast, a three-pattern oracle uses fixed initial-profile columns on distal units(0,1), distal units(2,3), and proximal units(4,5). Its per-example coefficients minimize path-field squared error using the current exact q. This is an explicit oracle routing control, not a locally estimated encoder.

All four development regimes and all three learning rates per optimizer/rule will be retained. The declared task-order selection depends only on exact learnability and teacher geometry, never on the observed broadcast gap. Fresh seeds and equal-budget extension are disjoint from development. The learning-rate and source freeze are separate from the first study.
