# State-matched positive-conductance reliability result

The locked programme completed 50 paired seeds,
2,250 seed--condition rows and every numerical gate. All input rates,
excitatory conductances and shunt conductances are nonnegative. A compensating
current holds branch voltage identical, isolating the physical input-resistance
factor in local eligibility.

At reliability heterogeneity 2, aligned minus best-global one-step loss
decrease was 0.001913 (95% interval
0.001789--0.002038); all
50/50 paired seeds favored
aligned conductance. Aligned minus no-shunt one-step decrease was
0.000947 (0.000114--0.001914),
but only 28/50 pairs favored
aligned and the two-sided Wilcoxon value was
0.249.

After 40 updates, aligned-minus-global final test loss was
-0.019052 (-0.020553---0.017552);
negative favors aligned. However, aligned-minus-unshunted final loss was
0.003810 (0.001367--0.006036),
so the immediate improvement did not become a sustained advantage over the
unshunted noisy rule. Exact clean backpropagation remained the optimization
reference. The state-matched conductance and explicit point gate were identical.

This validates a positive-conductance realization of reliability shrinkage,
not autonomous shunt learning, a dendrite-exclusive operation, or uniform
training superiority.
