# Clean exact-transport versus backpropagation audit

This directory is generated by
`scripts/collect_clean_exact_bp_rerun.py` after all acceptance gates pass. The
factorial contains 320 training runs: two learning methods, two tasks, two
forward cores, four dendritic depths and ten paired seeds. The 160 method
pairs are the inferential comparisons.

The synthetic additive model retains signed transfer outputs. The positive-
conductance synthetic shunting model uses an explicit ReLU transfer before
conductances enter the denominator. This makes the comparison input-valid but
means it is not a byte-identical replication of the excluded historical
signed-shunting condition.

- `run_outcomes.csv`: accepted run endpoints, condition fields, artifact
  checks, hashes and evaluation-path flags;
- `paired_differences.csv`: every seed-, task-, core- and depth-matched
  exact-minus-backpropagation accuracy difference;
- `condition_summary.csv`: method-specific seed summaries;
- `exact_bp_contrasts.csv`: depth-specific and within-seed depth-averaged
  paired contrasts; and
- `summary.json`: source commits, completeness gates and global numerical
  bounds.

Depth-averaged contrasts first average depths one through four within each
seed. Bootstrap intervals resample the ten independent paired seeds. Exact
transport is an information-oracle implementation control, not a proposal
that biological circuits compute the oracle.

## Audited result

All 320 runs and 160 method pairs passed the frozen collector. There were no
missing artifacts, nonfinite final metrics or checkpoint tensors, incomplete
dendritic stages, critical accepted-log matches, or transport-shape fallbacks.
Forty-two runs used the explicitly logged batchwise recomputation after a
full-dataset terminal metric exceeded device memory; every resulting endpoint
was finite.

Depth-averaged exact-minus-backpropagation accuracy was 0.005 percentage
points for additive MNIST (95% paired-seed bootstrap interval -0.028 to
0.041), -0.013 for shunting MNIST (-0.047 to 0.022), -0.112 for additive
noise resilience (-0.465 to 0.247), and -0.098 for shunting noise resilience
(-0.653 to 0.390). Across all 160 depth-specific pairs, the mean difference
was -0.0545 points and the largest absolute individual pair difference was
5.90 points. These results support close agreement of condition averages, not
a formal equivalence conclusion or pointwise equality.
