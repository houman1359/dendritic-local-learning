# Learned local-context route coefficients

An imposed local branch-context cue is available during forward activation. The encoder learns its mapping to four subtree coefficients using local branch activation targets on separate calibration trials. It never receives exact parameter gradients or held-out task labels. Its weights are frozen before task training. Trial delay is a cue/eligibility mismatch under independent contexts, not a calibrated physiological time constant.

Twenty fresh paired seeds. Oracle/frozen fits repeated across nuisance cells are identical controls, not additional independent observations. Confidence intervals resample seeds; three primary contrasts use Holm correction. Other grid contrasts are descriptive sensitivity analyses. The protocol was locally fixed and hashed before outcomes, not publicly preregistered.
