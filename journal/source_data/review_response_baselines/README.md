# Measured-response baselines and observed-input sensitivity

Seven targets from one mouse. Train-only nested tuning and split-wise reliability filters; perturbation draws average before scan and target aggregation. Missingness removes observed presynaptic features and cannot recover unobserved inputs or estimate population power. Archived nonlinear fits are descriptive paired references, not retrained under each sensitivity mask.

Run `OPENBLAS_NUM_THREADS=1 python scripts/analyze_review_response_baselines.py`. All preprocessing, repeat-reliability masks and ridge tuning use training identities only. Manual masks use archived contact provenance. Missingness masks are nested within each of five random orderings; perturbation draws average before outer splits, scans and seven targets. Noise is added to predictors in train and test, scaled by training-only feature SD; this is measurement degradation, not biological time or a task-rank manipulation. Empty masks use an intercept-only model and remain included. Archived nonlinear fits are read unchanged. Output rows retain every declared condition. Intervals resample seven target means; no population-power or equivalence claim is made.

Validation: `OPENBLAS_NUM_THREADS=1 python scripts/audit_review_response_baselines.py` reconstructs and hashes all 130 outer trial masks and stimulus-identity sets, verifies all historical train/test counts and inner/outer stimulus disjointness, and challenges one complete nested analysis per scan with arbitrarily altered held-out inputs and responses. All 338 condition-level checks preserve selected penalties, masks and training-only reliability exactly. Original historical trial-mask arrays were not separately archived; the unchanged archived helper and seed rule provide deterministic reconstruction. See `validation_report.json`, `outer_split_audit.csv` and `heldout_exclusion_audit.csv`.
