# Morphology, interaction structure and learning: independent design audit

The minimal useful test is a locally connected nonlinear scalar tree. Restrict each leaf to one named input and each internal compartment to one scalar output. With this restriction, trees have mathematically different function classes even when the task sensitivity spectrum, number of parameters, number of edges and local operation are identical. An unrestricted dense compensating matrix would erase the intended structural hypothesis.

The primary diagnostic uses all 105 perfect matchings and all 35 unordered four-plus-four partitions on eight inputs. The two families have exactly the same input-gradient covariance, I/4. They differ in their interaction supports and degree. They are enumerated independently of the twelve candidate trees, so a task is not generated by choosing its favored candidate. This is an exact finite-domain mechanism study, not a new prospective validation of a learned selector or a conductance-neuron experiment.

## What the earlier prospective model can and cannot show

In `scripts/run_prospective_morphology_selection.py`, every candidate has a freely learned dense 8×8 matrix W. Its output is aᵀHWx, with invertible passive transfer H in the joint arm and H=I in the feedback-only arm. Projection updates from zero enforce W=DZ, where D contains K route directions. If the task contexts span Q_r, only the r×K matrix B=Q_rᵀHD controls representability. Whenever B has row rank r, choosing Z=B†Q_rᵀW_teacher reproduces every noiseless context. Generic rotations give this condition for K≥r. Geometry still changes singular values, parameter norms, finite-time conditioning and costs, but does not then impose an irreducible function-class difference.

For the experiment's orthogonal teacher and equally likely contexts, rank(B)=q yields the population optimum half-MSE `(r−q)/(2r) + noise_variance/2`. Thus a policy selecting K close to r has a strong analytic basis; the dense weights can undo passive transfer. The original result is an honest failure of a one-step score as a long-horizon selector, not evidence that useful morphology selection is impossible.

The package's true branch parametrization is richer than this surrogate. `DendriticBranchConfig` specifies separate E/I input dimensions, synapses per branch, input branch factors and explicit connection indices/masks. `branch_synapses.py` explicitly rejects structured indices under adaptive non-indexed wiring because rewiring can leave the prescribed spatial regions. `branch_dynamics.py` distinguishes raw additive, tangent-matched and normalized/shunting integration. Those distinctions must remain explicit when bridging from the present algebraic test. The replacement module `transformer_replacement/morphology_matrix.py` also identifies itself as a legacy proxy rather than a PopulationNetwork morphology experiment. Its wins or losses cannot validate biological branching claims.

## Executable fixed-resource construction

Use independent inputs x_i∈{−1,+1}, each at a single leaf, and evaluate all 256 inputs with equal probability. A tree has eight leaves, seven internal nodes and fourteen edges. Every internal node computes

`u_v = a_v + b_v u_left + c_v u_right + d_v u_left u_right`.

Only the root is read out. Every tree therefore has 28 coefficients, the same local scalar operation and the same number of edges. There is no dense input mixing, hidden-state concatenation, cross-branch connection, unrestricted skip readout or learned input permutation. The three shapes are balanced, comb and a 3+5 root split with balanced children; the same four predetermined leaf permutations are used for every shape. Shape and input assignment are separate factors. Their physical path lengths and depth-dependent execution latency are not equal, so the study establishes a fixed-edge/parameter result rather than a claim of identical biological or hardware resource cost.

Primary targets are:

- **Quadratic matching:** `f_M(x)=.5 Σ_(i,j in M) x_i x_j`, for all 105 perfect matchings. Variance=1.
- **Quartic partition:** `f_A(x)=.5[Π_(i in A)x_i + Π_(i not in A)x_i]`, for all 35 unordered4+4 partitions. Variance=.5.

For both, the continuous derivative of the unique multilinear extension has zero mean, and `E[∇_x f ∇_x fᵀ]=I/4`. Consequently algebraic rank and participation-ratio effective rank are both8, and the full covariance spectrum—not just rank—is identical. Normalized MSE divides native MSE by target variance so loss scales are comparable. This covariance is a task-input sensitivity descriptor. It is **not** the changing covariance of model parameter gradients, synaptic eligibilities or compartmental credit during learning. The difference in target variance is intentional and reported; fixed spectrum and fixed target variance cannot both be obtained by a single rescaling of these degree2 and degree4 targets.

The enumeration is a census of two finite combinatorial families. It does not supply140 independent draws from a biological task distribution, and optimizer restarts are not biological replicates. Report exact family means, quantiles and counts rather than sampling confidence intervals over the exhaustive tasks. Family-specific results are preferable to an unqualified pooled score because the families contain unequal numbers of tasks.

## A sharper structural bound than global rank

Expand the target in orthonormal Walsh monomials, `f(x)=Σ_U c_U Π_(i in U)x_i`. Parseval gives `E[(f−g)²]=||c_f−c_g||²` exactly. For a candidate subtree with leaf set S, reshape coefficients into a matrix C whose row index is a subset of S and whose column index is a subset of its complement.

Every scalar subtree enters every ancestor affinely, because its output appears only once and the other child depends on disjoint inputs. Therefore any represented function has the form

`g(x)=A(x_notS)+h_S(x_S) B(x_notS)`.

The full coefficient matrix has rank at most2. More strongly, removing the row for the empty subset of S leaves a rank-at-most1 matrix. The constant subtree feature is fixed; an arbitrary two-dimensional left space is not available. Hence

`LB_S = Σ_(j≥2) σ_j(C_without_empty_S_row)²`

is a lower bound on population MSE. The maximum over actual proper candidate subtrees remains a lower bound. The sum is merely a heuristic score because the cuts overlap. Normalize by target variance for NMSE. Halve the numerical bound if the endpoint is defined as half-MSE. The empty-root/rest case and single-leaf cuts are uninformative. Do not impose the centered-rank1 constraint on arbitrary complements that are not themselves candidate subtrees.

Analytical checks:

1. The usual matching `(01)(23)(45)(67)` has zero bound on the compatible balanced tree and an explicit exact realization: multiply within each pair, add the pair results and multiply the root output by .5.
2. For that target, subtree S={0,2} has centered tail.25; an even/odd root split has tail.75. Rank8 alone cannot distinguish these assignments.
3. For the two-quartet target with supports0123 and4567, subtree S=01234 has full coefficient rank2 and rank2 tail0, but centered rank1 tail.25. This distinguishes the actual scalar bottleneck from a generic bond-dimension2 tensor approximation.
4. The correctly grouped balanced quartet target is represented by products within each quartet followed by their sum. A3+5 split and comb expose additional incompatible cuts.

The centered-rank conditions are necessary and, when exactly zero at every actual subtree cut, jointly sufficient in this particular multi-affine model; the proof below handles their compatibility. A positive maximum-cut bound need not equal the true optimum. The gap between a fitted model and the bound may contain both optimization error and looseness of the bound. Call it a **gap above the lower bound**, not a proved optimization gap.

### Exact representation theorem for a fixed tree

Let the inputs be independent Rademacher variables with the complete uniform truth table, and fix a binary tree with one named input at each leaf. The target is represented exactly by scalar nodes `u=a+b*l+c*r+d*l*r` and a root-only output **if and only if** every proper subtree's Fourier matrix, after removing its empty-subset row, has rank at most one.

Necessity follows from the affine-in-subtree factorization above. For sufficiency, associate a function space V_S to every subtree S. If its centered matrix has rank one, let h_S be a nonzero centered function whose Fourier coefficients span that matrix's column space, and set `V_S=span{1,h_S}`. If the matrix is zero, set `V_S=span{1}` and h_S=0. For a leaf use `V_i=span{1,x_i}`. The rank condition says that the complete target belongs to `V_S ⊗ H_notS`, where H denotes the complete finite-dimensional function space on the named inputs.

Consider sibling subtrees L and R. Their orthogonal projections act on disjoint tensor factors and commute. The target therefore belongs to `V_L ⊗ V_R ⊗ H_outside(L∪R)`. For a non-root parent P=L∪R with a nonzero centered component, write the global target as `1_P ⊗ A + h_P ⊗ B`, with B nonzero. Contract the outside factor against a linear functional taking B to one. This produces `h_P + c*1_P` in `V_L ⊗ V_R`. The constant function is also in that product space, so h_P itself lies there. Consequently h_P is a linear combination of `1, h_L, h_R, h_L*h_R`, exactly the four allowed local features. If P has no centered component, its zero feature is trivially representable. At the root, the complete target itself lies in the product of its children's spaces and has the same four-feature representation. Induction from leaves to root supplies all local coefficients.

This proof makes the constant channel explicit and resolves the compatibility issue that the uncentered rank-two condition alone misses. It also explains the constructive SVD algorithm: choose each active h_S from the dominant left singular vector of the centered target matrix, then solve its local four-feature coefficients. Exact rank-one cuts imply exact local reconstructions in exact arithmetic. Numerical near-zero tails only certify an approximate rank condition to the stated tolerance, not an exact theorem about noisy measurements.

The theorem relies on every ancestor being affine in the output of a given child. A general nonlinear scalar ancestor can generate a high-rank function of that scalar feature and the other inputs. Therefore neither this necessity statement nor its lower bound applies automatically to a tanh tree, a conductance model or an arbitrary scalar bottleneck. A width-m extension has centered rank at most m only when the ancestor remains affine in that branch's vector output.

## Fitting and finite-effort interpretation

Alternating least squares is a useful initial optimizer because each node's four coefficients are linear conditional on the other nodes. Let q(x) be the derivative of the root with respect to u_v. The correct local design is `q(x)[1,u_left,u_right,u_left*u_right]`; the offset is the current root output minus `q(x)u_v`. Omitting q would solve a different problem. Alternating postorder/preorder sweeps and multiple fixed random starts reduce, but do not eliminate, nonconvex optimization failure.

Record every restart and its loss trajectory, not only the winner. Report best-restart upper bounds, restart means/spread, dead coordinate blocks, least-squares design rank and parameter norms. A subtree whose ancestor gain vanishes can become a dead block. Unrestricted hidden-state affine gauges can also create enormous cancelling coefficients; mean/RMS normalization with exact compensation in the parent preserves the represented function and is a sensible numerical stabilization. Full-domain fitting has no generalization gap. Its finite-sweep comparison is an algorithm-effort result, not an experiment in local synaptic plasticity or gradient-descent sample efficiency.

For a later genuine finite-horizon learning test, freeze candidate local Jacobians J and compare the actual initial score with the full spectral trajectory. In the linearized squared-loss model with `K=JJᵀ/N`, gradient flow yields `r(t)=exp(−Kt)r(0)`. Initial progress is determined by `rᵀKr`, whereas loss at t depends on every kernel eigenvalue and the target's energy in its eigenvectors. Equal rank does not determine either quantity, and ranking initial slopes need not rank finite-time risks. A finite-sample/noisy experiment would then add independent training and test examples, a declared step budget and development-only hyperparameter selection. It should follow—not be conflated with—the present exact-domain capacity study.

## Falsifiable controls and interpretation

- Verify all 140 targets are unique, covariance-equal and generated before reference to candidate fits; verify the Walsh design is orthonormal.
- Verify all candidates retain exactly 28 parameters,14 edges and one input per leaf. Record their actual subtree sets so different drawings of the same function class are not counted as different morphologies.
- For random realized tree functions, every candidate subtree must satisfy the centered-rank1 constraint numerically. Verify the node derivative design with a finite coefficient perturbation and verify gauge normalization preserves all 256 outputs.
- Include explicit exact matching and quartet constructions. A failure to learn these when a positive lower bound is absent is an optimizer diagnostic.
- Every fitted NMSE must exceed its normalized lower bound within a stated numerical tolerance; do not sum cut lower bounds and call the result a bound.
- For selectors, use a tolerance for mathematically tied bounds. Floating-point SVD tails can differ at 1e−16, so raw `idxmin` need not implement the promised lexicographic tie rule. Keep frozen outcomes and repair selector aggregation in a separately versioned analysis.
- Compare both fixed predetermined and best-fixed-in-hindsight baselines, and show the cost of a two-sweep pilot. A per-family hindsight baseline uses family identity beyond constant rank and must be labeled accordingly.
- Report assignment effects within a fixed shape separately from differences between shapes. On a complete permutation-symmetric family, each permutation of a given shape has the same population distribution of structural bounds; unequal empirical mean fitting errors can reflect optimization variability.
- Both primary families may favor balanced shape because their interactions are parallel collections. Do not force a crossover. The implemented separate positive control is `.5 Σ_(k∈{2,4,6,8}) Π_(j≤k)x_pi(j)`, using 24 seeded permutations. Its covariance eigenvalues are `.25,.25,.5,.5,.75,.75,1,1`, not I/4. All permutations within that family are isospectral; rank is8 and effective rank is 20/3≈6.667. It cannot be pooled as another isotropic primary task. This differs from the initially suggested eight-prefix control, which was not the executed experiment.
- A capacity result for signed bilinear algebraic nodes is not a result for positive conductances, active dendrites or anatomically realistic electrotonic shape. The later biological bridge must preserve input-access constraints and compare actual conductance, tangent-matched and additive branches at stated physical budgets.

## Primary literature and what it supports

[Saxe, McClelland and Ganguli, ICLR2014](https://arxiv.org/abs/1312.6120) show that even networks with the same linear function class can have different nonlinear parameter-learning dynamics. Initialization and singular-mode structure matter. This supports separating representation from finite-time optimization; it does not establish a morphology selector.

[Canatar, Bordelon and Pehlevan, Nature Communications2021](https://www.nature.com/articles/s41467-021-23103-1), with [author manuscript](https://arxiv.org/html/2006.13198v3), analyze task alignment with kernel eigenfunctions and how it affects learning curves. This is the closest conceptual precedent for why eigenvalues alone or a single task-rank number cannot determine sample efficiency. Its kernel/infinite-width scope must not be imported as a theorem for finite nonlinear dendritic trees.

[Raskutti, Wainwright and Yu, JMLR2014](https://www.jmlr.org/beta/papers/v15/raskutti14a.html) establish early stopping as regularization in kernel least-squares regression. This motivates specifying training horizon and noise when asking for an optimal model, rather than treating asymptotic fit and finite-data performance as interchangeable.

[Mhaskar and Poggio,2016](https://arxiv.org/abs/1608.03287) study approximation advantages for compositional function classes. [Cohen and Shashua, ICML2016](https://proceedings.mlr.press/v48/cohenb16.html) connect restricted network architectures with tensor decompositions. Together they motivate using interaction structure and architecture-specific tensor cuts. The centered-rank1 condition above is a direct derivation for the present scalar affine-subtree model, not a borrowed theorem about biological dendrites.

[Poirazi and Mel, Neuron2001](https://www.sciencedirect.com/science/article/pii/S0896627301002525) analyze capacity gains from nonlinear dendritic subunits and structural input allocation. [Poirazi, Brannon and Mel, Neuron2003](https://pubmed.ncbi.nlm.nih.gov/12670427/) show that a detailed pyramidal-neuron model can be approximated by a two-layer nonlinear-subunit model. These establish a biological computational motivation for local nonlinear processing and input placement, while leaving the present exact tree arithmetic deliberately abstract.

[Bicknell and Häusser, Neuron2021](https://pubmed.ncbi.nlm.nih.gov/34715026/), also available from [UCL](https://discovery.ucl.ac.uk/id/eprint/10137669/), derive a cable-based learning rule and demonstrate learned nonlinear feature binding using spatial and temporal input structure. Their result that useful computation can be learned without specially structured connectivity is a substantive counterweight: local-access restrictions should be tested, not assumed to make one morphology universally necessary.

## Audit of the new implementation

I independently inspected `scripts/morphology_structure/model.py`, `run.py` and `test_model.py` before the full outcome analysis. The Fourier conventions, actual-subtree selection, normalized centered-cut bound, derivative-weighted coordinate solve and affine gauge compensation match the derivation. No blocking scientific error was identified. The selector-tie tolerance, final-diagnostic repetition in checkpoint rows, distinction between a lower-bound gap and a certified optimization gap, and task-input versus parameter-gradient covariance should remain explicit in reporting. The frozen protocol correctly describes an exhaustive mechanism diagnostic rather than a deployable prospective selector.

## Completed fixed-pool results and numerical audit

The independent `scripts/morphology_structure/audit_analysis.py` reads the frozen 1680 candidate endpoints and 6720 complete four-restart fits. It implements absolute score ties at 1e−10 with lexicographic candidate IDs, and compares achieved errors with tolerance1e−7. This changes31 selected IDs relative to raw floating-point minima while leaving the reported mean regrets unchanged. No original endpoint, fit or protocol was overwritten.

For all 105 quadratic matchings, the centered-cut selector's mean NMSE is0.378571 and its mean regret relative to the best fitted candidate is0.009524. The full-cut selector's regret is0.023810; best fixed in hindsight is0.173810; random-candidate expectation is0.270040. For all 35 quartic partitions the corresponding regrets are approximately0,0.042857,0.042857 and0.052381. The two-sweep fitting pilot attains approximately zero mean regret in both families; it is a computational baseline that already fits every candidate. These are full-target oracle scores and exhaustive family averages, not independently calibrated prospective predictions. The maximum of valid bounds outperforms the sum heuristic on the matching family, so adding more cut penalties indiscriminately is not justified.

The fixed pool contains only twelve trees and misses many exact target-compatible assignments. Its best fitted candidate has mean NMSE0.369048 for matchings and0.442857 for quartic partitions. Zero regret in this pool therefore does not mean zero approximation error or globally optimal morphology. The subsequent constructive experiment removes this restricted-pool ceiling explicitly.

Shape and input assignment have distinct effects. At the same four assignments, mean matching NMSE is0.545833 for balanced trees,0.621429 for the 3+5 shape and0.750000 for combs. Across420 same-task/same-assignment comparisons, comb is worse than balanced in319 and tied in101. Mixed is worse than balanced in162, tied in220 and better in38. Thus balanced is better on average here, but is not uniformly better under a fixed assignment. Changing assignment within balanced trees changes achieved error for73/105 matching tasks; within the mixed shape it changes error for97/105; the comb's variation is below numerical tolerance. Quartic assignment effects occur in4/35 tasks for the balanced shape; mixed and comb both average0.5 NMSE. These are paired combinatorial counts, not statistical hypothesis tests.

A fitted endpoint attains its centered-cut lower bound within 1e−7 in1407/1680 cases (987/1260 matching cases and all 420 quartic cases), numerically certifying its optimum within the declared class and tolerance. The remaining positive gaps are not certified optimization errors. The maximum observed checkpoint error increase is3.06e−10 and the minimum endpoint-minus-bound is−5.59e−10, consistent with numerical roundoff at the1e−7 reporting tolerance. Some ALS fits contain large cancelling coefficients:20/6720 final fits have norm above 1e4 and16 above 1e8; four best-error restarts among1680 candidate endpoints exceed both thresholds. For each endpoint, the audit also records the minimum-norm existing restart within 1e−7 of its best error. Only `matching_013/balanced_p1` lacks a small-norm equivalent among its four existing restarts. Crucially, every selected case for all deterministic policies has an equivalent existing fit with norm at most2.645752. These feasible alternatives preserve the selected-policy result without excluding any fit or changing the frozen endpoint. The norm certificates and selected-policy joins are retained in `audit_norm_certificates.csv`, `audit_selected_norm_certificates.csv` and `audit_norm_summary.json`.

## Adaptive construction and depth certificate

The separate `constructive_dp_v2` analysis considers every labeled binary tree on the eight named inputs through dynamic programming over subsets. First minimize the maximum normalized centered-cut tail. Then constrain all cuts to that globally minimal threshold and minimize total tail, followed by tree depth and deterministic split ties. This two-pass procedure corrects the earlier exploratory implementation's generic secondary-objective issue; both original and corrected data are retained. The corrected implementation matches exhaustive enumeration of945 six-input trees on four independent integer-valued cost tables.

For a subtree S, the minimax recurrence is `B(S)=max(cost(S), min_(L partition S) max(B(L),B(S\L)))`, with zero leaf costs and zero root cost. Every binary tree has exactly one root split and two recursively independent children, so the recurrence exhausts all possible trees. When the optimal threshold is zero, minimizing depth within its feasible splits identifies the shallowest exact tree by the representation theorem. For positive thresholds, the DP certifies the best cut-bound score, not the smallest achievable nonlinear fitting error. Rounding cut costs to12 decimals is a declared numerical tie convention.

All105 matching targets and all 35 quartic targets have zero-bound constructions at minimum depth 3. All24 nested-prefix controls have zero-bound constructions at minimum depth 4. An independent depth-constrained DP gives a minimum centered-cut lower bound of0.146446609407 for every nested-prefix target at depth≤3, and zero at depth≤4. Thus the depth requirement is a representational obstruction, not merely a property of one constructed solution. These164×3 depth calculations are recorded in `design/constructive_depth_certificate.csv`. The SVD/local least-squares construction reproduces every target, with maximum normalized error6.88e−30 and maximum absolute coefficient approximately1. The primary tasks therefore establish a need to adapt assignment and grouping despite the same full input-sensitivity spectrum; they do not establish differing optimal primary-family depths. The separate nested family supplies a shape/depth positive control at the same parameter and edge count, while honestly retaining its different sensitivity spectrum. This is an exact-target construction and representational certificate, not training from limited data, a universal biological morphology law or confirmation that the earlier one-step selector predicts long-horizon outcomes.
