# Learning after oracle-informed morphology construction

This controlled bridge tests whether a compatible multi-affine tree can learn from label-independent weights under exact and restricted credit. It separates parameter learning from structure estimation. It uses three development seed blocks and20fresh blocks;3,600fresh fits retain every optimizer/rate/rule/assignment and21,600checkpoint rows. `protocol.json`, `protocol_freeze.json`, `selection_freeze.json` and`validation.json` preserve the protocol/source/choice chain. Run`python scripts/morphology_credit/audit.py` from the journal directory to recheck it.

The exact tree comes from the complete target Fourier tensor. Projected credit coefficients also use the current exact path field. Neither is claimed to be a biologically learned or limited-data estimator. All28weights start from label-independent random values; a shape-preserving input-label permutation tests structural compatibility at matched resources. Test targets have independent noise SD0.15. NMSE uses the known noiseless target variance,1for matching/nested and0.5for quartet targets. Thus the irreducible expected test NMSE is0.0225/0.045/0.0225.

Rates were selected only on development data, separately for each optimizer and rule, with a shared-rate check selected on development as well. All SGD rules chose the top tested rate0.03; this is a frozen finite-grid recipe, not an assertion of globally optimized SGD. Parameters were constrained to[-2,2], which contains the known exact constructions; clipping/projection counts are retained, and several restricted rules hit the parameter bounds. Do not interpret the outcomes as unconstrained optimization optima.

With compatible trees, mean test NMSE under Adam was0.0247/0.0495/0.0245for exact credit versus0.0422/0.9911/0.7538for broadcast on matching/quartet/nested targets. Exact compatible-tree Adam averaged0.0329versus0.6080after input-label shuffling. SGD exact credit improved quartet/nested targets but broadcast performed better on matching targets. Both optimizers favored exact credit on the average of all three families, under the frozen recipes. Exact and broadcast Adam use different development-selected rates, but the shared-rate analysis retains the same qualitative conclusions.

Two proximal-subtree oracle profiles improved some conditions, but did not consistently outperform size-matched shuffled profiles; averaged under SGD, their performance nearly equaled broadcast. The experiment therefore supports a conditional value of informative credit and compatible forward structure, not a universal ordering of hierarchical credit bases. The main figure displays task heterogeneity; complete controls are in Supplementary FigureS40.

Reported95%intervals resample20whole paired seed blocks; task families are averaged within each seed for pooled comparisons. They are pointwise descriptive intervals, not multiplicity-adjusted discoveries. `gradient_cosine` is the cosine between aggregate population gradients at the learner's own state, not a mean of per-example cosines. Full clean-domain population NMSE is secondary to the independent noisy test endpoint.
