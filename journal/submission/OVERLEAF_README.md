# Overleaf package

The canonical build instructions are in `../OVERLEAF_README.md`; the current manuscript uses nine main figures and 36 supplementary figures. Build the final combined PDF and `Overleaf_Project.zip` after integrating all text, figure and methods fragments. Use the main/supplementary PDFs from that build to determine page counts.

The figure map is `../figures/README.md`. Replace a previous Overleaf project in full when uploading the new standalone ZIP, and inspect both manuscript previews. Internal revision logs and unrelated project files are excluded from the project archive.
